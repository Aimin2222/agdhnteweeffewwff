# LoL AutoCine v5.9.8 — スマートハイライト・ディレクター

## 今回の追加
- 参考動画から一般化した「導入→追走→キル瞬間の強調→自然な復帰」を**明示的なスマート自動編集**で利用できるようにしました。
- かんたん編集の「自動カメラ演出」: **おまかせ / 追走シネマ / キル瞬間を強調 / 集団戦（広め）**。
- キル時刻基準のカメラキーフレーム5点を自動生成し、キャラクター中心の既存TargetLockを使います。キル前後は緩やかな曲線でゼロへ戻します。
- 短時間だけ映像の明るさ・彩度をわずかに強調するエフェクトを追加。常時強いBloomやぼかしを入れないため、色が残りやすい方式です。
- 詳細編集の「全シーンに参考動画風のカメラ＋キル強調を設定」は、現在スキャン中のシーン全件を一括更新し、Undoで元に戻せます。
- 詳細編集のシーン設定に「キル瞬間の強調」スライダーを追加。色・FXの全体上書きがOFFでも、この一瞬の強調は独立して使えます。
- シーン編集プロジェクトJSONへハイライト強度を保存。旧版データも読み込み可能。
- ログに `SCENE_PLAN ... highlight=... keyframes=...` を出力し、自動編集が実際に選択されたか分かるようにしました。

## 使い方
1. LoLリプレイへ接続、対象プレイヤーを固定。
2. **かんたん編集**で「自動カメラ演出」のタイプを選択。
3. 「✨ スマート自動編集」を押す。従来の「★ これで自動作成」は既存の挙動を維持します。
4. **詳細編集**ではシーンをスキャンし「全シーンに参考動画風のカメラ＋キル強調を設定」→シーン別編集ON→チェックしたシーンを作成。変更したくない個別設定がある場合、この一括上書きは押さずに既存のシーン設定を使ってください。

## 注意・限界
- 元動画の完全再現ではありません。イベントメタデータからは敵の実際の方向やスキル軌跡を測定できないため、追走型とは**対象プレイヤーを中心にした控えめなカメラ演出**です。
- LoLのReplay APIの応答遅延で実機のガクつきは残ることがあります。
- 新しいキル瞬間エフェクトはFFmpegのCPU標準フィルターで実行し、GPUエンコードNVENCの経路はそのままです。GPUエフェクト化を達成したわけではありません。
- 既存の個別シーン設定は尊重します。すでに編集済みのシーンにはスマート自動編集時もその設定を適用し、自動上書きしません。
- LoL音声、既存のGPUエンコード、モンタージュ連結、HUD処理、TargetLock本体は変更していません。

## Windowsテスト
1. 通常「★ これで自動作成」で1本作成（以前どおりか）。
2. スマート自動編集「おまかせ」で1本（キル前後の寄り引き・一瞬の明るさ変化・対象の固定・LoL音声を確認）。
3. スマート自動編集「集団戦」で1本（引いた画角・カメラの安定性）。
4. 詳細編集で「全シーンに参考動画風のカメラ＋キル強調を設定」→Undo→Redo→保存/復元。
5. チェック済み2シーンを作成、モンタージュと音声・カラーを確認。
6. `COLLECT_DIAGNOSTICS.bat` でZIPを生成して送付（ログの `SCENE_PLAN` を確認）。
