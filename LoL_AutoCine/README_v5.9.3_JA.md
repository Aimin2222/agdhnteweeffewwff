# LoL AutoCine v5.9.3 — 編集モード分離・カメラ滑らかさ改善

## 主な変更

- **上部の表示切替**：「★ かんたん編集」/「⚙ 詳細編集」。既存UIコントロールは削除せず、表示だけ切り替えます。切替時にシーン別設定・チェック状態・保存済みプロジェクトをリセットしません。起動時はかんたん編集、表示選択は設定に保存。
- **かんたん編集**：自動作成、スマート自動編集、仕上がり「自然」「シネマ」「ダイナミック」の3種類にアクセス。リプレイ準備、プレイヤー固定、テンプレート、検出シーン、出力状況、LoLミラーは常時表示。
- **詳細編集**：タイムライン、シーン別ディレクター、モンタージュ順、色/FX、カメラキー編集、カメラ数値設定、参考動画、全設定を表示。
- かんたん編集で「★ これで自動作成」を押すと、保存済みの手動シーン上書き設定はその実行では適用されません。**保存済み設定は消しません**。「✨ スマート自動編集」はシーン別演出経路を使います。詳細編集では既存のシーン別演出ON/OFFに従います。
- **カメラ時刻補正**：Replay APIの観測値に0.25秒ごとに補正ステップを足す動作を廃止。小さな時刻誤差は再生速度の微補正として滑らかに吸収。大きな外部seek時だけ時刻をリセット。
- **キーフレーム補間**：3点以上のキーフレームは単調性を保つ三次Hermite補間を使い、連続して変化する区間の中間点でもカメラが停止しないように変更。2点の場合は従来のsmoothstep。
- **便利な編集プリセット**：詳細編集に「自然な回り込み」「寄って戻る」「キル瞬間を強調」の5点キーフレーム型を追加。型を当てても自動保存はされず、「このシーンに保存」で確定。
- **三人称カメラの安定設定に戻す**：距離、Yaw、仰角を安全寄りの値に戻すボタンを追加。既存のシーン上書きは消さない。
- **カメラ診断ログ**：録画中のReplay API送信回数、25ms超の呼出回数、最大API待ち、最大時刻ずれを記録。

## 変更していないもの

- `core/effects.py`, `core/gpu_pipeline.py`, `core/audio*.py`, `core/procloop.py` 等のGPU/音声経路。
- LoLの座標系、TargetLockの追従・旋回計算および校正値。
- 元の検出/出力/モンタージュ/音声機能（モード表示のみUIで分離）。

## PCでテストしてほしいこと

1. **新規フォルダ**に展開し、`START.bat` で起動。v5.9.2は別に保管。
2. 上部で「かんたん編集」「詳細編集」を何度か切替。LoLミラーは消えないか、詳細編集に全項目が戻るか。シーン・チェックの選択が消えないか。
3. かんたん編集で「自然」「シネマ」「ダイナミック」を順番に選択し、最後に任意の仕上がりで**1クリップ自動作成**。カラー・LoL音声を確認。
4. 詳細編集 → 検出シーン選択 → キーフレーム「自然な回り込み」 →「このシーンに保存」→**1クリップ生成**。カメラが不連続に飛ばないか確認。シネマ/動きの前後も見る。
5. 「追従カメラを安定設定に戻す」→ 1クリップを再生成し、**前の映像と比較**。対象が画面から外れないか確認。
6. 2シーンチェックしてモンタージュ出力。順番、カラー、LoL音声を確認。
7. `COLLECT_DIAGNOSTICS.bat` を実行し、診断ZIPを共有。特に `カメラ動作診断` がログにあると有用。

## 既知の限界

- カメラの引っかかりはReplay API HTTP待ち、LoLの描画FPS、キャプチャ、実機リグにも影響されます。今回の修正は**時間同期と補間のソフト側の段差対策**であり、Windows/LoL実機での改善効果は未検証です。
- キャラクター中心の追従カメラ自体の座標・視線・校正は変更していません。カメラの位置が間違っている問題は別途映像を見て調整が必要です。
- GPUエフェクトの高速化はCodex側の変更と統合してください。このZIPをCodexのGPUコードへ丸ごと上書きしないでください。
