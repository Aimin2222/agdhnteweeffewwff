# LoL AutoCine v5.10.15 Windowsテスト

v5.10.14とは別フォルダにWindows版ZIPを展開しSTART.batから起動。まず診断結果を保存してください。

## A. プルダウンとページ
- [ ] キルフレームの選択肢を開いてホイール → 候補だけ上下、裏の画面はスクロールしない
- [ ] カラーグレード／モンタージュの選択肢でも同じ動作
- [ ] かんたん／詳細へ切替してもシーンのチェック・編集値・ミラー状態が変わらない
- [ ] 詳細編集はシーン／カメラ／カラー／FX／出力だけ。中の「基本／カラー／FX・DOF／出力」タブが消えた
- [ ] チェックは×ではなく✓で表示。独立ON/OFFは同時に複数選べる

## B. シーン・色・ぼかし
- [ ] シーン選択するとキラーの公式チャンピオン顔が表示（取得できなければ名前表示）
- [ ] 簡単編集「仕上がりを大きく比較」で、左元映像／右色補正後が見やすい
- [ ] カラーグレード名が「青緑×橙」「ノワール」「夕焼け」など分かりやすい
- [ ] FX→DOFチェックONで直下に詳細が開き、OFFで閉じる
- [ ] DOFの円形・従来上下、強さ・中心、ミラー画像比較が正常
- [ ] 10種類の「動画のつなぎ目」を選べ、2クリップ以上の書き出しに反映できる
- [ ] キルフレーム37画像（K/DA風、PROJECT風、スターガーディアン風等）が図鑑で選択できる

## C. カメラ（重点）
- [ ] RED側通常三人称のクリップ：キル対象が画面内で見える
- [ ] RED側FPS風のクリップ：以前より中央に近く、地形・壁が目立たない
- [ ] BLUE側の通常・シネマ・FPS・Lolnam風は以前より悪化していない
- [ ] RED側Lolnam風も同様に良好な状態を維持
- [ ] クリップ録画後、ミラーが勝手にOFFにならずカメラ復帰も正常

## D. 書き出し・回帰
- [ ] 1920×1080、60fps固定で書き出せる
- [ ] LoLゲーム音のみ録音、映像との同期に問題がない
- [ ] NVENC/CPUの使用とGPU FXの実行ログが正しい
- [ ] HUD/TargetLock/キル+アシストの検出と1回スキャン後のプレイヤー切替が正常

不具合があればRED/BLUE、カメラ名、該当キル時刻、MP4、AutoCine_Diagnostics.zip、スクショを送ってください。

注意：Windows実機でのLoL映像の良否とGPU性能は自動テストだけでは判定できません。
