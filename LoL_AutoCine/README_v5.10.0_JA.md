# LoL AutoCine v5.10.0 — UI / GPU / キルフレーム統合改善

前提: v5.9.9 Champion Pair Fix（キラー × 被撃破チャンピオンの公式画像）を維持し、追加機能だけを改修。
**横1920×1080**が標準。縦型Shortsは作らない。既存のカメラ/TargetLock、LoL専用音声録音、HUD、シーン別編集、モンタージュ、FFmpeg処理は維持。

## 今回の追加・修正

1. **スクロール誤操作防止**: 読み取り専用Combobox／Spinbox上のマウスホイールは値を変更せず、それを収めるパネルをスクロールする。これにより「キル→アシスト」などの意図しない変更を防ぐ。
2. **検出シーン一覧**: 左端 `[✓]` または `[  ]` を直接クリックすると個別にON/OFF。右側の選択操作と既存「全選択/全解除/チェックしたシーンだけ作成」を維持。文字の右側を押すと通常どおりシーンを選択。
3. **上部ナビ**: ホームはリプレイ準備、テンプレートは実際のプリセット選択、参考動画は入力・一覧、設定は詳細編集→出力タブへ移動。参考URL入力欄の内容も取得に使用。従来は「ホーム」でミラーにフォーカス、「設定」でログだけ表示していた。
4. **キルフレームの調整**: 色（枠・発光）、発光ON/OFF、強さ、枠の太さ（1–8px）、中央マーク（テンプレート任せ／シャープX／二重斬撃／交差する剣／稲妻／クリスタル）。既存4テンプレート、チャンピオン顔2つ、配置・大きさ・秒数・不透明度は維持。カラーコードは `#RRGGBB` として検証。不正な色は既定色にフォールバック。
5. **GPU実態の可視化**: 設定→出力でエンコーダを自動・GPU優先・CPU優先から選択。素材録画／時間補正／最終エフェクト書き出し／モンタージュの切替演出へ同じ方針を渡す（未対応ハードウェアではCPUに戻る）。GPU対応のFFmpeg上でもドライバ起因でNVENC実行に失敗する場合は **libx264で安全に1回再試行**。診断JSONとログに実際のエンコーダと再試行理由を残し、画面に直近の成功/失敗・エンコーダとGPU/CPUエフェクト経路を表示。
6. **設定保存**: 新しい色、発光、中央マーク、エンコーダ選択は `settings.json` へ保存・復元。既存データのフィールド順と旧保存形式との互換性を維持。

## GPUの正確な状況

提供側資料には `AutoCine_Diagnostics(6).zip` の直近5回が「h264_nvenc成功・エフェクトCPU」と記載されている。この診断ZIPをCodex側で直接検査した結果ではない。NVENCによる圧縮処理とGPUフィルタ処理は別機能で、v5.10.0では分けて表示する。今回のLinux環境では実NVENCの拒否とlibx264への再試行を確認した。実GPUでの成功と性能は未確認で、ブルーム/DOFのGPU高速化は未実装。

録画はフレーム送信前にNVENCの実行プローブを行う。録画途中の失敗は中断し、元動画を保持する。完成素材の時間補正・FX・切替モンタージュでは、NVENC選択時のFFmpeg失敗後に同じ映像/音声条件でCPUへ一度再試行する。CPU優先は映像エンコードの選択であり、GPUエフェクトのON/OFFではない。

## Windows実機テスト

1. 古い版とは別フォルダへZIPを展開して `START.bat` を実行。音声ヘルパーのセットアップが必要なら既存スクリプトの指示に従う。
2. ホイールを「検出対象」「テンプレート」のプルダウン上で回しても値が勝手に変わらず、パネルがスクロールすることを確認。
3. 右の検出シーン `[✓]` / `[  ]` を直接クリック。2回押すと元に戻り、任意の3つだけ選んで作成できることを確認。
4. 上部のホーム/テンプレート/参考動画/設定を順にクリック。対象の画面へ移動し、設定タブで出力先・GPU設定・キルフレームが見つかることを確認。
5. キルアイコンをONにして、公式チャンピオン画像2つが表示され、文字 `KILL` / `x1` が出ないことを確認。枠色・発光色・マーク・枠幅を変え、再起動して保存を確認。
6. 設定でCPU優先を指定した短いクリップを作り、映像エンコードがlibx264になることと、エフェクト経路が別に表示されることを確認。続けて自動かGPU優先で実際のNVENC/CPU経路を確認。
7. 問題があれば `diagnostics/performance/*.json` を確認する。`COLLECT_DIAGNOSTICS.bat` でローカルへ収集できる。外部への自動送信はしない。

## 検証の範囲

提供側の183件という記載とは別に、統合後のLinux/Xvfbで**209件成功**。実FFmpegの合成動画、NVENC拒否→CPU再試行、実Tkの設定再起動とモックAPI経由のカメラ/録画/モンタージュを確認。**Windows、実LoL、実GPU/NVENC成功、Windows専用Process Loopbackは未確認**。詳細は `docs/CODEX_INTEGRATION_RESULTS_v5.10.0_JA.md`。
