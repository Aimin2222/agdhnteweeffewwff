# LoL AutoCine v5.10.12 — Match Scan / Calibrated Side Camera / Premium Quality / Color

ベース: v5.10.11 Windows Full。

## 変更点

1. **試合全体スキャン1回**: Replay APIから全体の ChampionKill イベントを収集し、終了後はメモリ内キャッシュからプレイヤー・BLUE/RED・キル/アシスト条件で即座に再抽出。対象を切り替える度に試合全体を再生する必要はなくなった。最初の1回は従来同様、試合尺に応じた再生時間がかかる。途中キャンセル/試合の再接続時はキャッシュ破棄。
2. **サイド別の安全寄りカメラプロファイル**: Replay APIの三人称リグが実測済みの絶対座標方向を返す場合、REDでさらに180°を二重適用しない。BLUE -12°/RED +12°の穏やかなオフセットと、サイド別の仰角/距離下限を適用。手動BLUE/RED指定の水平回転は既存仕様を維持。対象追従/TargetLockロジックの基礎座標は不変更。
3. **安全構図**: 既存のカメラ位置読み戻し検証と俯瞰フォールバックを維持。スマート構図選択時の距離/高さを保守的に引き上げ、過大Orbit回転を制限。**被写体をAIで画面認識したり、地形遮蔽を画像で判定したりする機能ではありません。**
4. **キルフレーム高画質化**: 既存の透過PNGアセットは1ピクセルも変更せず、素材型21種類の合成途中解像度を従来の2倍（770×232）へ。映像合成時に表示サイズを戻す。GPU FullとCPU FFmpegの両経路で対応。元画像自体を生成AIで再描画していないため、失われた顔肖像の細部そのものを復元する処理ではありません。
5. **テンプレートカラー差**: ゴールド/アイスブルー/Lolnam/紫/ネオン/フィルムの強弱を調整。既存の実シーン図鑑の大型左右比較を利用可能。
