# LoL AutoCine v5.9.5 — 編集ワークスペース整理

## 使い方
1. `START.bat` で起動。
2. 左上から順番に **リプレイ準備 → 対象プレイヤーを固定 → キル/アシストをスキャン**。
3. 上部の「★ かんたん編集」で自動作成、または「⚙ 詳細編集」に切り替える。
4. 詳細編集では、中央下の編集ワークスペースを選択する。
   - **シーン**：タイムライン、シーン別ショット、キーフレーム、順序、シーン個別FX。
   - **カメラ**：全体の追従、距離、高さ、Yaw、Orbitと自動モーション。
   - **カラー・FX**：全体の色補正、カーブ、Fog、DOF、映像演出。
   - **出力**：映像・音声・BGM・LUT・保存先。
   - `Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4` でゾーンへ移動可能。
5. 右上で「検出シーン」を選び、チェック切替、該当キルへのジャンプや書き出しをする。プレビューは上段に固定される。

## 新機能：シーン設定をコピー / 貼り付け
- 「シーン」ゾーンでコピー元を右の検出一覧から選択する。
- 必要に応じて Orbit・Dolly・Yaw・キーフレーム・FX を調整する。
- 「設定をコピー」を押す（**未保存の編集値もコピー**）。
- 右の検出一覧で別シーンを選び「設定を貼り付け」を押す。
- 貼り付けは編集プロジェクトに保存され、「元に戻す / やり直す」に対応する。
- クリップを別シーンの時間・キル対象へ移すのではなく、**演出設定のみをコピー**する。

## UIの整理
- 左側の優先順位：①リプレイ準備 → ②プレイヤー固定 → ③スキャン → 参考動画 → テンプレート。
- 右側の優先順位：検出シーン → 出力状況 → その他の設定・ログ。
- 詳細編集時のカメラとカラーの**重複した右側のスライダーは非表示**。値や処理コードは消していない。
- 出力ワークスペース表示中は、右側の重複するクイック出力設定のみ隠す（HUD等は維持）。
- 架空の再生時刻・疑似シークバー表示を削除し、実際のミラー/Replay APIと混同しないようにした。
- ヘッダー上下の余白を縮小した。

## 維持したもの
- 既存のショット/キーフレーム、Replay API、TargetLock、カメラ時計、キル/アシスト検出、ミラー、LoL Process Loopback音声、NVENC、色補正、FX、モンタージュ、診断。
- `core/` と `ui/` 以下の**実装コードはv5.9.4から変更していない**。変更対象は主に `legacy_app.py` とUIテスト。
- かんたん編集と詳細編集を切り替えても編集状態とチェック済みシーンは初期化しない。

## 検証と残る課題
- Linux/Xvfbで56件のPython自動テスト通過。Windows/LoL/GTX 1070 Ti実機は未検証。
- 同梱するGPUエフェクト環境の制約で、NVENCエンコードが動いても動画エフェクトはCPUフォールバックする場合がある。GPU最適化はCodex側と連携する。
- カメラ位置/視点・Replay API待機によるガクつきは今回のUI整理で変更していない。以前の時計補正は維持。

## テスト
1. `START.bat` で起動。
2. 左側の準備→プレイヤー→スキャンの順番と、右側のシーン一覧が上方にあることを確認。
3. 詳細編集へ切り替え、4ゾーンが切り替わることを確認（中央に同じカラー/カメラスライダーを二重表示しない）。
4. 2つのシーンをスキャンし、片方で `自然な回り込み` を設定。設定をコピーし、もう片方へ貼り付け、Undo/Redoを確認。
5. 右のチェックしたシーンだけ作成を実行。カラー、カメラ追従、LoL音声を確認。
6. `COLLECT_DIAGNOSTICS.bat` で診断ZIPを送る。`No logs found` の場合は `diagnostics/latest_diagnostics.zip` でも可。
