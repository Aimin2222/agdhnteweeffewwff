# LoL AutoCine v5.10.10：まとめて実施するWindows確認リスト

## 1. 起動・画面
- [ ] 新しいフォルダで `START.bat` から起動できる。
- [ ] 起動直後の「LoLミラーを開始するとここに実映像が表示されます」が中央に表示される。サイズ変更しても中央に残る。
- [ ] かんたん編集で設定が過密でない。詳細編集の「キルフレーム詳細」が開閉できる。
- [ ] タブ上のマウスホイールで基本／カラー・FX／録画・出力が勝手に切り替わらない。検出シーンのチェックでスクロール位置が戻らない。

## 2. 実シーン比較（今回の最重要）
- [ ] 対象プレイヤーを固定、LoLミラーON、キル／アシストの両方をスキャン。
- [ ] 上部「テンプレート」の図鑑から、キルとアシストのシーンを選択できる。
- [ ] 「①選択シーンへ移動」の後、ミラーで正しい場面を確認。
- [ ] 「②ミラーの今の実フレームを保存・比較」で実際のゲームの1枚が登録される。
- [ ] 同じ実フレームを使い、左が元画像／右が補正後で、色味の違いが分かる。
- [ ] 保存済みのシーンに切り替えるとその画像に切り替わる。未保存シーンでは架空画像を表示しない。
- [ ] 図鑑の検索・テンプレート適用が動作する。
- [ ] かんたん側Aの色見本カードと図鑑Bの両方を試し、どちらが操作しやすいか比較。
- [ ] 「デフォルト」「ゴールド」「アイスブルー」「ネオン」などを比較。ミラー再生中にも選んだ色が反映される。

## 3. プレミアムキルフレーム・発光
- [ ] プレミアムゴールド／黒曜石×ゴールド／ネオン・クリスタル／星と翼／炎熱ゴシック／サイバーパンクを選べる。
- [ ] キルフレームのプレビューと書き出しで、被写体のチャンピオンと倒された相手の顔アイコンが正しい。
- [ ] 素材フレームが巨大に表示されず、**1080p動画上の右上などに収まる**。
- [ ] 発光の弱（0.4）／標準（1.0）／強（1.7）で実際の見た目が変わる。
- [ ] 発光色（金／青／紫など）・角の光・縦積み間隔の調整が機能する。
- [ ] 2〜3キル連続時に、装飾が縦に重なり過ぎず映る。
- [ ] 既存のシンプル／シネマ／ネオン／インパクト／装飾なしも壊れていない。

## 4. 既存機能の回帰
- [ ] キル＋アシストが両方検出される。
- [ ] ブルー／レッドで三人称カメラが自然に向き、TargetLockが対象を見失わない。
- [ ] 手動プレビュー再生なしで最初のキルを録画し、ネクサスが冒頭に映らない。
- [ ] プレビュー・書き出し後、ミラーが地形に埋まらず安全な視点へ戻る。
- [ ] 円形DOF、カラー・FX、HUD設定が録画結果に反映される。
- [ ] 1920×1080、60fps、LoLゲーム音が正常に書き出される。
- [ ] Codex側のGPU設定・ログが従来どおり有効で、意図しないCPUフォールバックがない。

## 異常があった場合に送ってほしいもの
- 問題の `kill_001.mp4` または `montage.mp4`
- `AutoCine_Diagnostics.zip`
- 設定したテンプレート名、キルフレーム名、発光強度
- 実シーン比較画面またはミラーのスクリーンショット
