# AutoCine v5.10.11 — Windowsまとめテスト表

**順番**：v5.10.10と別フォルダに解凍し、`START.bat` 起動。まず `✓ 自動診断`、次にゲーム内の比較を行う。

## 1. 自動診断（最初に実行）
- [ ] アプリ上部「✓ 自動診断」または `RUN_AUTOTEST.bat` を実行。
- [ ] `diagnostics/selftest_latest.json` が生成され、「失敗 0」になる。NVENC等はハードウェア依存のため「注意」が出る可能性あり。
- [ ] 上記の自動テストは LoLカメラやゲーム画面を**勝手に動かさない**ことを確認。

## 2. テンプレート図鑑
- [ ] 実キルまたはアシストをスキャンし、図鑑からシーン選択、ミラー移動→フレーム保存。
- [ ] 左右比較がカード幅いっぱい（補正前／適用後）に拡大されている。
- [ ] 画像をクリックすると、さらに大きな比較ウィンドウが開く。
- [ ] その画像と書き出し動画でカラー補正が大きくズレないか確認。

## 3. カメラ（RED側とBLUE側の両方で）
- [ ] 三人称・通常、三人称・追従、三人称シネマ、FPS風、Lolnam風を同じキルで順に再生。
- [ ] プレビュー上部の「設定」と「実際」表示を照合。「実際：FPS風/俯瞰」の場合は三人称成功とは扱わずログを保存。
- [ ] RED側で被写体が画面外・地形に隠れないか、BLUE側で以前の方向が保たれているか確認。
- [ ] ▶プレビュー/録画後のミラー復帰が地面に埋まらないか。
- [ ] 不自然な回転やカクつきが残る場合、同じ設定の短いMP4＋診断ZIPを保存。

## 4. キルフレーム
- [ ] 装飾ドロップダウンから従来の4種類＋素材21種類を確認。
- [ ] 金系・紫ネオン・K/DA風・PROJECT風・Star Guardian風・Spirit Blossom風・High Noon風が見分けられる。
- [ ] キルとアシストの双方で、左・右のチャンピオン肖像が正しいか。
- [ ] キルフレーム詳細ボタンで**同じ場所に設定欄が開き、画面が自動スクロールする**。
- [ ] 発光ON/OFF・弱/標準/強・縦並び間隔が保存される。
- [ ] 連続キル2〜3件でフレームが重ならないか。

## 5. ミラー・映像・音声・GPU
- [ ] ミラー開始を2回押しても勝手にOFFにならず、明示的な「停止」で終了する。
- [ ] 操作していないのにミラーOFFになる場合、ログの「理由:」を確認。
- [ ] リプレイを手動再生せず初回クリップを作成でき、ネクサスが入らない。
- [ ] 1080p 60fpsの動画が作成でき、LoL音声だけ入り、音ズレがない。
- [ ] Codex側GPU書き出し時のハードウェア使用は診断ログとタスクマネージャーで確認。

問題時は `AutoCine_Diagnostics.zip`、問題シーンのMP4、設定したカメラ/キルフレーム名を送ってください。
