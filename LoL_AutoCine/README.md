# LoL AutoCine v5.0.2

白基調UI + OrbitTargetLock 3人称カメラ + Lolnam風自動モーション。

## 今回の重要修正
- クリップが8倍速などになるタイミングずれを実時間基準で補正。
- 音声はデスクトップ全体ではなくLoLプロセス音声のみを録音。
- 音声のネイティブ処理を子プロセスへ隔離。
- TargetLockの座標系と既存3人称追従は変更していません。

## 起動
`START.bat` を実行してください。

## 3人称カメラ
- 固定キャラを常にターゲット
- 0 / 90 / 180度Orbitでもターゲットを維持
- 自動Orbit
- 自動ドリーイン
- ローアングル
- FOV変化
- キル前→キル→キル後の滑らかなモーション
- 複数キル時のワイド化

## 音声
LoLのゲーム音だけを対象にします。デスクトップ音声へのフォールバックは行いません。
