# LoL AutoCine v5.10.5

Windows向けのLoLリプレイ編集アプリです。キル検出、三人称TargetLock、カメラ演出、GPU対応エフェクト、LoLプロセス専用音声で横型1080p動画を作成します。

## 起動と使い方

1. 旧版とは別フォルダへ完全版を展開します。
2. `START_GPU.bat` を実行します。GPU対応FFmpegの初回準備にはダウンロードが必要です。
3. LoLリプレイを開いて接続し、10人を取得して対象プレイヤーを固定します。
4. キルを検出し、最初はチェックした1シーンを60 FPSで書き出します。

音声の初回確認は `00_AUDIO_TEST.bat`。Native Audio Helperの構築バッチは従来どおり使えます。音声はLoLのみで、デスクトップ音へ切り替えません。従来の `START.bat` も残しています。

## 今回の変更

- v5.10.5のサイド別カメラ、最大3段の実チャンピオン画像キルログ、発光、見える「？」説明を統合しました。
- ミラーの画像変換・簡易FX合成を別スレッドへ移しました。未処理の映像・設定は最新1件だけ保持し、古い設定結果を表示しません。簡易FXは最大15回/秒、録画と書き出しは通常60 FPSです。
- グラフ更新をまとめ、見えているときだけ低頻度でヒストグラムを更新します。キルフレーム画像の取得・発光処理もUIを止めません。
- 旧説明書を保存して整理しました。実行ファイル・音声ヘルパー・起動バッチの位置は保っています。

## フォルダの案内

| 場所 | 内容 |
| --- | --- |
| `app.py` / `legacy_app.py` | 起動・現在の画面と操作 |
| `core/` | GPU、FFmpeg、録画、カメラ、Replay API、LoL音声 |
| `ui/` | タイムライン、シーン編集、ミラー制御、非同期プレビュー |
| `assets/` | フォント・チャンピオン画像キャッシュ |
| `tools/` | GPU FFmpeg準備、診断収集、Native Helper、開発用パッケージ作成 |
| `tests/` | 回帰テスト |
| `docs/` | 統合・開発・GPU処理の記録 |
| `docs/history/` | 過去版の説明書（当時の仕様。現在の起動手順には使わない） |
| `patches/history/` | 過去のUI差分 |
| `settings.json` / `projects/` | 自分の設定・シーン編集データ（自動生成、Git対象外） |
| `diagnostics/` | 実行ログと診断（個人情報が含まれるため公開しない） |

詳細は [今回の統合](docs/CODEX_INTEGRATION_v5105_JA.md)、[Windows確認項目](docs/WINDOWS_TEST_v5105_JA.md)、[アプリ配布への開発順序](docs/APP_PACKAGING_PLAN_JA.md)、[UI側の更新内容](README_v5.10.5_JA.md) を参照してください。

GPU Bloom/円形DOF/Focus BlurとNVENCは対応環境で利用します。色補正などとミラーの簡易合成はCPU処理が残ります。GPUに対応しない場合は理由を記録してCPUへフォールバックします。

この版はPythonと起動バッチで動くデスクトップアプリです。単体exeのビルドとWindowsでの配布検証は次段階です。
