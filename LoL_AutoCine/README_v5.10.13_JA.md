# LoL AutoCine v5.10.13

## 主な更新
- 検出シーンカードに「表示プレイヤー」切替を追加。試合全体スキャン後、その場で対象プレイヤーを切り替えて一覧を更新できます。
- REDサイド自動三人称カメラの基準角を180°反転寄りに再調整。添付のRED側動画に合わせて、従来より対象の背面側を向きやすくしています。
- `image-gen-1.zip` の16枚を、キルフレーム素材としてすべて追加。既存21種と合わせて合計37種類。
- キルフレームは従来どおり高解像度素材のまま内部合成します。

## 注意
- REDカメラは今回「180°反転寄り」の暫定補正です。RED動画4本で、被写体が見やすくなったかを確認してください。
- 検出シーンの「表示プレイヤー」は、切替時に対象固定も連動更新します。
