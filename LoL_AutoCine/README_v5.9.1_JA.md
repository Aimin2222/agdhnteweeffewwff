# LoL AutoCine v5.9.1 — Montage Sequence Editor（ChatGPT/UI側）

Codex Cloudから取得した `codex/lol-autocine-v590-handoff` ブランチの `LoL_AutoCine` を基準にUI機能を追加した版です。GPU/Audio/TargetLock実装は編集していません。

## 新機能

- 中央の **シーン別ディレクター → モンタージュの再生順** に順序リストを追加。
- リストからシーンを選んで **▲上へ / ▼下へ**、またはリスト内を**縦ドラッグ**して並べ替え。
- 右のキル一覧の `#01`, `#02` がモンタージュ順を表示。右リストは従来の時刻順のまま。
- **シーン別演出ON**で作成した個別クリップ、モンタージュの連結順に反映。
- シーン別演出OFF時の従来の書き出し順・音声・GPU処理は変更なし。
- 順序の変更をプロジェクトJSONへ自動保存し、Undo / Redo、保存・読込に対応。
- プロジェクトスキーマはv2。従来のv1 JSONを読み込める（順序は検出時刻順）。
- 新たにスキャンされたシーンは順序リストの最後へ追加。チェック解除されたシーンは従来どおり除外。

## 実機テスト（Windows）

1. ZIPを**新しいフォルダ**に展開し `START.bat` を起動。スキャンして2〜3キルが表示されることを確認。
2. 「シーン別演出を使用」をONにし、「モンタージュの再生順」で2番目のキルを選んで「▲上へ」。右の一覧の#番号が変わることを確認。
3. リスト内でシーンを縦ドラッグして別位置へ移動。Undo → Redo → プロジェクト保存 → 再起動 → 読込で順序が保持されることを確認。
4. 「モンタージュ」ONで2〜3シーンをチェックして「チェックしたシーンだけ作成」。MP4個別クリップと結合モンタージュの再生順を確認。
5. 完成MP4の**カラー、LoLだけのゲーム音、同期、映像切れ**を確認。
6. 「シーン別演出」をOFFに戻し従来どおり1クリップ作れることを確認（新しい並び替えがこの経路に影響しないこと）。
7. トラブル時は `COLLECT_DIAGNOSTICS.bat` でログを収集して送付。
