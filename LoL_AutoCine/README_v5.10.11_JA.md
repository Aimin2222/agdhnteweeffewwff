# AutoCine v5.10.11 — 視認性・カメラ検証・自動診断

ベースはv5.10.10 Windowsフル版。GPU動画書き出し本体とLoL専用音声には変更を加えていません。

- 図鑑：実試合比較を幅833pxの大画面に拡大、クリックで追加拡大。
- カメラ：上の固定文言を廃止。選択モードとReplay APIから取得した実モードを区別して表示。
- カメラ校正：Replay APIの仰角2方式を安全に検出し、第三者視点のキャリブレーションを別スタイル間で共有。安全に判別できない場合は従来の誤認しやすいFPS風でなく安全俯瞰に切替し、理由をログへ残す。
- ミラー：開始ボタンと停止ボタンを分離。停止理由もログへ記録。
- キルフレーム：詳細ボタンが開いた状態を表示し、開いた詳細の位置まで移動。
- 素材：生成済みの透過フレームを追加し、合計21種類の素材スタイルを選択可能。既存の旧スタイルはすべて維持。
- アプリ内自動診断：`✓ 自動診断`、`RUN_AUTOTEST.bat`。報告は `diagnostics/selftest_latest.json`。

**制限**：Windows/LoLの実3D構図の「良し悪し」は録画映像で検証が必要。自動診断は実ゲームを勝手に操作しません。LoLのスキン自動判別は未実装で、テーマはキルフレームメニューから手動選択します。

PC用テスト項目は `TESTLIST_v5.10.11_JA.md` を参照。
