# 共通部品と旧ラスタ複合部品の内訳

これは表示部品を共有する仕様。配置コンテナの統一ではない。画面別の矩形・部品順を優先する。各画面の複合領域は同じ機能群を持つが、絶対座標と並びは原画に従う。

| 部品 | 構成 | 既存機能 | 状態を共有する候補 |
|---|---|---|---|
| SceneFocusCard | 行／サムネイル／時刻／種別／サイド | F06 | 全12。旧Aは表、新Dはグリッド、新Fはリボン |
| SceneOutputCheck | 行と独立したチェック／件数 | F07 | 全12。シーン選択とは別イベント |
| PreviewDock | 表示見出し／WGC表示面／演出再生停止／ミラー開始停止／実状態 | F08/F09 | 全12。親スクロールに入れない |
| CameraControlMode | 従来手動／固定自動／フルオート／既存維持の経路 | F10 | 全12。旧案の自動シネマ等の曖昧名は内部値を別途表示 |
| SideChoice | 自動／BLUE／RED | F10 | 全12。QA承認を兼ねない |
| CameraStyleTile | 画像／ラベル／選択枠とチェック | F11 | 全12。10内部キーを欠落させず全件入口を維持 |
| BoundNumericInput | ラベル／スライダー／値入力／単位／範囲 | F12/F17 | 全12。数値とスライダーの一方向コピーを禁止 |
| CatalogAssetCard | 原素材サムネイル／ID／品質ラベル／選択 | F13/F14/F15 | 全12。37バッジ、89原本、652候補を混同しない |
| MaterialPairApply | 枠選択／同名FX／個別FX／弱強／確認用使用／適用 | F14/F15 | 全12。枠の合格をFXへ継承しない |
| MotionChoice | 画像／instant,slide_left,slide_right,slide_up,slide_down,pop | F16 | 全12。6種を文字・選択枠でも識別 |
| EventTimeline | イベント行／現在位置／前後トリム／表示倍率 | F17 | 全12。4行は独立動画編集エンジンではない |
| SceneAdvanced | 保存／UndoRedo／コピー貼付／一括適用／順序／キーフレーム／色DOF | F18/F19 | 全12。主要画面にないものは同候補詳細で到達 |
| OutputControls | 対象範囲／件数／出力設定／作成／中止／進捗 | F23 | 全12。演出確認と実録画を別ボタンにする |
| Diagnostics | 実行状態／結果／警告／ログ／QA起動 | F24 | 全12。一括QAは動画作成を伴う |
| Appearance | ライト／ダーク／Windows追従／選択保存 | F25 | 全12。旧は基本設定、新は上バー |

旧画像の合成領域は画像からの再構成であり、内側全ピクセルを検出したベクターソースではない。旧の繰り返しシーンカードは画面別の原画寸法を基準に等間隔配置し、最終差分で1行ずつ照合する。見えない項目を全案共通の別配置へ置換して終えない。データカード数は実データに追従し、固定表示件数を本番へ持ち込まない。

CONTROL_ACTIONS.jsonが部品別の正規ファイル。各画面仕様にも部品ID・動作表を付けた。非対話の説明カードは表示部品であり、押せるように見せる場合は正規のモデル選択や候補内遷移を実装する。
