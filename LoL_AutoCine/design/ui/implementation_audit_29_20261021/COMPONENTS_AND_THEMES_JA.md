# UI部品・寸法・テーマ

全29の座標原本はSCREENS_29.json。新18はRESEARCH_MEASURED.jsonに全590部品と親パネルの実測値、CSS・computed styleを保持。旧11はLEGACY_RECONSTRUCTION.jsonに再構成寸法と原画から採取した中性色を保持。旧の字形・小さい生成文字・素材の内部描画は一意復元できない。画像未提供ではなく、編集可能な旧ソースが存在しないという制約である。

## 寸法の優先順
1. 対応原本の固定画素と画面ID。
2. 新18：同梱参照元HTML/CSSのcomputed bounds。共通スタイルより画面別の実測を優先。
3. 旧11：再構成矩形・部品値。過去の論理幅「目安」を原画座標の代わりに使わない。
4. 幅変更時のブレークポイント、旧の未定義小タブは派生仕様と明示。

新18の基本：Yu Gothic UI / Meiryo、本文16px・行高24px、補助14px、見出し20px、h1=26px、数値は等幅。外余白24px、パネル間16px、内余白20px、パネル角丸12px、通常操作角丸7px、操作境界1px、選択枠2px。通常ボタン40px、主作成CTA60px、チェック22px、数値入力74〜76px幅、スライダー列36px。個別カードは画面別JSONを優先する。

旧11は各画面component_contract_nativeを優先。標準本文16原画px、補助14、見出し22、入力72×34、タブ38、パネル角丸10、カード6、内余白16、間隔10、線1、選択線2が再構成基準。実装者が「本来のフォント値」として扱わない。1672→1920は約1.1483倍、T-B-Sの1672→1366は約0.817倍。縮小時は別途操作性を検査し、文字を潰して合格にしない。

## 固定とスクロール
外側クライアント領域は固定グリッド。左右のシーン／図鑑／インスペクタは独立スクロール。プレビューとその操作列はスクロール祖先に置かない。下部は外枠固定、内容だけ横スクロールまたはタブ。新A_cameraの下部数値は初期表示範囲外であり、右インスペクタをスクロールして到達する。画面外のDOM座標を最下部へ無理に詰めない。

新18のレスポンシブ：幅1550以下で余白16・間隔12、幅1150以下で一部補助表示を整理。高さ850以下で上バー64・サブバー52・フッター32、A/E詳細系下ドック142。正確な幅はui.cssと画面別実測値。1366×768の6枚はそのまま検査用基準。Windows125/150%は物理画素数とDIPを分け、同じDIPで検査してから実DPIを検査する。静止資料だけでは実DPI対応合格としない。

旧11の1920基準への変換は左右・上下辺を浮動小数で変換して最後に丸める。T-B-Sは原本1672×941、実装目標1366×768を別記。原本の名前から実画素数を決めない。旧候補が狭い時は同候補のタブ切替で維持し、新A/Eに切り替えない。原本のない幅の具体的な再配置は派生仕様であり、原画との一致判定とは分ける。

## テーマ
COLOR_TOKENS.jsonはライト／ダーク双方の全色を指定する。light / dark / systemの3値をappearance.modeに保存。現在のWindowsテーマがlight/darkでも保存値systemを勝手に書き換えない。表示用テーマだけを解決する。新画面はヘッダーのテーマ選択、旧画面は既存の基本設定→外観へ置き、原本のヘッダーを押し縮めない。

ライト：背景#EEF1F4、パネル#F8FAFC、段差#E4EAF1、文字#172B3E、補助#465A6F、操作枠#6C7D90、青#245FAB、選択背景#D7E6FC。
ダーク：背景#1B222B、パネル#252F3C、段差#2D3A4A、文字#EDF2F7、補助#B1C0D0、操作枠#8DA1B9、青#9BC6FF、選択背景#344D6B。
映像マット#30343Aは共通。映像・原素材にテーマの色変換や不透明度変更を掛けない。選択は枠＋チェック＋文言、無効は破線＋ラベル、警告はアイコン＋説明、合否は正式合格／確認用と文字表示。BLUE/REDも文字を併記する。

通常文字4.5:1、重要UI部品3:1を基準にする。同梱CONTRAST_AUDIT.csvは新トークンの60組を検査した記録であり、旧原画のすべての色や実装全体が合格した証明ではない。旧ライトは原画サンプルを保持し、低コントラスト箇所の修正が必要なら忠実版の差分とアクセシビリティ版の差分を分けて報告する。黙って色を統一しない。

## 状態保存
テーマとUI候補の選択はappearance/workspace設定として保存し、SceneProject・カメラ値と独立させる。テーマ変更はスタイル更新のみ。プロジェクト再ロード、カメラ再初期化、WGC停止、録画ジョブ停止、シーン再選択は行わない。再起動後も選択値を復元するが、録画開始など副作用は復元時に実行しない。

今回原本があるダーク版は新Aと新Eの2枚。他27画面の暗色化は派生実装。機能配置は変えず、色の対応と状態保存を別検査する。採用案を限定する理由にはしない。
