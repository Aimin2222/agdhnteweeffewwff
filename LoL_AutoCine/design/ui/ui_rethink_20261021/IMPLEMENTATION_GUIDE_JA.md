# 実装再現ガイド・配置契約
対象は採用前のUI設計資料。HTML/CSS/JSは閲覧・比較用で、AutoCine本体の実装ではない。

## 再現の基準と優先順位
1. 承認された案・画面・テーマをSCREENS.jsonで指定する。
2. その画面のPNGとHTMLを1対1で参照する。
3. 配置・文字・余白はui.css、RENDERED_LAYOUT.json、ELEMENT_METRICS.jsonを参照。
4. 色はCOLOR_TOKENS.jsonを使用。生成映像から色を拾わない。
5. 操作はFEATURE_MAP_JA.mdの既存接続先へ。表示層のために内部処理を複製しない。

全メイン、上位2案の明暗比較、追加画面を1920×1080で出力している。1920×1080は今回はPNGの実画素でもある。縮小版は1366×768の別キャプチャ。全体を縮小した画像ではなく、同じHTMLのレスポンシブ配置。

## 共通の寸法
単位は論理px。上部タイトル76、高さ64の作業ナビ、下部状態32。作業領域はその間に置く。外周余白24、パネル間16。パネル角12、部品角7〜9、内側余白通常20。サイズの値はui.cssと測定JSONを優先する。

- 本文16px / 行高1.5。補助14px、見出し20px、主要CTA19px。分類ラベル・非操作の状態注記のみ13pxを使用。
- 標準ボタン40px以上。主CTAは60px。小型画面のプレビュー操作は34px以上。
- チェック表示22×22px。行全体を操作対象にする実装が望ましい。キーボード操作とスクリーンリーダー用の名前を必ず付ける。
- 選択は色＋2px枠＋チェック／ラジオ／選択中文字。無効は破線＋理由文。警告・合格・エラーには文字と記号を付ける。
- 数値スライダーはラベル・トラック・74〜76pxの入力欄を一組にする。単位と既存の範囲を保持する。
- カードは同じ種類の中で同じ寸法に揃える。部品原寸の例はcomponents/、配置はELEMENT_METRICS.jsonを参照。

UIのCSSpxをTkのポイント数へそのまま渡すと大きさが変わる。100%表示ではYu Gothic UIの16pxを基準にし、Tkでは負のピクセルサイズ等、使用フレームワークの単位を明示して変換する。DPI変換は1箇所で行い、二重拡大しない。フォントの代替・OS描画による字形差と、レイアウト差は別に評価する。

## プレビューの最小サイズと縮小
推奨の確認領域は1366×768論理px以上。メイン6案はこのサイズでも出力して確認した。1920のメインで見える16:9映像は最小でも約748×421px。1366では最小がCの約491×276pxで、共通の下限目標480×270を満たす。A/Eは約597×336px。stageの幅・高さと、レターボックス内の実映像面の寸法は区別する。

- 幅1550以下：A/Eの左右列を細くする、素材は2列、補助表示を減らす。文字を全体縮小しない。
- 高さ850以下：上76→64、作業ナビ64→52、A/Eの下部を142にする。副レーンや補助説明を隠す。値・設定は保持する。
- 右設定、左図鑑・シーン、下の詳細表示だけが必要に応じてスクロール。中央ミラーと再生操作は外側の固定領域に置く。
- Cの下部動作表示、素材画面の下部サマリーは独立スクロール可能。固定映像を押し出さない。
- 1366より狭い／低い画面、Windows125%・150%の実機では、利用可能な論理領域を再判定する。本文サイズを削って詰め込まず、右設定をタブ・別ドックへ畳む追加仕様で対応する。今回はWindowsネイティブDPI動作までは検証していない。

## 状態と作業順
表示層は1つの編集モデルを共有し、Eの簡単作成、Studio、素材図鑑、テーマ切替でモデルを生成し直さない。

共有するもの：リプレイID、対象選手、選択scene_key、出力チェック、順序、カメラ設定、枠／FX、登場動作、前後秒数、キーフレーム、色、音声、出力設定、Undo/Redo、ジョブID。UIの仕事場名をプロジェクト設定の新しい内部カメラモードとして保存しない。

「演出を確認」は録画しない既存プレビュー、「ミラー開始」は表示用キャプチャ、「動画を作成」は既存の録画・出力処理。「カメラ＋Work素材一括QA」は動画と診断ZIPを作るため、録画なしと表示しない。

## 実装時に比較する検査
採用したPNG・テーマ・解像度を固定して以下を比較する。

- 主要パネルのx/y/幅/高さ：基準から±2pxを初期目標。OSの外枠を除いたクライアント領域で比較。
- プレビューの表示面、16:9維持、余白、再生操作の位置。画像がUIテーマで色変更されない。
- 全主要ボタン・カード・入力欄の寸法、文字サイズ、ラベル、選択・無効・警告状態。
- 長い日本語、最大の数値、素材名、未接続・未スキャン・エラーでも必須操作が欠けない。
- 左右・下部スクロール、簡単↔Studio、素材画面の切替で映像が消えない。
- フォーカスが見えること。色を除いても選択と品質状態が分かること。
- テーマ変更の前後で同じscene_key・値・ジョブ・再生位置・WGC表示元を保持。
- シーン選択と出力チェック、カタログ承認と使用許可、録画方針と実利用、目標Hzと実測fpsを混同しない。
- 指定の色組み合わせをCONTRAST_AUDIT.csvと比較し、通常文字4.5:1、主要部品3:1を再計算。
- 1366×768と、OSの100%・125%・150%を実機検証。今回のブラウザー出力をネイティブDPI合格と扱わない。

±2pxは採用後に双方で合意する検収目標であり、Tk/Chromeの全ピクセルが自動で一致する保証ではない。文字のアンチエイリアス差を許容する場合も、位置・余白・大きさの崩れを許容したことにはしない。
