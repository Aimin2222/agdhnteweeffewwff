## 推奨する製品構成
**E Flowを初回入口、A Studioを詳細の仕事場にする構成**を第一候補とする。

1. かんたん作成：準備状態と仕上がり、作成対象を確認して既存自動作成を開始。
2. Studio：同じプロジェクト・選手・シーン・設定のまま詳細を調整。
3. 素材選択：中央映像を残して図鑑へ。品質状態を維持。
4. システム設定：GPU、音声、HUD、録画、出力先、診断等をまとめる。

Fの「キル前・瞬間・余韻」は、採用後にStudio内の補助表示として検討できる。まず6種類の画面をすべて製品へ実装することは勧めない。ユーザーが採用案を選んだ後に実装範囲を固定する。

## 上位2案の追加画面
- A_main / A_main_dark：同じ配置・同じ入力値・同じ映像の明暗比較。
- A_camera：既存10スタイル、サイド、数値、手動承認の導線。
- A_frames：原本を参照する図鑑と6種類の登場動作。ミラーを残す。
- E_main / E_main_dark：かんたん作成の同一配置明暗比較。
- E_studio：詳細編集へ進んだ状態。既存機能への接続を想定。
- E_frames：簡単作成から素材を選ぶ状態。

A/Eの素材画面は同じ共通部品を使う。これは品質状態・操作を学び直さずに済むよう意図的に揃えている。6つのメイン画面は異なる配置・作業順になっている。
