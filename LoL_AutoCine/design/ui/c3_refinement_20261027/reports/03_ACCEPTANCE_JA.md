# 実装後の比較審査 / 今回の検証範囲

Workは静止画像と寸法・参照関係の検査を担当しました。LoL実接続、実アプリのクリック/スライダー、設定保存、Undo、GPU、音声、録画、DPI、WebView2はNOT_RUNです。画像の見た目から実動作成功と判定しません。

| 段階 | 合格条件 | 今回 |
|---|---|---|
| 静止資料 | PNG12枚の寸法、JSONの座標、同テーマ対の配置一致 | QA_RESULTS.json参照 |
| 画像再現 | 同一論理解像度でパネル位置/サイズ±2px、余白±2px、文字サイズ±1px | NOT_RUN（Codex実装待ち） |
| 再現画像比較 | 合成見本を同一画像に固定してUI部分のみ差分重畳。文字AA/ゲーム動画は別に評価 | NOT_RUN |
| 操作 | すべての見える操作の接続先・無効理由・キーボード操作を確認 | NOT_RUN |
| 状態維持 | 選択シーン/出力チェック/キー/TargetLock/プレビュー時刻がビュー・テーマ切替で保持 | NOT_RUN |
| ドラフト | 適用/キャンセル/Esc/閉じる/別シーンへの移動で意図した状態だけが変化 | NOT_RUN |
| 数値・キー | 手動48°と選択キー64°を混同せず、編集してUndoできる | NOT_RUN |
| 実接続 | Replay/10人取得、BLUE/RED、スキャン・実カメラ・ミラー、失敗時の正しい表示 | NOT_RUN |
| 出力 | チェックしたシーンのみ、ジョブ重複なし、NVENC/CPU、LoL音声の実結果 | NOT_RUN |
| 素材 | 37/89/652/35と6アニメの接続、確認用と正式承認を区別、承認ファイル不変 | NOT_RUN |
| DPI/狭幅 | 100/125/150%で固定ミラー・フォーカス・各パネル内スクロール | NOT_RUN |
| 配布 | 信頼できるソースとビルド、Defender等の実結果と必要な正規手続き | NOT_RUN |

実装審査で重大なレイアウト逸脱/既存機能の欠落/誤録画/状態消失/承認状態変更はFAIL。視覚的な好み・新しい配色の採用はREVIEWでユーザーが判断します。PASSは検査した項目に限定します。

回帰試験例：シーンAのFOV48手動→キー1秒40/5秒64/10秒48を設定→5.5秒へ移動→テーマ変更→C3-S→C3-P→対象・キー・時刻が保持→素材を一時選択してキャンセル→既存素材に戻る→A/Cのみ出力チェック→未接続で作成開始しない。実LoL接続できる環境で同じ操作を再実施します。

研究の残件P2素材523件、暫定肖像枠651件、原本制約19件、LoL/GPU/音声/DPI検証は継続残件です。今回のUI設計で解決・承認済みへ変更しません。
