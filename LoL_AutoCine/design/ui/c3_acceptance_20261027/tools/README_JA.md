# 画像比較補助ツール（任意・Codex用）

PythonとPillowを既に利用できる検証環境で、compare_screens.pyへ --expected 元PNG --actual 実装PNG --out 結果フォルダー を指定します。任意の --masks は可変映像/時刻の除外矩形リストJSONです。入力は同じピクセル寸法に限ります。無断で縮小拡大しません。

出力：50%重畳、RGB差分、比較範囲マスク、数値JSON。同一画像でもREVIEWで、実機受入PASSにはしません。フォントや配置の測定、操作確認、ユーザーの好みは別途記録します。PNGだけを読み、アプリ起動・ネットワーク・ブラウザー操作・設定変更はしません。

この.pyはGitHubの検証用研究ソースのみです。静止資料ZIPには含めません。Pillowを導入/実行する必要がある場合はCodex側の検証環境で判断してください。今回のWorkは付属の合成PNG自己試験だけを行いました。
