# LoL AutoCine 現行テストUI改善モック
更新日：2026-10-20。対象は v5.10.32-test、参考ブランチ codex/camera-effects-integration-20261019、固定コミット feb895491ca4bc780da4aab91990f25177cd35ab。今回は既存テストUIの配置改善。過去の全面リニューアル8画面とは別の納品であり、アプリへの実装は含まない。

## 比較
| 案 | 配置と目的 | 長所 | 短所 |
|---|---|---|---|
| A 現行UI整理型 | 上段は左準備・中央ミラー・右検出シーン、下段は詳細編集 | 現行の操作位置を覚え直す負担が少ない。移行範囲を絞りやすい | 下段に詳細項目が集まり、カメラと素材を行き来しやすい |
| B テスト特化型・推奨 | 左シーン、中央固定ミラー、右カメラ／キル演出、下段タイムラインと結果 | BLUE/RED・モード・素材の状態を映像と照合しやすい | 左右の役割変更が必要。狭い画面ではタブと折りたたみが必要 |
| C 初心者カード型 | 左に準備とシーン、中央ミラー、右に4種類の選択カード | 選択結果と次の操作が分かりやすい。詳細編集を後から開ける | 多数の数値を同時比較するテストではBより手数が増える |

推奨はB。画像選択カードの分かりやすさはCから取り入れ、Aは移行負担を抑える比較案とする。

以下は論理キャンバスでの実装用配分。PNG上の正確な測定座標ではない。PNGは生成原寸を維持し、実画素数はMANIFEST.jsonに記載。1920×1080／1366×768への再サンプリングを実施したという意味ではない。

ミラーは左右・下部ScrollFrameの外に置き、左右だけ独立スクロール。中央は列幅に合わせて16:9を維持してレターボックス表示。上記幅は余白込みの目安で、プレビュー全体が指定幅・高さに必ず一致する保証ではない。上下の分割比を変更しても再生・停止をミラー直下に固定する。

1366×768は現行root.minsize(1280,780)のままでは収まらないため、新規レスポンシブ提案。右はカメラ／キル演出タブ、下はキル選択／詳細／テスト結果タブで一度に表示する量を減らす。本文14〜16論理px、主要操作36px以上を目標。Windows125%／150%表示では有効領域を再判定し、必要なら縦配置や別ウィンドウを用いる。静止画像ではDPI対応を検証していない。

## 各部品の機能
| 部品 | 配置・動作 |
|---|---|
| ヘッダー | リプレイを開く、準備、簡単／詳細、GPU・音声・HUD等の設定、ログ、出力設定、動画作成への導線 |
| 対象選手 | 準備領域でTargetLockの実際の対象を表示。BLUE/REDを味方／敵の固定概念にしない |
| スキャン | 接続・10人取得・試合全体スキャンの既存一操作を維持。キル／アシスト／両方で絞る |
| シーン一覧 | 選択行と出力チェックを別状態にする。選択、ジャンプ、全選択、解除、選択／チェック分／全検出作成への導線を保つ |
| ミラー | 設定目標144Hzと実測FPSを別表示。実測未取得は「—」。画像は表示例であり実機144fpsの証明ではない |
| 再生・停止 | ミラー開始／停止と、LoLでの演出プレビュー再生／停止を分離。演出プレビューは録画しない。動画作成は出力設定と別の操作 |
| カメラモード | 既存設定を維持する選択肢を残す。従来手動／固定視点＋自動構図補正／フルオートシネマを既存値に対応付ける |
| カメラサイド | 自動・BLUE・REDを既存のサイド設定へ接続。確認済み候補の承認は別の明示的な手動操作 |
| カメラ選択 | 既存10スタイルへの画像ボタン案。主な4スタイルと全スタイルへの導線を用意 |
| 数値 | 既存スライダーと同じ変数を入力欄で共有。距離500〜1400、高さ0〜900、Yaw−180〜180、回り込み0〜45、ドリー0〜15等の既存範囲を維持 |
| 素材 | 既存37バッジとWork枠652候補を別タブ。枠は正式合格1・確認用651、FXは35点すべて確認用。枠の合格を同名FXへ継承しない |
| 図鑑 | 検索・状態・スキンテーマ／地域モチーフ／基本案の分類、テーマフィルター。地域は素材モチーフでありチャンピオン出身地ではない |
| 適用 | 同名FXを枠と組で選択。個別FXは詳細に残す。未合格を使用するチェックは品質合格操作ではない |
| 登場6種 | instant／slide_left／slide_right／slide_up／slide_down／pop。日本語は一気に表示／左から登場／右から登場／下から登場／上から登場／パッと飛び出す |
| pop | 現行は横方向の減衰位置ずれ。拡縮・回転・フェード・グリッチ等を既存機能に追加して描かない |
| タイムライン | キル選択のイベント行は新規UI案。既存SceneTimelineの前後トリムとは分ける。前後1〜15秒・0.5秒刻みを維持 |
| 詳細編集 | シーン保存、Undo/Redo、コピー・貼付、全チェック適用、順序、キーフレーム、色、FX、出力、プロジェクト保存読込を既存経路で維持 |
| テスト | 既存のカメラ＋Work素材一括QAは動画と診断ZIPを作成する。録画なしのプレビューとは異なる。モックは未実行／未確認。集約結果パネルは新規UI案 |

## 実装されていない部分
画像選択によるインライン統合、キル選択タイムライン、テスト結果の集約パネル、1366×768の再配置は新規UI提案。画像内にも新規UI案を付ける。既存ハンドラーがあっても新しい配置・連携が実装済みという意味ではない。

フルオートはサイド別に実機QA承認された候補からクリップ境界で選ぶ既存仕様。未承認候補を自動合格にしない。候補なしは既存固定視点へのフォールバックを維持し、リアルタイムに新しい世界座標を推定する機能を提案しない。

## 保持する全設定の導線
簡単／詳細を切り替えても同じ変数・プロジェクト状態を共有。未表示タブや折りたたみ中の値を初期化しない。カメラ詳細、TargetLock、HUD、色・DOF、音声・ゲーム音・BGM、GPU、録画、出力FPS・フォルダ、参考動画／テンプレート、キーフレーム、シーン別上書き、モンタージュ、診断・ログは既存機能への導線で保持する。カードは設定を隠して整理する表示案であり、機能削除ではない。

## 品質確認の範囲
日本語主要ラベル、配置、固定プレビュー、操作の区別、素材承認状態、新規UI表示を制作側で目視確認。生成されたゲーム映像・人物・枠・FXの小画像は説明用で、既存原本や合格素材そのものではない。実装時は必ず原本のカタログIDと実際のサムネイルに置換する。

アプリ起動、カメラ実機テスト、GPU計測、録画・音声・書き出しは今回実施していない。アプリコード、89原本、37バッジ、652候補、エフェクト素材は一切変更しない。
