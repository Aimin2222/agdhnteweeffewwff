# League Director参考版 / R1 Track Desk

これはWorkが制作したAutoCine独自の参考UIです。他社アプリの忠実コピーや本体の同梱ではありません。ファイルは LD_ 接頭辞です。

## 候補3と違う骨格

左の縦シーン一覧、中央固定ミラー、右インスペクタ、下の常設トラック。候補3の左準備/右シーンへ並べ替えない。

## 画面別の機能と導線

| 画面 | 置く操作 | AutoCine接続項目 | 誤接続を防ぐ条件 |
|---|---|---|---|
| メイン | 準備/接続状態 / シーン焦点/チェック / 現在カメラ/FOV/音声/件数の概要 / 構成を作って確認 / 比較 / 再生/停止 | REPLAY, LAUNCH, PLAYER, SCAN, ASSIST, SCENE, MIRROR, PREVIEW, JOB | デモの合成5シーン/12秒を実スキャンや実LoL成功として表示しない |
| かんたん | カメラ3候補 / 自然/暖かい/涼しい / キル演出3候補 / 細かく調整する | FIXED, FULL, GRADE, WORKFRAME, WORKFX, MOTION, JOB | カードは既存能力へのプリセット。未実装処理を生成しない。数値変更後はカスタムと表示 |
| 詳細編集 | キー時刻 / FOV値 / 次キーへの補間 / 追加/削除 / キー適用 / 下部タイムライン | KEYFRAME, TIMELINE, SCENE, MULTI, SMARTMONTAGE | 画像でFOVだけ編集可。Yaw/Zoomの既存接続は別確認。XYZ/自由接線がある証拠にはしない |
| カメラ | 既存/固定自動/フルオート / 自動/BLUE/RED / 既存スタイル選択 / FOV/Yaw/距離/高さ / TargetLock | PLAYER, FIXED, FULL, FOG, DOF | 画面で状態保存できたことと実カメラ送信は別。採用済み三人称斜め後ろを維持 |
| カーブ | 選択キー / 時刻/値 / linear/smooth/hold / 追加/削除 / キー適用 / 手動FOV | KEYFRAME, TIMELINE | smoothは自由Bezier接線と同じではない。手動FOV48と選択キー64は入力元が別 |
| 色調整 | ニュートラル/ウォーム/クール / 露出/彩度/暖かさ / 比較ON/OFF / 比較位置 | GRADE | CSS近似をLUT/GPU色処理の完成と扱わない。UIテーマは映像グレードと独立 |
| 素材 | 自作見本3枠 / FX見本3候補 / FX強度 / 登場6種 / 正式/確認用の実カタログ入口 | BADGE, WORKFRAME, WORKFX, MOTION, REFERENCE | 図形のライン/リング/ツインは正式素材IDではない。652/35を3種類に削減しない |
| 出力 | 研究JSON保存（プロジェクト保存） / 解像度/fps/encoder方針 / ゲーム音/HUD / 実動画作成 / 結果/ログ | JOB, RECORD, AUDIO, AUDIOGUARD, NVENC, HUD, DIAG, SELFQA | JSON保存はMP4作成ではない。GPU方針autoと実使用NVENCを区別。結果/診断の詳細入口は追加接続提案 |


専用のcamera/color/materialだけで不足する詳細機能は、同じ右インスペクタ内の詳細セクションへ接続します。新しいトップレベルタブや別UIへ勝手に置換しません。全70項目の個別接続はFUNCTION_MAP_210.jsonにあり、表に省略した各カメラスタイル・CoreFXも列挙しています。

カメラの入口はカメラタブ、数値/キーは詳細編集・カーブ、素材は素材タブ、色は色調整、書き出しは出力です。テスト結果は出力の結果詳細と右上設定→診断に付随させる追加提案。原画には候補3のようなテスト結果タブはありません。追加提案を原画に存在する部品と偽りません。

R1/R2原画のメインにはROFL専用ボタンがありません。右上設定→リプレイ準備/対象の詳細ペインを追加して接続する提案です。「保存・開く」はプロジェクトの保存/読込であり、ROFLを同じパーサーへ渡さないでください。既存ネイティブ機能の専用アダプターを使います。

初心者の入口は「かんたん」。カメラ/雰囲気/キル演出の少数カードを選んでプレビュー、出力へ進みます。詳細を開いてもショット/キー/TargetLock/時刻を保持します。図形サンプルの3種類はカタログの削減を意味しません。

初心者が難しい点：キー/トラック、サイド・カメラスタイル、相対時刻とリプレイ絶対時刻の違い。右の「かんたん」から始められる。

Codexが誤解しやすい点：トラックが複数あるからXYZ全軌跡を編集できる、あるいはLeague Director本体を埋め込んでいると考えない。


画像のLoL未接続/合成プレビューは研究時の正直な状態表示です。製品接続後は実状態に差し替えますが、未接続なのに文言だけ消して成功に見せないでください。保存/テーマ/状態操作ができた過去のデモ試験を、今回の実LoL/GPU/音声/MP4の成功証拠に流用しません。
