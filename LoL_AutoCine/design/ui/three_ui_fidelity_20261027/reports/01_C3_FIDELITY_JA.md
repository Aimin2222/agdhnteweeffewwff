# 候補3の忠実再現判定

ユーザーが指定したのは番号だけでなく **testA / T-A-M / 旧テストAの原画像の見た目・構成・パネル配置・情報密度** です。候補3を基礎にすることは今回の明示方針として扱い、C3-P/Sや現在のBAT版の構成を代替基準にしません。R1/R2は別UIとして実装します。本体への正式統合やmainマージは別工程です。

原本は1672×941、SHA256 b05abe6a04732069729abd58fc4e7aca3b09c19e8d2703c5d9af3e5a5ed01a13。L03-Nは候補2、R-A-mainは新A Studio。原画像のある正本フォルダーとPR51証拠はSOURCE_OF_TRUTH_JA.mdを参照してください。

## 候補3と認めるためのゲート

| ゲート | 必須条件 | 失格例 |
|---|---|---|
| G0 識別 | testA/T-A-Mと指定PNGに結び付く | 別の案3やC3-P/Sの画像を参照 |
| G1 構造 | 左準備・中央ミラー・右シーン、下部編集/素材 | R1の左シーン/右インスペクタへ入替 |
| G2 同時表示 | ミラー、シーン表、下段タイムライン・カメラ・素材が同時に見える | メインをプレビューと数カードだけに簡略化 |
| G3 密度 | 10人/12シーンのフィクスチャで原画相当の情報が見える | 原寸で表を5枚の巨大カードに置換、数値を全隠し |
| G4 配置と文字 | パネル/操作列/タブ/数値/素材が原画の関係を維持 | 余白の都合で素材を下段から消す、下段を丸ごと別ページへ |
| G5 機能と状態 | 全機能の導線、実状態、未対応理由が正しい | 演出確認で録画、未接続を成功表示、確認用を承認表示 |

G0〜G5にFAILが1つでもあれば「候補3忠実再現として合格」としません。未試験はNOT_RUN、目視で未決のものはREVIEWです。平均点で重大な欠落を相殺しません。見た目の合格とLoL実接続の合格も別です。

## 数値による比較

主パネルの基準矩形はC3_FIDELITY_CONTRACT.jsonのregions、主要ボタンはnative_button_anchorsです。矩形は原画左上基準のx,y,width,height。1920×1080へ換算する際はX×1920/1672、Y×1080/941を明示します。OS外枠/影を勝手に足し引きせず、原画内の青いタイトルバーも比較対象です。Windows側の二重タイトルバーを避け、どこがクライアント領域か証拠へ記録します。

目標は主要辺±2原画px。手計測の不確かさのため2〜8pxはREVIEWとして重畳確認し、8px超は測定基準の誤りを除いてFAIL。旧資料の±8pxを無条件の合格幅にしません。主要文字サイズは同じ大きさを目標とし、測定後の±1px差を確認。元フォント名を厳密に復元したとは主張せず、画像上の大きさ・太さ・折返し・行高と密度で確認します。

原画の左右幅は約20.2%/23.9%、中央パネル約53.9%。C3-P/Sの320/1176/376の幅を原本の幅と誤認しないでください。映像面はpreview-stageに16:9 containし、画像中のゲーム画角を実カメラへ強制しません。原画にある895×492の外側領域と、その中の874.67×492の16:9映像面を区別します。

可変のゲーム映像・実アイコン・時刻・件数は内容差の除外を許しますが、枠・タブ・ボタン・承認印は除外しません。映像を黒く塗り広げてUI差分を隠すことは禁止です。文字AA差だけを過度に採点せず、情報の消失を優先して検査します。

## 変えてよいもの / 事前合意が必要なもの

実データに応じた名前・試合情報・選択状態・時刻・件数・素材画像、版番号、表示例/未接続の説明文は実状態に合わせて変えます。原画の900/420/14°や144Hz、フルオート選択を製品の強制初期値にしません。状態依存の無効表示は理由を付けます。

余白・配色・列幅・行数・タブ・主要操作位置・表示の省略は、候補3の忠実再現とは別の変更です。ユーザーの合意なしに「見やすくした」として変更しません。ライト/ダークは共通要件ですが、原画ライト版の一致を先に判定し、ダーク派生をライト原本の代わりにしません。

1366×768の候補3原本はありません。B_1366x768やC3-P/Sの狭幅版を候補3原本にすり替えません。狭幅は別途アダプテーションとして記録し、同じ3カラムの役割・常設ミラー/タイムライン・素材入口を保ち、パネル内部のスクロールで到達可能にします。一括ビットマップ縮小やフォントだけの極小化は不合格です。
