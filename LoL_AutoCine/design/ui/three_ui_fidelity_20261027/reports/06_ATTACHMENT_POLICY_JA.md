# 既存・類似・新規機能の付随方針

画面ごとの配置は別にし、機能の意味と状態モデルだけを共通化します。3UIの見た目を一つへ寄せません。

| 機能の対象 | 候補3 | R1/R2 |
|---|---|---|
| Replay/対象/準備 | 左上/左一覧、上の準備 | 右上設定内の準備詳細（追加接続案） |
| シーンの焦点とチェック | 右表と下のキル選択 | R1左のシーン列、R2下のショット列と対象チェック |
| 実カメラ・環境 | 下段カメラ/対象/数値とカメラ詳細 | カメラの右インスペクタ |
| キー/トリム/時刻 | 常設タイムライン、下段詳細 | 下部トラック＋詳細編集/カーブ |
| CoreFXとグレード | 色・FX | 詳細編集のCoreFXセクションと色調整を分離 |
| 枠・WorkFX素材・6登場 | 下段素材と図鑑 | 素材インスペクタと実図鑑 |
| 録画/MP4/音声/GPU | 上部/右下の作成＋下段出力/設定 | 出力と右上設定 |
| 結果/警告/診断 | テスト結果とログ | 出力の結果詳細/設定の診断（追加接続案） |

似た操作をまとめてよいのは、同じcapabilityId・対象・単位・副作用・保存モデルを使う入口だけです。共通ボタンコンポーネントは使えても、ゲーム内Fogと後処理ぼかし、素材FXとCoreFX、保存とMP4作成、焦点とチェック、ミラー停止と録画停止、カメラサイドと色テーマは統合しません。

ProjectStoreにproject/revision、focusedSceneId、checkedSceneIds、TargetLock、camera/keys/grade/assets、previewTime、audio/output、Undo履歴を保持し、3UI切替で初期化しません。3UIへの切替は比較版の共通選択入口から行い、個別画面の原本の列構造を変えません。

選択中ショットの値とジョブ開始時スナップショットを分離。カードやスライダーを触っただけで録画を始めない。途中のドラフトは適用/キャンセルを明示し、別ショットへ移る際に誤適用しません。明るい/暗いテーマはUIだけに適用し、LUTや映像の色を変えません。

未実装なら能力を無効＋理由表示にします。ENGAGE/BESTSHOTは以前の監査で未実装、FULLは部分実装です。説明の導線を残すことと、その機能が動作することは別です。似た既存機能を実行して代わりに成功扱いしません。

完全新規の能力は「新規提案」として親タブ・入力データ・結果・失敗・Undo・保存・テスト条件を添えます。ユーザーの判断とCodex実装の工程を残し、今回の調査中に本体へ混ぜません。既存37/89/652/35の素材や承認状態は変更しません。
