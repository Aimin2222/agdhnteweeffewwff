# 2つの参考UIの試し方
1. ZIPを全展開し `体験版を起動.cmd` を開く。
2. 上部R1/R2でレイアウトを切り替える。同じ研究プロジェクトを共有する。
3. R1では左のシーン、R2では下のshotstripで焦点を選ぶ。出力対象のチェックは別。R2のチェックは「対象チェック」から変更する。
4. カメラでFOV数値/sliderとAUTO/BLUE/RED等を変更する。距離/高さ/style/modeは状態保存のみで、LoLの3D計算は行わない。FOVとYawは合成ステージの表示へ近似反映する。
5. カーブで点を選び時刻/値/補間を編集。「FOVキーをプレビューへ適用」で補間を表示する。キー追加で現在FOVを記録。FOV slider直接編集はベース値の表示へ切り替わる。
6. 色調整でpreset/露出/彩度/暖かさを変更し分割比較する。CSS近似なので、製品LUTやGPU色管理の検証ではない。
7. 素材は自作図形見本。既存652/35/37/89へ書き込まない。6motionは既存名を維持した近似表示。
8. 保存・開くで研究JSONを保存/読込。実動画作成ボタンは未接続のため無効。設定と診断で自己テスト/ログ/画面撮影を実行できる。

プロジェクト・シーン別設定・キー・出力方針・外観は専用localStorageへ保存する。再起動時は停止状態。保存領域に書けない場合は通知しJSON保存を利用する。保存先はこのパッケージの `_session/webview2` 等で、本体設定とは独立。ネットワーク/音量/OSテーマは変更しない。

点は左右矢印で1/30秒・上下で1°、Enterで選択。Ctrl+Z/Ctrl+YでUndo/Redo。Escでdialogを閉じる。native入力の網羅試験は未実施なので、問題があれば操作順と設定を研究ログへ保存して比較する。

`QAを実行.cmd` は合成fixtureを使う独立QAモード。既存プロジェクトを使わず `_session_qa` と自作screenshotsへ結果を書き、終了する。これは手動pointer/keyboard試験の代わりではない。
