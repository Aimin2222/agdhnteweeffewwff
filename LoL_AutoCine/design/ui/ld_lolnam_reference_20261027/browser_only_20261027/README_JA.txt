AutoCine R1 / R2 ブラウザー体験版

ZIPを「すべて展開」し、index.html を通常のブラウザーで開いてください。
このフォルダーには EXE / DLL / CMD / BAT / PowerShell / インストーラーを含めていません。
R1 / R2、画面切替、スライダー、キーフレーム、色調整の近似、設定保持を試せます。
Windows WebView2ホスト専用の撮影機能は使えません。JSONの保存はブラウザーのダウンロードになります。
LoL・録画・GPU・音声・実動画出力は未接続です。

元のWindows版ZIPは、このPCのWindows保護機能により「ウイルスまたは望ましくない可能性のあるソフトウェア」として読み取りをブロックされました。
誤検知かどうかは未確認です。保護機能を解除したり、除外登録したり、隔離ファイルを復元する手順は行っていません。
この版は元のZIPを改名したものではなく、ネイティブ実行ファイルとSDKのDLL等を除外した別の配布物です。

既存混合案7＋4・比較3/5/8・本体・正式素材は変更しません。
