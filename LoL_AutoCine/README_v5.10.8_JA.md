## 基準
- Codex GPU開発の最新版 \`codex/lol-autocine-v5107-mirror-test-handoff\` をベースとした追加修正版。
- **GPUフル書き出しのコア実装には変更を加えていません**。
- 既存のTargetLock・レッドサイドカメラ・音声・HUD・1080p・シーン編集を維持。

## 追加・変更
1. キルログ金色装飾: ユーザー提供画像を**完成イメージとして参照**し、透明レイヤーにオリジナルの二重金枠・ベベル・広域グロー・角フレア・光筋・粒子風ポイントを描画。ゲーム中のキラー/相手の肖像アイコンは個別の実際のキャラを動的に表示する。スクリーンショットそのものを貼り付けた固定画像ではありません。
2. 中央マーク: 新規「ロイヤルゴールド紋章（参考画像風）」「LoL風・撃破エンブレム（オリジナル）」、中央なしの3方式が主力。旧設定は引き続き読み込み可。
3. 発光: オフ / ゴールド / ネオン。色・枠色・強さ(0-2)・角の光(0-2)・重ね表示間隔(0-36px)を個別指定。既存の色入力も利用可能。
4. A「かんたん編集の色見本カード」: 折りたたみ式。コンパクトに色調とカメラの違いを確認・適用できる。
5. B「全テンプレート図鑑」: 上部テンプレートナビから開く独立ウィンドウ。検索、テンプレートごとの色補正サンプル画像・色タグ・カメラ・エフェクト・適用ボタンを備える。A/B両方実装し、今後選択可能。
6. カラーグレード: デフォルト（無加工カラー）、Lolnam風、ドラマ、フェード、高コントラストなどを追加。従来の標準/フィルム/アイスブルー/シネマゴールド/ネオンも維持。
7. テンプレート選択時、同じカメラ・カラー・FX変数がミラー側にも適用。編集時だけの低解像度モードを外して、**画面上のミラー表示領域の解像度**で合成する。

## プレビューに関する正確な区別
- ミラー上のカラーやDOF表示: Python/PILで合成するリアルタイム近似映像。現在のCodex GPU Full **動画書き出し**とは処理経路が異なります。
- 書き出しと厳密に同じフィルタに近い静止画は既存の「1枚だけ更新」を利用。GPUミラーパス完成とは表示しません。
- 参照画像の肖像は見本。キルログにはLoLプレイヤー名を照合して公式チャンピオン肖像アイコンを動的に読み込みます。

## Windowsでのユーザーテスト（まとめて実施）
1. ロイヤルゴールド・キルログを選択し、同じキルの発光 0 / 0.6 / 1.4 / 2.0 を比較。角の外まで光が伸びるか確認。
2. 「ロイヤルゴールド紋章」「LoL風撃破エンブレム」「なし」を比較。キャラ×キャラの間が上品か、アイコンが正しいか確認。
3. 2キル・3キル連続シーンで、縦表示と行間調整（0, 12, 30px）を確認。
4. かんたん編集の「A：色見本カード」を開く。カード上の色サンプルから適用できるか確認。
5. 上部「テンプレート」から「B：全テンプレート図鑑」を開く。見本画像・検索・適用を確認。どちらの画面が使いやすいか選んでほしい。
6. 「デフォルト」から「シネマゴールド」「アイスブルー」「ネオン」へ変更し、ミラーON・FXをミラーに反映ON・▶再生で色が切り替わるか確認。
7. 出力1080p・LoLゲーム音・TargetLock・レッドサイドカメラ・キル＋アシスト検出が以前どおり動くか確認。
8. Codex側のGPU書き出し診断ログで、GPU使用パスが想定どおりか確認。

問題があれば完成MP4と AutoCine_Diagnostics.zip を添付してください。
