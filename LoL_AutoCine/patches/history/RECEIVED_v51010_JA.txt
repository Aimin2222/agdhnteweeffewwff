LoL AutoCine v5.10.10 - Codex統合用の変更ファイルとパッチ

ベース：LoL AutoCine v5.10.9（キルフレーム素材追加版）

推奨：v5.10.9のソースをブランチ化してから
  git apply --check v5.10.10_from_v5.10.9.patch
  git apply v5.10.10_from_v5.10.9.patch
で適用してください。

CHANGE_FILES/には同じ変更ファイルが入っています。
パッチを適用済みなら、CHANGE_FILES/を上書き適用しないでください。

既存Codexブランチ側で未取り込みのGPU処理がある場合、
core/jobs.py、core/effects.py等のGPUコアは今回変更していません。
競合した場合は変更箇所を手動で比較して統合してください。

今回の主な変更点：
- UI：実キル/アシストフレームを選んで色/FX比較するテンプレート図鑑
- UI：キルフレーム詳細の折りたたみ、発光スライダー・弱/標準/強
- UI：ミラー未再生案内の中央位置修正
- キルログ：豪華PNG素材も発光量に対応、385x116の正しい出力サイズに調整
- 既存自動テストの仕様更新および新規回帰テスト
