# LoL AutoCine — A/B/C/D キルフレーム実装引き継ぎ (ChatGPT担当)
更新: 2026-10-13 / 基準: v5.10.26-test / Codexエンジンと衝突しない独立ブランチ

## 絶対条件
- A: シンプル / B: 高級感 / C: シネマ / D: スキン・出身テーマ
- Dはここで作成した**実際のコンセプトPNG画像のピクセル**を素材として切り出す。名前だけを付けた抽象図形で代用しない。
- チャンピオン肖像はゲームから取得した実際のキラーと被害者のアイコンを左右に配置する。
- 余分なx1、テキスト、ロゴは**動画内のフレームには描かない**。説明文章・テーマ名は設定画面のみに表示。
- Dには装飾弱め/強め、近接/遠隔/ハイブリッド、テーマ固有の登場FXを付ける。
- 既存37種類・現行保存データ・TargetLock・録画・音声・GPUを壊さない。
- 最終統合、FFmpegへの接続、GPUによる登場FXの動画化、Windows ZIP生成はCodex担当。ChatGPT側は画像素材・UI・テンプレート担当。

## 正式な素材取り込みルール
1. ChatGPTで生成済みの画像ファイルを元のピクセルのまま`LoL_AutoCine/assets/kill_concepts/`へ配置。ユーザーの非公開素材は勝手にpublicリポジトリへ上げない。
2. `THEMES`の`source_file`と実ファイル名を照合し、生成画像のライセンス・公開範囲をチェック。
3. PNGから装飾部分を抽出する際は、参照画像内のサンプルキャラクターの顔を透過させる。左右には実プレイヤーアイコンを後から合成。
4. `extract_original_motif`で素材化、白フチ残り・背景混入・切断がないか実画像で目視評価。
5. 必要に応じてフレーム枠、背景、中央装飾の3レイヤーに手作業で分け、元の画像の装飾・材質・配色を守る。
6. 選択UIは既存キルフレーム一覧にA/B/C/Dタブを追加。D内はカテゴリ・テーマ・装飾弱/強・近接/遠隔/ハイブリッド・登場FXのプレビューを設定。
7. 既存`core/kill_icons.py`、`legacy_app.py`、`core/jobs.py`の共有編集は事前の差分レビューと担当調整が必要。
