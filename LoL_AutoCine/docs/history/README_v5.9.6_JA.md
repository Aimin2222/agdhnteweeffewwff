# LoL AutoCine v5.9.6 — HUDプリセット / チェック済み一括設定

v5.9.5をベースに、Codex版の統合を待たずにChatGPT側で進めた更新です。

## 追加・改善

### HUDを3択に整理
- **すべて非表示（シネマ）**：UIとHPバーを隠す従来の設定。
- **体力バー中心（名前はLoL設定）**：Replay APIの既存HUDフラグでチャンピオンのHPバーを残し、その他のUIを隠す設定。
- **通常HUD（ゲーム内表示のまま）**：HUDを変更せず、LoLで表示している状態をそのまま収録。

「かんたん編集」と「詳細編集 → 出力」のどちらでも切り替え可能。設定は保存され、再起動後に復元されます。UIが二重に異なる状態にならないよう共通変数にしました。既存のテンプレートにある `hide_hud` / `keep_champion_bars` フラグとの互換性も維持しています。

**重要：名前の非表示そのものはAutoCineが自動設定しません。** LoLリプレイ側のインターフェース設定で、体力バー上の名前の表示を「なし」にしてください。項目名はLoLのバージョンで変わる可能性があります。ミラーで名前が消えているか事前確認をしてください。自動で名前を消せると保証するUIにはしていません。

### シーン設定の一括適用
「詳細編集 → シーン → ☑ チェックした全シーンに適用」で、現在選択中のシーンの**未保存の編集値**も含め、チェックが付いた複数シーンへ適用します。確認ダイアログあり。**1回のUndoですべて戻せます。** 実際の書き出しに反映する既存のシーン別演出モードを自動的にONにします。

### 診断ログ
作成開始時のHUD状態をログに表示します（体力バー中心・シネマ・通常HUD）。

## 変更していない部分
- Replay APIのカメラ座標系、OrbitTargetLock、カメラ時計
- クリップの録画・エフェクト・GPU処理本体
- Windows Native Process LoopbackによるLoL専用音声録音
- 音声mux、NVENCのエンコードパイプライン

## テスト
自動テスト61件をLinux/Xvfb上で実行し通過。LoLリプレイ実機・WindowsでのHUDフラグ/名前表示の挙動と映像・音声は利用者側の確認が必要です。

## Windows動作確認の順序
1. 新しいフォルダにZIPを展開して `START.bat` で起動。
2. かんたん編集でHUD表示を「体力バー中心」にして、詳細編集 → 出力で同じ選択になっているか確認。
3. LoL内で体力バー上の名前表示を「なし」に設定し、ミラーを確認。
4. 1クリップを作成し、HPバーが表示され名前が消えているか（出ていれば画像または短い動画を送付）。
5. シーン設定を編集→2シーンにチェック→「☑ チェックした全シーンに適用」→Undo/Redoを確認。
6. チェックした2シーンで書き出し、カラー・音声・カメラの動きを確認。
7. 必要なら `COLLECT_DIAGNOSTICS.bat` で診断ZIPを作成。

## トラブルの切り分け
- HPバーも表示されない：Replay APIでのHUD変更がLoLのバージョンと合っていない可能性。診断ログと映像を確認。
- 名前だけ残る：LoL側の名前表示設定を確認。AutoCineからゲーム内の名前表示を変更する仕組みは現時点でありません。
- 操作後にクラッシュ：v5.9.5の安定フォルダへ戻し、診断ZIPを提供してください。
