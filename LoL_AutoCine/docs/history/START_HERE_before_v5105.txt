LoL AutoCine v4.1 - 使い方
============================

■ これは何？
LoLのリプレイから、選んだプレイヤーのキルを自動検出し、
カメラ演出・色・Fog・DOF・スロー・フラッシュなどを付けて
60fpsのMP4へ自動変換するWindows向けツールです。

lolnamの「プレビューを見ながら右側で編集する」使いやすさを参考にしつつ、
AutoCineは「キル検出→録画→編集→出力」をワンクリックに寄せています。

■ APIキーについて
不要です。
「Replay APIを自動設定」で game.cfg に EnableReplayApi=1 を設定します。
初回だけ LoL の再起動が必要です。

■ 最短手順（初回）
1. LoLのリプレイを音が鳴る状態で起動
2. 00_AUDIO_TEST.bat（または SOUND_TEST.bat）を実行
3. [PASS] になったら START.bat をダブルクリック
4. START.bat をダブルクリック
2. 上部の「LoLを準備」を押す
3. リプレイが起動したら、読み込み完了まで待つ
4. 「接続して10人を取得」
5. 対象プレイヤーをダブルクリック
6. 右上でテンプレートを選ぶ
7. 「★ これで自動作成」

これだけで、全編スキャン → 対象キル抽出 → キル位置へ移動 → カメラ演出 → 録画 →
色/エフェクト → MP4出力まで自動で行います。

■ 個別操作
・「全編スキャン」: キルだけ先に確認
・「選択したキルへ移動」: リプレイ内のキル3秒前へ移動してカメラを配置
・「選択キルだけ作成」: 一覧で選んだ1キルだけMP4化
・「全キルを作成」: スキャン済みキルをまとめて作成
・「ミラー ON / OFF」: LoLウィンドウだけをアプリ内プレビュー
・「カメラ演出を確認」: 録画せずにカメラ演出を確認

■ 編集
「かんたん」: テンプレ、カメラ、タイトル、前後秒数
「カラー」: グレード、色温度、コントラスト、露出、彩度、Fog、カーブ、DOF
「カメラ」: 距離、高さ、HUD、HPバー
「録画・出力」: 切替、音、BGM、LUT、出力先

タイトル欄を空にすると文字は表示されません。

■ 音声
初回は必ず 00_AUDIO_TEST.bat を実行してください。5秒間の実録音を行い、LoLプロセス音声・WAV信号・依存関係を確認します。
診断ログ: diagnostics\audio.log
テスト結果: diagnostics\audio_test_result.json

既定ではLoLプロセスの音だけを取得するWASAPIプロセスループバックを優先します。
利用できないWindows環境ではデスクトップ音へ自動フォールバックし、ログに理由を表示します。
「ゲーム音」をOFFにすれば無音映像として出力できます。

■ 出力先
既定:
  ビデオ\\LoL_AutoCine\\プレイヤー名_チャンピオン\\

元録画(raw)も残すため、後から再編集できます。
同名ファイルは上書きせず別名で保存します。

■ 重要
・録画中はLoLを最小化しないでください。
・LoLウィンドウを他アプリで隠さないでください。
・リプレイ再生中は操作をできるだけ行わないでください。
・初回のgame.cfg変更前には自動でバックアップを作成します。

■ トラブル
「接続できない」
→ game.cfg設定後にLoLを再起動し、リプレイを実際に再生してください。

「キル0件」
→ プレイヤー固定後に「全編スキャン」を実行し、diagnostics\\last_scan_events.json を確認してください。

「録画が止まる」
→ LoLが前面/表示状態か確認してください。同じ時刻で再生が止まった場合は安全側で録画を中止します。

「音がLoL以外も入った」
→ プロセスループバックが使えずデスクトップ音へフォールバックした可能性があります。ログに理由が表示されます。

「詳しいエラー」
→ diagnostics\\last_error.txt

■ テスト
LoLなし: RUN_TESTS.bat

■ 参考動画からテンプレート
「編集」→「かんたん」→「参考動画 → テンプレート」で動画を複数追加できます。
追加した時点では解析しません。必要な動画を揃えて「テンプレート作成」を押してください。
1本が壊れていても他の動画は解析を続けます。
作成したテンプレートは現在の三人称/距離/高さ/仰角/録画設定を維持し、参考動画の映像演出だけを取り込みます。
「HERO / CLEAN / HYPE」は、その参考テンプレートからワンクリックで3種類を派生保存します。
