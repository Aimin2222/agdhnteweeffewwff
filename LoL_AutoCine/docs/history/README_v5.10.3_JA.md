# LoL AutoCine v5.10.3 — 円形DOF統合版

Codex保存版v5.10.1に、受領v5.10.3 ZIPの円形DOF・カラー・FX説明・4プリセットを統合しました。受領パッチの基準はv5.10.2ですが、その完全版は今回の環境にはなく、パッチの直接適用やGPUファイルの丸ごと上書きはしていません。前回のGPU修正、キル時刻補正、初回WGC準備、ホイール・シーン位置保持を残しています。

詳細編集→カラー・FXで円形DOFをONにすると、円の内側は鮮明、外側はぼけます。中心X/Y・半径・境界・ぼかし強度を調整でき、「おすすめ：キャラをくっきり」も使えます。画面位置に固定した2Dぼかしで、実際の深度情報やチャンピオン自動追跡を使う効果ではありません。キャラが中心から外れたら位置を手動調整してください。軽量プレビューと書き出しは同じ位置指定を使いますが、ぼかしの画素単位の一致は保証しません。

旧上下DOFは形状bandとして残しています。形状指定のない旧JSONは新しい既定値circleになります。従来の帯状表示を使う場合はbandを選んでください。新しい5設定はTemplate末尾に追加し、古い位置引数を保ちます。

アイスブルー・シネマ、ゴールド・フィニッシュ、クリア・アクション（視認性重視）、エピック・チームファイトを追加しました。既存プリセットとカメラ座標は維持しています。円形モザイクは導入せず、他環境のv5.10.2 JSONに残ったvideo_effects.center_mosaicだけを除去します。入力JSONを変更せず、他のFXと既存のブロックモーション効果は保持します。

円形DOF/BloomはCPUフィルターです。auto/gpu/cpuは映像エンコードの方針で、NVENCとGPUエフェクト実行は別です。非対応時のCPU再試行と診断を保持しています。

## Windowsへ取得

GitHubのcodex/lol-autocine-v5103-handoffブランチでCode→Download ZIP。旧版を別フォルダへ保管し、展開したLoL_AutoCine/START.batを起動してください。handoff/LoL_AutoCine_v5.10.3_Windows_Full.zipのDownload raw fileでも完全版を取得できます。Codex_MergeChanges.zipはCodex保存版v5.10.1基準の差分で、単体起動用ではありません。チャットのダウンロードリンクやmainへのマージ、環境Publishは必要ありません。

## Windowsでの確認

ホイールでカラーや対象が勝手に切り替わらないこと、シーンのチェック位置保持、手動再生なしの最初のクリップ、円の中心・半径変更、4プリセット、TargetLock/HUD/カラー/60fps/LoLだけの音声、複数クリップの順序と同期を確認してください。旧版と新しい版を別フォルダで比較します。診断や録画はPC上に保管し、必要な範囲を確認してから共有してください。
