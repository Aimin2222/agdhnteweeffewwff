# LoL AutoCine v5.9.7 — ワークスペース刷新・モンタージュ演出

## 変更内容
- 3分割の上段（左：リプレイ準備・対象選択、中央：LoLミラー、右：検出シーン・出力状況）と、画面全幅の下段編集領域。境界をドラッグして高さ変更。上段の左右は個別にスクロール。
- 上部の余白・見出し・ミラーの初期表示サイズを圧縮。かんたん編集と詳細編集は従来どおり切り替え可能。
- 編集表示の日本語化（カメラプリセット／Fog／エフェクトのラベル）。内部キー・保存形式は維持。
- 「チェック済み」の表示を [✓]/[  ] に変更。誤解しやすい説明とボタン文言を整理。
- カメラ曲線：キルの瞬間、各キーフレーム、カーソル下の値・凡例を追加。DOFはピント位置・近遠の範囲の概念図に改善（LoL映像をシミュレートするものではない）。
- モンタージュ切替演出：通常連結（従来どおり・無劣化）、白い閃光、シネマ暗転。かんたん編集と出力ゾーンから変更可能。
- 非標準切替はクリップ連結後の映像の明るさのみを短時間調整、音声はコピー。フィルター／エンコード失敗時は元の連結動画を残す。
- GPU/音声/TargetLock/キル検出の基礎処理は変更しない。モンタージュに演出を加える場合のみ、最後に映像を追加でエンコードする。

## Windows 実機テスト
1. ZIPを新しい短いフォルダに展開し START.bat。左側で Replay API、プレイヤー取得・固定・スキャン。
2. 上段プレビュー・右側シーン一覧が見えること、境界ドラッグで下段全幅編集領域が伸縮することを確認。
3. 詳細編集の シーン／カメラ／カラー・FX／出力 を切り替える。日本語名や [✓] のチェック表示を確認。
4. キーフレーム編集後、カメラグラフに縦線と数値が出ること、DOFのピント位置を動かすと緑の範囲が変わることを確認。
5. チェックした2シーンを書き出し、モンタージュを通常連結／白い閃光／暗転で各1本作成し、つなぎ目の効果とLoLゲーム音の維持を確認。
6. 診断ZIPと、気になるシーンの短い完成MP4を送付。

## 留意点
- YouTube Shorts の映像本編を、この作業環境では直接取得・再生して分析できていない。特定クリエイターの演出再現を検証したものではない。
- X動画も未検証。参考クリップが提供されれば、カメラの速度・キル前後の尺・色・トランジションを分析して次のワンクリックプリセットに反映できる。
- モンタージュの切替は現段階では明るさ演出であり、クロスディゾルブやAdobe/DaVinciのトランジションと同一ではない。
- 144fpsなどの実機エンコード性能・LoLのライブプレビューはWindows上の確認が必要。
