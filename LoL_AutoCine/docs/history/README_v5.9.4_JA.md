# LoL AutoCine v5.9.4 — 実カメラプレビュー＆時計修正

## 主な修正
1. 詳細編集 > シーンを選択 > キーフレームの型または編集値を設定 > 「動きをプレビュー」を押すと、未保存の設定も含めLoL Replay上のカメラ演出を再生します。LoLミラーを開始しておくとアプリ内でも見られます。
2. Replay APIのリクエストが遅い場合の時計の経過時間切り捨てを緩和。
3. プレビュー終了時にAPI待ち時間・時計のずれの診断を記録。

## 推奨テスト
1. 詳細編集で検出シーンを1つ選び、「自然な回り込み」をクリック。
2. 「このシーンに保存」を押さずに「動きをプレビュー」をクリック。
3. LoLミラーでキル前〜キル後のカメラの回転を見る。
4. 異なるキーフレームを入れて再プレビュー、見た目の変化を確認。
5. 同じシーンを保存して1クリップ作成、音声・色・ターゲットロックを確認。
6. `COLLECT_DIAGNOSTICS.bat` で診断ZIPを保存し、前回の遅延（約100ms・最大0.73秒）と比較。

## 注意
- プレビューは実際のLoL Replay APIを操作するため、リプレイが起動しプレイヤーが固定されている必要があります。
- 表示や時刻の改善はLoL実機で未確認であり、完全なガクつき解消を保証しません。
- GPUエフェクト、NVENC、LoL録音、カメラ位置/TargetLockの座標設定は変更していません。
