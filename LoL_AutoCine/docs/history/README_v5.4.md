# LoL AutoCine v5.4

LoLnam風の見やすさと、動画編集ソフトのような操作感を両立しつつ、初心者が少ない操作でキル動画を作れる構成です。

## 使い方
1. `START.bat` を起動
2. Replay APIを自動設定
3. リプレイを開く
4. 対象プレイヤーを選ぶ
5. 全編スキャン
6. テンプレートを選ぶ
7. `動画を生成`

## UI
- LoLミラーは中央上部に固定
- 下の編集エリアだけスクロール
- 右側の検出シーンはチェック切替、選択シーン移動、作成を常時操作可能
- スライダーは数値直接入力にも対応
- 出力フォルダをUIから変更可能
- サンプル画像は使用しない

## カメラ
- Replay APIへのカメラ制御は最大144Hz
- キル付近はsmooth-damp補間で位置/FOV/回転を連続化
- 144Hzはゲーム内カメラ制御とミラー表示の更新基準
- 最終MP4は1080p / 60fpsを標準

## GPU
- NVIDIA NVENCがあればH.264エンコードをGPU優先
- CUDAが利用できる環境では入力デコードもGPU優先
- GPU対応がない処理はCPUへ安全にフォールバック

## 音声
- LoLプロセス音声のみをWASAPI Process Loopbackで録音
- WAVが空/短すぎる場合は無音MP4を成功扱いしない
- 最終MP4にAudio streamが存在することを検証

## 注意
WindowsのLoLプロセス音声取得はWindows側の音声APIに依存します。実機ではリプレイを再生してLoLの音が鳴っている状態で生成してください。
