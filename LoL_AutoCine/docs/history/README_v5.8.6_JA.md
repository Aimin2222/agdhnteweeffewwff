# LoL AutoCine v5.8.6 Parallel UI

このバージョンはGPU側の最適化と並行して進める **UIの第1段階** です。

1. 中央のタイムラインの左右ハンドルをドラッグすると、キル前・キル後（秒）を変更できます。「詳細編集 → 基本」の秒数欄とも連動します。
2. カメラ設定に「自然」「シネマ」「ダイナミック」を追加。Orbit・ドリー・モーションプロファイルの既存パラメータへ反映します。
3. 自動作成欄に「自動ディレクター（任意）」を追加。初期値はOFFで既存のワンクリック挙動に影響しません。ONでは事前スキャン済みキルがあればマルチキル数に応じてカメラの簡単設定を選び、未スキャンならカメラのautoモードにします。全シーンごとのカメラ切替は今後の課題です。

機能の詳細とCodexとの統合は `docs/CODEX_INTEGRATION_CONTRACT_JA.md` を確認してください。

**注意:** このパッケージにはCodex側でこれから作るGPU高速化コードは入っていません。UIの変更とGPUの変更はGit上でレビューして統合します。
