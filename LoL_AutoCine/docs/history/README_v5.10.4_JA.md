# LoL AutoCine v5.10.4 — タブ誤切替・ライブぼかし・カメラ通信改善

v5.10.3を引き継いだ修正版です。**新しいフォルダに展開し、START.batを起動**してください。

## 変更点

1. **詳細編集 ＞ カラー・エフェクト/書き出し ＞ 基本 / カラー・FX / 録画・出力**：マウスホイールによるタブ切替を禁止。タブの切り替えはクリックのみ。タブ上でホイールを回すと中央編集エリアを縦にスクロールします。検出条件のコンボ誤変更防止も継続。
2. **円形DOF（ぼかし）と色の再生プレビュー**：LoLミラーをONにして「FXをミラーに反映」をチェックすると、▶ 再生（カメラプレビュー）中も簡易FXを表示。以前は再生処理がbusyと判定されて効果を表示していませんでした。録画・書き出し中は処理負荷のため簡易FXを停止します。
3. **Replay APIの滑らかさ**：HTTP(S) Keep-Aliveでカメラ命令のTCP/TLS接続を再利用する。HTTP/1.0サーバーや切断時は再接続。実測でAPIが遅い場合だけ、カメラ位置・角度・FOVの1命令あたりの変化を制限し、スロー速度の細かすぎるPOSTを削減。TargetLockの座標系・三人称リグは変更していません。

## 注意

- **ぼかし・色補正はAutoCine中央のミラー内の簡易プレビュー**に表示します。LoLゲームウィンドウへ画像加工を送信するものではありません。動画書き出し側は従来のFFmpeg FXで処理します。簡易プレビューの仕上がりは完成MP4と完全一致するわけではありません。
- 円形DOFは画面上の設定中心を基準とする**2Dぼかし**です。チャンピオンの画面座標をトラッキングする機能ではありません。
- この版のカメラ改善はReplay APIへの通信待ちや角度ジャンプを減らすことを狙います。LoLゲーム側のフレーム生成やAPI自体に遅延がある場合、60fpsの完璧な移動は保証しません。
- ユーザー提供の診断記録では、v5.10.3のAPI POSTは最大約244ms。診断の「API送信数・25ms超・最大API待ち」と実際の映像を次回比較してください。

## Windowsでお願いしたいテスト

1. 詳細編集の「カラー・エフェクト/書き出し」の **基本 / カラー・FX / 録画・出力** のタブ上でホイールを回す。タブの選択は変わらず中央エリアが上下スクロールすることを確認する。タブはクリックでは切り替わること。
2. LoLリプレイのミラーをON、FXをミラーに反映ON、詳細編集の円形DOFをON、ぼかし強度4〜8程度。▶ 再生を押し、**中央ミラー**でぼかしが確認できること。LoLウィンドウでは変化しないのが正常。
3. 円形DOFをONにした1キルを実際に書き出し、完成MP4でも円形ぼかしを確認する。
4. 旧版と同じキルで同じカメラテンプレートを使い、動きが滑らかになったか比較。診断ZIPのAPI待ち時間も比較。
5. LoLゲーム音、GPUエンコード、色、キルアイコン、初回ネクサス対策、シーンチェックを簡単に確認。異常があれば素材MP4と診断ZIPを添付。
