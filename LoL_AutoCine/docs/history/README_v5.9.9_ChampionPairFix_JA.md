# LoL AutoCine v5.9.9 — キルアイコン実キャラクター対応修正版

## 主な変更

- キル装飾から `KILL`, `x1`, `HIGHLIGHT`, `CINEMATIC` 等の文字を取り除きました。
- **キラーのチャンピオン画像 × 倒されたチャンピオン画像**の2つを主役にします。
- 中央はテンプレートに応じて細いクロス線・交差する斬撃モチーフなど。4つのプリセット（シンプル／シネマ／ネオン／インパクト）を維持。
- プレイヤー10人のリプレイ情報から、キルイベントの名前と使用チャンピオンを対応付けます。**1つのクリップ内でキル対象が変われば、画像も切り替わります。**
- 名前・使用チャンピオンの対応が不明な場合、別チャンピオンをでっち上げて表示しません。対象の装飾のみ省略します。
- 画像はRiotの公式Data Dragonから初回だけ取得してキャッシュ（ネット未接続のときは手動でPNGを用意可能）。
- 各シーンのテンプレート・表示位置・大きさ・表示秒数・濃さの調整は既存UIのまま。
- GPU/NVENC、音声、カメラ、HUD、スマート編集やモンタージュの処理本体は変更していません。

## 重要：初回だけインターネット接続が必要

- Riot公式のチャンピオン肖像画像が未保存の場合、エフェクト適用時に `ddragon.leagueoflegends.com` から該当画像を取得します。
- 保存先は `%LOCALAPPDATA%\LoL_AutoCine\champion_icons`、ファイル名は `LeeSin.png` のようなチャンピオンIDです。
- ネットなしで使いたい場合は、公式の該当PNGを手動で `assets\champion_icons\<ChampionID>.png` に置いてください。
- リプレイの10人を取得・対象プレイヤー固定を完了してから作成してください。プレイヤー名や画像が取得できない場合は装飾が省略されます。
- Riotの公式画像はゲームの素材です。配信・投稿での利用はRiotのコンテンツ利用規約を確認してください。

## Windows 実機テスト手順

1. v5.9.8や元のv5.9.9とは**別のフォルダ**にフルZIPを展開し、`START.bat` で起動。
2. リプレイ → 10人の取得 → 対象選択・固定 → スキャン。
3. **シンプル**で1クリップ作成。右側に2人のチャンピオン肖像画像だけが並び、余計な文字がないか確認。
4. **シネマ／ネオン／インパクト**も各1本。中央装飾、発光、表示時刻を確認。
5. 異なる敵を倒す2キルで出力。右側の倒されたキャラ画像がキルごとに切り替わるか確認。
6. 詳細編集で位置（左上／右上等）、大きさ、表示秒数、濃さを調整し、保存・再読込・書き出し。
7. タイトルの有無、HUD非表示＋HPバー、LoL専用音声、1080p、カラー、NVENCが維持されているか確認。
8. できれば一度録画した後、インターネットを切ってキャッシュからアイコンが出るか確認。
9. `COLLECT_DIAGNOSTICS.bat` の診断ZIPと、代表的な完成MP4を送付。
