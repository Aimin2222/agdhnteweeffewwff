# LoL AutoCine v5.10.1 — スクロール・シーンチェック・初回クリップ修正

v5.10.0 UI/GPU/Kill Frame Full 版をベースにした互換性修正版です。

## 修正点

1. **カラーFX/録画出力のコンボボックス**: マウスホイールでカラーグレード、Fogプリセット、切替演出、エンコーダ、中央マークなどの選択値を変えないよう `TCombobox`/`TSpinbox`/`Spinbox` のクラス操作を共通でブロック。スクロールは下層のパネルへ渡し、クリックで値を選択する動作はそのままです。新規に生成されるコンボボックスにも対応。
2. **右の検出シーン**: `[✓]` を外す／付けるたびにリストの先頭へ飛んでいた不具合を修正。再描画時のスクロール位置、選択中の行、アクティブ行を保持。全選択／全解除にも同じ処理を適用。チェックのクリック範囲は従来のまま維持。
3. **最初のクリップがネクサスになる問題への対策**: 最初のWindows録画の前に短いLoLリプレイのプレロールを自動再生。Replay APIで目標時刻へ戻し、カメラ反映後を基準にWGCの新しいフレームを待って録画。リプレイ時刻の大きなずれは一度再シークし、映像更新が止まっている場合は録画開始前に中断する。準備中の停止にも応答する。リプレイの再接続・新規起動時にはウォームアップをやり直す。

## 維持している機能

- TargetLock・Lolnam風三人称カメラの座標設定
- LoL専用Process Loopback音声・既存HUD
- ワンクリック編集、詳細編集、キルフレーム6マークとチャンピオン肖像
- GPU優先／CPU優先切替、1080p 60fps横型MP4、モンタージュ
- 音声のデスクトップ全体キャプチャへの切替はしません

## Windowsでの確認手順

1. 以前のv5.10.0フォルダを残し、このZIPを別のフォルダへ展開して `START.bat` を実行。
2. 「カラー・FX／録画出力」でカーソルを色グレードやFogのコンボボックス上に置いてホイールを回す。**選択値が変わらず、パネルが上下に動く**ことを確認。
3. キル検出を10シーン以上表示して下のほうまでスクロール。`[✓]` を外す→再度付ける。**同じ位置に留まる**ことを確認。
4. リプレイを開いてスキャンしたら**手動プレビューを一度も再生せず**、チェックした1クリップを作成。最初の映像がネクサスではなくキル直前の現場になっているか確認。
5. 音声、カラー、GPUエンコーダ、残りのクリップとモンタージュも確認。
6. 改善しない場合は `runtime.log` の「初回クリップ」ログを見る。必要なら `COLLECT_DIAGNOSTICS.bat` でローカルへ診断を収集する。外部へ自動送信しない。

### 検証上の制約

TkのGUI自動テスト・ダミーReplay APIによる初回再生テストは実施していますが、**LoL Windows実機のゲーム描画完了を自動テストで再現はできません**。ネクサス問題の最終確認は実機映像でお願いします。描画準備が遅い環境では失敗として中断する場合があります。
