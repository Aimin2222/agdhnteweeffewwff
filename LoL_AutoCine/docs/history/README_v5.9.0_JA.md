# LoL AutoCine v5.9.0 — Scene Studio（ChatGPT/UI側）

このバージョンは **v5.8.6を起点に、UI・シーンごとの自動演出・プロジェクト保存を追加**した並行開発版です。GPUエンジンとLoL専用音声の既存のソースコードは変更していません。Codex側の最新GPU修正はこのZIPに**まだ含まれていません**。

## クイックスタート

1. 前の安定版をバックアップし、ZIPを**新しいフォルダに**展開。
2. Windowsで `START.bat` を実行。League of Legendsのリプレイを接続し対象プレイヤーを固定。
3. **従来通り**に使うとき：`★ これで自動作成` または「チェックしたシーンだけ作成」。新機能の「シーン別演出」をOFFにすれば従来のジョブ呼び出しを使用。
4. **シーン別自動演出**：`✨ スマート自動編集：全シーンに個別カメラ演出 → 作成` を押す。スキャン後、キル数やアシストに合わせて各クリップに別のテンプレートを割り当てる。
5. **個別編集**：全編スキャン→右の検出シーン一覧で1件を選択→中央の「シーン別ディレクター」でパラメータ調整→「このシーンに保存」。シーン別演出がONのとき、その値で書き出す。
6. 「自動演出を設定」「全シーンの演出を自動推薦」「上書きを解除」「元に戻す」「やり直す」に対応。編集プロジェクトはJSONで保存・読み込みができる。

## 今回実装した内容

- シーン単位の `motion_profile` / Orbit / Dolly / Yaw / キル前後秒数 / 演出強度を編集し、既存の `Template` へ反映。
- **三人称カメラ**のシーン別自動演出では、既存の `lolnam_cinema` のTargetLock・Orbit実装を使用。FPS/俯瞰をユーザーが選んでいる場合はそのスタイルを維持。
- キル / アシスト / マルチキル数から自動推薦。個別設定があればそちらを優先。
- CameraPlanを使うFOV / 距離 / Orbitプレビューカーブ（計算結果を描画、手描きの架空曲線ではない）。
- プロジェクトJSONのバージョン管理、検証、原子的保存、850ms遅延自動保存、Undo/Redo最大100回。
- シーン別書き出し時の詳細ログ `SCENE_PLAN`、モンタージュ結合、従来のLoL専用音声経路をそのまま呼び出す。
- **通常の作成はデフォルトで変更なし**。明示的にシーン別演出をONにした場合だけ新しい経路を使用。

## 重要な仕様・制約

- **シーン別演出ON時は1シーン=1クリップ**で録画する。近接する連続キルの自動マージとは異なる。モンタージュは完成した個別クリップを連結する。
- 一部のLoL環境では実際のキャプチャ、音声、GPU、カメラ動作が変わる可能性がある。**Windows/GTX 1070 Ti上での実機確認は未実施**。
- カメラ曲線は既存CameraPlanを使う可視化。**任意のキーフレームを時間軸で追加して出力へ反映する自由なKeyframe Editorは未実装**。グラフはドラッグ式のキーフレームエディタではない。
- シーン別カメラ演出は3rd-personカメラで最も効果がある。ユーザーがFPS/俯瞰を選んだ場合、Orbit/Dollyの一部の見た目は変わらない。
- 編集ファイルは `projects/scene_project.json` に自動保存される。別のリプレイに移る際は『編集プロジェクトを保存』で区別して保存することを推奨。
- Lolnamの提供バイナリ・ソースコードはコピーしていない。参考資料の設計思想をもとに既存AutoCine構造で独自実装した。
- CodexでGPUを変更する際、古いGPUコードで上書きしない。`docs/CODEX_INTEGRATION_CONTRACT_JA.md` と `docs/CODEX_MERGE_v5.9.0_JA.md` を参照。
