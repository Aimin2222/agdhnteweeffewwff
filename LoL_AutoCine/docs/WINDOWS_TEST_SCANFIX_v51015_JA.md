# ScanFix Windowsまとめテスト

新完全版を旧版と別フォルダへ展開してSTART_GPU.bat。個人設定/プロジェクト/録画は保管。

1. 未接続から右側①スキャンだけ押す。接続→プレイヤー取得→試合全体スキャン、取得後の対象切替は再スキャンなし。再接続後に古いシーンを使わない。接続中/スキャン中の中止も確認。
2. ミラーONでチェックをON/OFF→hover→disabled、青いチェックが残る。タブ/スライダー/スクロールの応答性を確認。
3. 円形DOF/従来上下ぼかしを切替。中央と右側で選んだモードだけ表示され、値は消えない。ミラー/実出力で円/帯を確認。
4. BLUE/RED双方で通常三人称/シネマ/FPS/Lolnamを連続再選択→プレビュー。地面が上にならないか確認。手動0/180とTargetLockも確認。
5. 開発用一括テストは複数録画するので時間がかかる。試合全体スキャン後に押し、出力先_dev_replay_qaとBLUE/RED4カメラ・全10切替の結果を確認。2キル以上あるプレイヤーがいる時だけモンタージュも出る。中止後に次ケースが始まらず、通常書き出し/ミラーを再開できること。
6. 1シーン1080p60fps、GPUエフェクト+NVENCを診断で確認。色・長さ・LoLだけの音声/同期を確認。新名称/旧保存設定/キラー画像も確認。

今回のWindows/LoL/NVIDIA実機検証は未実施。問題は操作と発生時刻、診断ZIPで共有。生ログや録画はGitへ入れない。詳細はWINDOWS_TEST_v51015_JA.mdも参照。
