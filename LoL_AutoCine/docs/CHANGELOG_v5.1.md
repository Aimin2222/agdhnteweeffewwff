# v5.1

- NVIDIA NVENC自動検出。利用可能なら録画/エフェクト後のH.264エンコードをGPU化、利用不可ならCPUへフォールバック。
- 検出対象を「キル / アシスト / キル＋アシスト」から選択可能。
- 検出シーンを☑/☐で個別選択し、チェックのみ一括作成 / 全件一括作成 / 個別作成を分離。
- スライダー横の数値をEntry化し、ドラッグと直接数値入力の両方に対応。
- トーンカーブをグラフ表示し、ポイントをドラッグ編集可能。
- Fog強度をカーブ表示。
- DOFの近距離・フォーカス・遠距離を可視化。
- 自動タイトルはアシストシーンならASSIST表示。
- TargetLock / 3人称追従 / Lolnam自動モーションは変更せず保持。
