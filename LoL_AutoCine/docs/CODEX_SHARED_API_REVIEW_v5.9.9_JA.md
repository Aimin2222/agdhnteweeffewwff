# v5.9.9 共有カメラ・録画接続レビュー

新設定は末尾へ追加し旧位置引数を維持。既存音声・TargetLock座標系は維持する。

- camera: スマート構図ONでのみ距離/仰角/Orbit範囲/平滑化・API待機適応・速度送信制限を採用。通常モードの0.25秒観測、既存速度範囲/送信閾値を保つ。スマート追加スローの0.40下限は有効時にだけ適用。
- jobs: 新設定をCameraPlanへ渡し、smart_impactはスマート計画有効時だけ渡す。装飾またはスマート構図ONの録画では、既存playback観測を動画の実時間へ線形補間しClipTake.effect_eventsに保持。APIリクエスト追加なし、録音・HUD復元・録画速度正規化・音声offsetは維持。
- effects: apply_effects末尾へ既定Noneのeffect_eventsを追加し、指定時だけ記録済み動画時刻を使用。既存呼び出しは従来のイベント変換を維持。PNG入力のindexをタイトル/BGM/ゲーム音それぞれで正しく接続し、GPU失敗・暗転回避の再試行にも装飾を保持。CPU overlayでありGPU効果ではない。
- UI: 通常計画でsmart_highlight_enabled=Falseの場合は暗転の自動採用も無効。手動順序を保持し、12件超の候補選択だけ明示スマートON時に実行。

新camera/jobsの正確なblobだけ承認し、camera_clockの既存承認は維持する。旧レビューはこれらの新共有変更を阻止することを確認する。実機の遮蔽回避/ガクつき改善は未検証で、テスト結果資料へLinux/モック/合成出力を区別して記録する。
