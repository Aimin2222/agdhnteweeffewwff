# PortraitCrashFix Windows確認

完全版を旧版と別フォルダへ展開しSTART_GPU.batで起動。旧設定/プロジェクト/録画は保管。

1. リプレイ接続→スキャン→異なるチャンピオンのシーンを10回程度連続選択。キラーの画像または名前が出て例外にならず、最後に選んだ対象と一致すること。
2. キャッシュ済み画像と未取得画像の両方を確認。ネットワーク遮断時に名前で表示できること。再接続/タブ切替/閉じる直後に古い画像が混入しないこと。
3. ミラーONで色・DOFスライダー、タブ切替、スクロールが以前の応答性を保つこと。
4. 1シーンを1080p/60fpsでGPUエフェクト付き出力。出力のfps/長さ/色、LoLだけの音声と同期を確認。NVENCだけでなく診断にGPUエフェクト経路が記録されること。
5. 可能なら既存BLUE/REDカメラ・全シーン出力も確認。詳細はWINDOWS_TEST_v51015_JA.md。

問題があれば操作、期待と実際、発生時刻、AutoCine_Diagnostics.zipを共有。診断/録画/個人設定はGitへコミットしない。
