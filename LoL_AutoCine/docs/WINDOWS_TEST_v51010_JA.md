# v5.10.10 まとめテスト（Windows / LoL / NVIDIA）

取得用ブランチのCode→Download ZIPを別フォルダへ展開し、LoL_AutoCine/START_GPU.batで起動。GPU側を古いUI版で上書きせず完全版を使う。以前の設定/プロジェクト/出力はそのまま保存する。

1. ミラーON、FX ONでスライダー・発光強度・色・タブ・スクロールを操作。「操作優先」で固まらないか確認し、「表示サイズで確認」で画質/負荷を比較。再起動して選択が保存されるか確認。
2. キル＋アシストをスキャン→図鑑→シーン選択→①移動→ミラーでその場面を確認→②保存・比較。各カードの左側が同じ実シーン、右側が色/2D FXだけ変わるか確認。検索・スクロール・適用ボタン、別の同件数スキャン後の選択肢も確認。画像未保存のシーンでは別の仮映像を出さないことを確認。
3. 同じキル素材でプレミアム6種類、発光OFF/弱/強、角の光0/2、行間0/12/36を比較。1シーンと連続キルを1080p/60fpsで書き出し、両者の実チャンピオン画像、縦配置、色、60fpsの自然な速度を確認。素材に描き込まれた光の模様は発光OFFでも残る。三人称TargetLock、BLUE/RED、LoLのみの音声と映像同期も確認。
4. アプリを閉じ、TEST_GPU_RENDER.batで同じraw MP4を選択→6ケース完了とRESULTS/終了コードを確認。CPU比較の03以外がGPU加工確認になるか、02と03の所要時間を比較する。GPUテストは無音で、LoL専用音声は手順3で確認。

最後にCOLLECT_DIAGNOSTICS.batで診断ZIPを送る。どの品質設定・素材・発光・行間を使ったか、固まった/違った操作があれば添える。CPU使用率だけでGPU不使用とは判断せず、実行経路/encoder/所要時間と結果を照合する。今回の新Windows版はクラウド上で実機確認していない。
