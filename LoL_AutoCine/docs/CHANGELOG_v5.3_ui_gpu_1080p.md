# v5.3 UI / 1080p / Camera Stability

- 中央プレビュー領域を縦スクロール化し、カメラ設定・詳細編集の下部が小さい画面でも見切れないよう修正。
- 右パネルを拡張し、検出シーンのリストを含むカードが画面内でスクロール可能。
- カラー/カメラ/DOFなど右側のスライダーに数値入力欄を追加。
- 出力先を右パネルにも常時表示し、「選択」で変更可能。
- 参考用のサンプル画像表示を廃止。LoLミラー開始前はプレースホルダーのみ表示。
- 「カメラ演出を確認」を「▶ 再生」「■ 停止」に変更。
- 出力形式を1080p MP4へ統一。FPSは60 FPSを標準化。
- 録画・最終出力とも1920x1080へ統一。
- NVIDIA NVENCを自動検出してGPUエンコードを優先。非対応環境はCPUへフォールバック。
- 最終エフェクト処理の入力デコードでFFmpegの自動ハードウェアアクセラレーションを有効化。
- CameraDirectorを45Hzへ引き上げ、FOV・位置・回転を指数平滑化してカメラ移動のガクつきを低減。
- トーンカーブをLoLnam系の大きな編集エリアへ変更し、ヒストグラム表示・Reset・クリック追加・ドラッグ移動・数値入力に対応。
- 既存テスト11件を通過。
