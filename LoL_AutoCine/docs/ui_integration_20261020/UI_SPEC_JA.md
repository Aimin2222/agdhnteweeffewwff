## 比較する配置

上部の「配置」で「現行配置 A」と「テスト配置 B」を切り替える。Aは準備を左、スキャン・シーンを右に置く。Bは同じ既存パネルを並べ替え、シーンを左、準備とカメラ・キル演出の短い操作欄を右に置く。中央のミラーと下の編集欄は共通。配置を切り替えてもウィジェット、選択シーン、カメラ、素材、出力設定は作り直さない。選択は `settings.json` の `ui_layout` に保存する。

この2案は、ユーザーが実際のLoLで操作して最終案を選ぶための比較版である。A/B以外の案1～6、Cの静的モックは引き続き原本で比較できる。現在のアプリにその見た目を完全再現したとは扱わない。

## 操作と既存処理の対応

| UI操作 | 実処理・状態 | 今回の状態 |
|---|---|---|
| ミラー開始／停止、再生／停止、FX反映 | 既存 WGC ミラー、Replay API、プレビュー | 既存処理を共用 |
| 試合全体スキャン、キル・アシスト、チェックとシーン選択 | `on_scan`、`lb_kills`、`checked_kills` | A/B同じ処理。イベント位置を下段に追加 |
| 固定自動／フルオート／手動、視点とサイド | `var_camera_control_mode`、`var_style`、`var_camera_side` | B右側から既存の変数を操作 |
| 距離・高さ・角度・FOV、TargetLock、BLUE/RED QA | 既存詳細編集と `on_dev_camera_qa` | B右側から既存画面・QAへ移動 |
| Work枠・同名FX、A/B/C/D、6登場モーション、弱／強 | 既存 `work_gallery` と `director_work_controls` | B右側から画像図鑑・設定を開く。枠1/652合格、FX35点は確認用 |
| GPU、録画、LoL音声、1920×1080/60fps出力 | 既存の実処理・出力設定 | 変更なし。配布版では実機再確認が必要 |
| 簡単／詳細、数値入力、参考動画、テンプレート、37バッジ | 既存UI | 保存値を共有し、削除しない |

下段の「カメラ動作タイムライン」はキル前後秒数の実設定。新設の「試合イベント」はスキャン結果のキル・アシストを示し、クリックで左／右の実シーン選択に同期する。マークの灰色は出力チェックが外れた状態であり、品質合格とは無関係。現在の時間軸はシーンごとの動画トラックを編集する機能ではない。

## 画面制約と検証境界

最小ウィンドウは1024×680。1366×768では中央ミラーを優先し、左右と下段は独立スクロールする。ミラーは従来どおり全体16:9表示と元フレーム以上の無理な拡大禁止を維持する。125%相当はTkスケールを指定した画面でレイアウト確認したが、OSの表示倍率そのものは変更していない。

実機LoL接続、WGC画面キャプチャ、BLUE/REDの構図品質、NVENC、LoL専用音声、書き出しの画質と同期は、このUI変更の自動テストだけでは合格にできない。友達用のEXEでも動作経路を実物で確認し、未確認のまま「完成」と表示しない。
