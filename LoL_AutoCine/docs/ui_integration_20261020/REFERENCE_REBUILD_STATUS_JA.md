# 添付モックに合わせたUI再制作：進捗と差分

前版の「9案」は既存UIの左右入替と小さな追加カードが中心で、添付PNGの画面構成を再現できていなかった。前版ZIPは完成版として扱わない。本版では`ui/reference_studio.py`に画面専用の表示層を新設し、既存の`legacy_app.App`を1つだけ使用する。LoL接続、スキャン、カメラ計算、FX合成、GPU、録画、音声、出力処理は複製・変更していない。

上部の録画方針・ゲーム音・HUD・ミラー目標は既存設定の値を読み取って表示する。ミラーの「接続中」は実際のキャプチャ源が稼働中の時だけ表示する。録画方針や目標Hzを、NVENC利用成功や実測FPSと取り違えないよう区別する。

## この時点の相違・未検証

- モックPNGとピクセル一致する画面ではない。Tk部品と実データを用いた再構成であり、未接続プレビューの参考静止画を除き、架空のシーン画像は表示していない。カメラ候補は過去のCameraQA実測画像を参考と明記して使用する。シーンのサムネイルは実際に保存済みのものがある時だけ表示する。
- 右の詳細設定は主要項目を配置した。キーフレーム、カラー、GPU、音声、出力先など全設定は「基本設定」から既存画面で操作する。これらの完全な新インスペクタ化は残る。
- 下の4トラックは実スキャンのシーン位置と設定を表示・選択できる。各トラック上で独立したドラッグ編集までは実装していない。既存のキル前後トリム・シーン詳細編集を使用する。
- 4案のドックは区切り付きの固定ペイン。ドラッグ移動・リサイズ可能なOBS式ドックではない。
- 9案の起動・切替、共有変数、1660×940と1366×768の空データ表示はWindows上で確認済み。LoLプロセスが起動していなかったため、実リプレイ接続、実ミラー、GPU/NVENC、音声、動画出力、カメラの画角はこの版で実機未検証。

`screenshots/reference_rebuild*`は実際のTkウィンドウから取得した画像であり、LoL未接続の状態を参考静止画つきで示す。ゲーム接続後の見た目と性能の合格判定には使わない。
