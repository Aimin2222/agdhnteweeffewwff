# UI比較テストの順番（友達向け）

これは本物のAutoCineに接続する9案比較版です。画面内の「配置 1～9」を切り替えても、カメラやシーンの値は共有されます。モック画像のような架空の試合・成功結果は出しません。

Windows ZIPは、UIブランチのGitHub Actions「AutoCine UI comparison portable Windows build」の成功した実行から `LoL_AutoCine_UI_Comparison_Portable` アーティファクトを一括ダウンロードできます。ローカルビルドの場合も同名ZIPを使用します。アーティファクトの有効期間は30日です。ビルドが成功していない実行のZIPは使用しないでください。

1. 新しいフォルダへ配布ZIPを一括展開する。EXE版では `LoL_AutoCine.exe`、Python版では `LoL_AutoCine/START.bat` を起動する。配布版の `README_TEST_JA.txt` に実際の同梱形式を記載する。
2. LoLのリプレイを再生し、AutoCineで「リプレイを開く」→必要ならReplay API設定→「スキャン」。接続、10人の取得、スキャン完了と件数を確認する。
3. キル／アシストを切り替え、シーンのチェックをON/OFFする。下のイベントマークをクリックし、一覧の選択が同じシーンに移るか見る。
4. 配置1～9を順番に切り替える。各案の操作性を比べ、切替前の選択シーン、チェック、カメラモード、BLUE/REDサイド、枠の選択が維持されるか見る。6番では素材ライブラリと編集ページも切り替える。
5. ミラーを開始し、中央にLoLの映像が出るか確認する。カメラを従来手動→固定自動→フルオートと切り替え、BLUE/RED、TargetLock、追従と構図を見る。視点変更時は上下反転、画面外れ、ガクつきも記録する。
6. 図鑑からキルフレームを画像で選び、同名テーマFXと6登場モーション、弱／強を試す。正式合格のNo.083 Aと未合格の確認用を混同しない。ミラーと出力のキル瞬間を見比べる。
7. 詳細編集でカメラ数値、FX、GPU/NVENC、LoL音声、出力先を確認する。チェックした1シーンを1920×1080・60fpsで書き出し、再生速度・音声・色・同期を見る。
8. 必要なら画面の「BLUE/RED カメラ＋素材一括QA」と「自動診断」を実行し、診断ZIPとログを保存する。失敗や見た目の問題は、配置番号、画面サイズ、時刻、対象サイド、選択シーンをメモする。

比較時の画面サイズは1920×1080、1366×768、Windows表示倍率125%。レイアウトの自動テスト結果は動画の見た目の合格ではありません。EXE版でLoL実機確認が終わるまでは配布物を「検証用」としてください。
