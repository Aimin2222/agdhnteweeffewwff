# UI比較版のテスト手順

このZIPには2つの起動入口があります。`LoL_AutoCine.exe` は従来の9案、`LoL_AutoCine_UI29.exe` は開発中の29画面・12候補比較版です。UI29は初回起動時の候補一覧で選び、画面を開いた後は右上の「UI比較を切り替える」ボタンから候補グループまたは個別画面を選んでください。`Ctrl+Shift+U`でも切替パネルを開閉できます。両入口は別アプリなので、UI29内の12候補比較にはUI29のEXEを使います。

UI29のLoL未接続時は実ミラー映像を表示しません。候補切替でシーンやカメラの設定を初期化しない設計ですが、実機接続を含む全操作の合格は未完了です。未接続機能は成功扱いにしないでください。

配布ZIPは**フォルダごと展開**し、29画面の比較には`LoL_AutoCine_UI29.exe`を起動してください。`_internal`と`WebView2Fixed`をEXEから離さないでください。従来の画面は`LoL_AutoCine.exe`、Python環境を持つ開発者は`START.bat`でも起動できます。

1. [ ] **起動・表示**：UI29の候補一覧から12候補を順に開き、各画面の右上「UI比較を切り替える」から全29画面を巡回する。中央ミラー、左右ペイン、下部タイムライン、ライブラリ／編集、検索・テーマ・品質・前後ページを確認する。1920×1080、1366×768、表示倍率125%でプレビューが設定のスクロールに巻き込まれないことを見る。
2. [ ] **リプレイ**：LoLのリプレイを起動し、UIの「リプレイを開く」から.roflを選ぶ。「試合全体スキャン」で接続、10人取得、スキャン完了と件数を確認する。接続不能ならログとゲーム側状態を記録する。
3. [ ] **シーン**：キル／アシストを切り替える。行のチェックと行の選択が別に動くこと、タイムラインのシーンを押すと同じ行に移ること、全選択／全解除が出力対象に反映することを確認する。
4. [ ] **12候補の状態保持**：シーンとチェック、キル前／後、カメラモード、BLUE/RED、Work枠を設定して12候補を巡回する。どの候補に戻っても値が残ることを確認する。
5. [ ] **ミラーとカメラ**：「ミラー」開始で実映像と状態が出ることを確認する。手動→固定視点＋自動構図→フルオート、BLUE/RED、TargetLockと既存10視点を試す。上下反転、対象外れ、FX反映時のフレームレートを記録する。144Hzは設定目標であり、実測FPSと区別する。
6. [ ] **枠・FX**：案6の実素材画像または全素材図鑑から枠を選ぶ。同名FXの連動、弱／強、6登場アニメを確認する。正式合格と確認用の表示を確認し、未合格素材を品質合格と扱わない。演出確認と出力のキル瞬間を見比べる。
7. [ ] **書き出し**：詳細設定でGPU/NVENC、ゲーム音、出力先を確認する。チェックした1シーンを1920×1080・60fpsで書き出し、画角、フレーム、音、映像の同期を確認する。必要なら既存のカメラ＋Work素材一括QAと診断ZIPを実行する。

比較中は、案番号、画面サイズ、表示倍率、LoLリプレイ名、対象サイド、選択シーン、問題が起きた操作を控えてください。このリポジトリに保存した自動スクリーンショットは**LoL未接続**のUI表示確認です。実機のミラー、録画、音声、NVENCの合格証拠ではありません。
