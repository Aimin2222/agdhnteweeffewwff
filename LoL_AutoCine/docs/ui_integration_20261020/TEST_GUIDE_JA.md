# UI比較版のテスト手順

上部のプルダウンで9案を切り替えます。LoL未接続時の映像欄は「UI参考静止画」と明記したモック画像です。これは実映像でも処理成功の表示でもありません。ミラーを起動すると実際のLoL映像へ切り替わります。詳細設定を開くと従来画面が別窓で表示されます。設定とシーン選択は同じAutoCineアプリで共有します。

配布ZIPは**フォルダごと展開**し、`LoL_AutoCine.exe`を起動してください。`_internal`をEXEから離さないでください。Python環境を持つ開発者は従来の`START.bat`も使用できます。

1. [ ] **起動・表示**：9案を1→9の順に開き、中央ミラー、左右ペイン、下部タイムラインが表示されるか確認する。6案では「ライブラリ／編集」を切り替え、検索・テーマ・品質・前後ページを試す。1920×1080、1366×768、表示倍率125%でプレビューが設定のスクロールに巻き込まれないことを見る。
2. [ ] **リプレイ**：LoLのリプレイを起動し、UIの「リプレイを開く」から.roflを選ぶ。「試合全体スキャン」で接続、10人取得、スキャン完了と件数を確認する。接続不能ならログとゲーム側状態を記録する。
3. [ ] **シーン**：キル／アシストを切り替える。行のチェックと行の選択が別に動くこと、タイムラインのシーンを押すと同じ行に移ること、全選択／全解除が出力対象に反映することを確認する。
4. [ ] **9案の状態保持**：シーンとチェック、キル前／後、カメラモード、BLUE/RED、Work枠を設定して9案を巡回する。どの案に戻っても値が残ることを確認する。
5. [ ] **ミラーとカメラ**：「ミラー」開始で実映像と状態が出ることを確認する。手動→固定視点＋自動構図→フルオート、BLUE/RED、TargetLockと既存10視点を試す。上下反転、対象外れ、FX反映時のフレームレートを記録する。144Hzは設定目標であり、実測FPSと区別する。
6. [ ] **枠・FX**：案6の実素材画像または全素材図鑑から枠を選ぶ。同名FXの連動、弱／強、6登場アニメを確認する。正式合格と確認用の表示を確認し、未合格素材を品質合格と扱わない。演出確認と出力のキル瞬間を見比べる。
7. [ ] **書き出し**：詳細設定でGPU/NVENC、ゲーム音、出力先を確認する。チェックした1シーンを1920×1080・60fpsで書き出し、画角、フレーム、音、映像の同期を確認する。必要なら既存のカメラ＋Work素材一括QAと診断ZIPを実行する。

比較中は、案番号、画面サイズ、表示倍率、LoLリプレイ名、対象サイド、選択シーン、問題が起きた操作を控えてください。このリポジトリに保存した自動スクリーンショットは**LoL未接続**のUI表示確認です。実機のミラー、録画、音声、NVENCの合格証拠ではありません。
