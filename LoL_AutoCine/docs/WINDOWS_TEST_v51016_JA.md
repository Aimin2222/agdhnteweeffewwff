# Windowsまとめてテスト v5.10.16-test

完全版ZIPを旧版と別フォルダへ展開しSTART_GPU.bat。旧設定・録画は保存。今回目安は各短い同一シーンで比較し、成功/失敗と所要時間をメモする。

1. 旧settings.jsonを読み、色/カメラ/DOF/キル素材と「一気に表示」が再現するか確認。ミラーONでスクロール・タブ・スライダー・チェックhoverが止まらないか確認。
2. キル表示を同じシーンで6種類（瞬時、左右、上下、pop）書き出し。登場方向・時間・画面内位置を確認。TEST_GPU_RENDER.batの終了画面/ログでエフェクトGPU confirmedとNVENCを別々に確認。CPU比較も同じ設定で行い、色・モーション・LoL音声・60fps・長さが一致するか確認。
3. 円形DOF/従来帯DOFを中央/右側から交互に切替、排他表示と値保持を確認。色や素材旧名を読み込めるか確認。
4. BLUE/REDで通常三人称・三人称シネマ・FPS・Lolnam風を確認。プレビュー→再選択→seekで突然反転しないか、俯角/追従/手動0・180度/TargetLockが保たれるか確認。別リプレイへ変え古いカメラ/スキャンを引き継がないか確認。
5. 接続→試合全体スキャン後に8本録画QAを押す。RED4/BLUE4と10切替のMP4・results.jsonが作成され、切替で新たなLoL録画が始まらないか確認。カメラ・LoL音声・長さ・60fpsを再生で確認。未検出の片側では案内が出るか確認。
6. 通常書き出し・全検出シーン・チェックシーンを各1回。開始準備でUIが止まらず、終了でミラーが復帰するか確認。QA中止は次ケース停止を確認。切替中止は実行中1本の終了後に残り停止する仕様。

失敗時はボタン/設定/何秒後かをメモし、AutoCine_Diagnostics.zipとQA results.jsonをこの会話へ添付。音声に他アプリが混ざるかはDiscord等を鳴らしLoL音声だけの録音で確認。録画や個人ログをGitHubへ無断公開しない。GPU計測はタスクマネージャーのVideo Encode/Decode/Computeの各グラフも確認し、CPU使用率だけで判断しない。
