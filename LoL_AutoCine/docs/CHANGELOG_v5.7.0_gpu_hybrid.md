# LoL AutoCine v5.7.0 GPU Hybrid

## 目的
GPUを主経路にしつつ、CUDA/CUVIDの環境依存エラーで書き出し全体が停止しないハイブリッド構成へ変更。

## 変更
- CUDA/CUVIDデコードを強制しない。
- FFmpegの `scale_cuda` が利用可能な環境ではGPUスケールを使用。
- GPUスケール後は `hwdownload` して既存CPUフィルターへ安全に接続。
- H.264出力はNVENCを優先。
- GPU機能が利用できない場合はCPU処理へ自動フォールバック。
- UIへGPUパイプライン状態を表示。
- ライブUIプレビュー更新を約60Hzへ制限し、スクロール時の負荷を低減。

## 注意
現在のFFmpegフィルター群にはCUDA版が存在しないエフェクトも多いため、すべてのエフェクトを強制的にGPU化していない。GPU対応フィルターが確認できる箇所だけGPUへ送り、その他はCPUで処理することで安定性を維持する。
