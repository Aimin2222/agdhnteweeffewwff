## 用意するもの・起動

1. Full ZIPを旧版と別の短いフォルダへ展開する。録画・既存設定を上書きしない。
2. Python 3.12の64bit版とpyランチャーを用意し、LoL_AutoCine内のSETUP_DEV_ENV.batを実行する。検証に使った依存の固定一覧はrequirements-recovery-20261018.txt。ZIPはソース配布で、Python・C++ Build Toolsを内包しない。
3. START.batで起動。Native Audio Helper未配置なら、既存のBUILD_AUDIO_HELPER/Build Tools導入フローが必要。初回には管理者確認や大きなダウンロードが発生しうる。本環境ではHelperの再ビルド・LoLプロセス録音は未検証。
4. 同じパッチで再生できるリプレイ、BLUE/RED双方の対象プレイヤー、単独キルと連続キルを用意する。ゲームクライアント・録画先の空き容量も確認する。
5. NVIDIAドライバーを確認。検証機ではGTX 1070 TiのNVENCが動作。標準FFmpegにprogram_openclがないためCPUエフェクトへ戻る。START_GPU.batなど既存経路は維持しているが、追加FFmpeg導入の成功を本版の結果とは扱わない。

## 新しい設定の操作

かんたん作成の「カメラ制御」で、従来の手動／固定視点＋自動構図補正／フルオートシネマを選ぶ。古い設定を読み込んだ最初は「既存プロジェクトの設定を維持」と表示し、勝手に新制御へ移行しない。

固定自動は既存のカメラ種類を維持する。フルオートは録画前のクリップ境界でだけ種類を選ぶ。自動候補は設定画面のBLUE/RED別QA登録に限定し、初期は空。候補がなければ選択中の固定視点へ戻る。QAチェックは自分が映像で確認した視点だけに付ける。自動テスト成功を視覚QAへ転記しない。

「Workキル素材・アニメーション／カメラ自動選択を設定」を開き、正式合格のNo.083 Aを選択する。登場アニメーションは既存6種類、位置・サイズ・表示秒数は従来のキル装飾設定を使う。Workをオフにすると既存37バッジの経路へ戻る。

未合格の確認スイッチを入れると651候補・35演出を表示する。35演出の弱=.45倍／強=1倍は明示選択時だけ使用する。未合格候補の肖像穴は未検証のため、原画見本だけを表示し、合成出力は拒否する。穴を推定して誤った完成品を作らない。

配置確認のDEMO肖像は仮画像。実ミラー・出力は対戦ロスターから一致した本物のチャンピオン画像を使用し、取得できなければ省略する。ミラーはキャッシュ済み画像を使用するため、初回出力での画像取得後に確認するとよい。ミラーはリプレイ時刻、動画は既存の出力イベント時刻を使う。再生速度変更中の同期は実機で別途確認する。

## 実機テスト

同じリプレイ・対象・キル・設定で旧版と新モードを比較し、設定画面、動画、diagnosticsを一組にする。

- BLUE/RED×既存全10種類。各種類を同じ対象で2回選択し、0/90/180度も確認する。
- BLUE6/9/10、RED1/3の既知症状を再現し、良好だったRED2/4/5と斜め後ろ三人称を比較する。過去番号と今回の対象・種類・時刻を対応付ける。
- 固定自動で種類が変わらないこと、人物の中心位置・追従・地面/空の占有・上下反転・遮蔽物・急な角度変化を確認する。
- QA登録済み候補を1種類ずつ増やし、フルオートの単独キル／連続キル、クリップ境界、理由ログ、候補なし時の復帰を確認する。
- No.083 Aで6アニメーション、キル前/瞬間/後、連続キルと4件以上の3行整理、肖像穴、中央装飾、発光順を確認する。表示はアイコン×アイコンのみ。
- ミラーと出力で同じイベントの時刻・行・位置が一致すること、1080p60、実時間、NVENC、LoL音声、HUD復帰、キャンセルを確認する。カメラ＋Work表示を同時に動かす。
- 未合格表示をオフにして35演出が解除されること、旧37バッジ・手動調整・GPU/音声/HUD/UIが残っていることを確認する。

異常時はCOLLECT_DIAGNOSTICS.batで収集する。SMART_CAMERA_DECISION/FALLBACK、CAMERA_QA_*、work_kill_compositor、エンコーダーの記録を確認する。実動画と個人情報を含む生ログは公開Gitへ自動追加しない。
