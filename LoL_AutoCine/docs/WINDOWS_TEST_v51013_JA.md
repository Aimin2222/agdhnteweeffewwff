# Windowsまとめテスト v5.10.13

新ブランチのCode→Download ZIPで取得し、旧版と別フォルダへ展開。LoL_AutoCine/START_GPU.batを実行。旧フォルダの設定/プロジェクト/録画は保存したままにする。GPU処理を切った比較はSTART_CPU_EFFECTS_COMPARE.bat。

1. リプレイ接続→10人取得→試合全体を一括スキャン。表示プレイヤーをBLUE/REDへ切替し、一覧・対象ラベル・カメラ対象が一致するか。キル/アシスト/両方、チーム表示、チェックON/OFF、移動と選択2シーン作成を確認。対象切替で再スキャンを開始しないこと。中断後の再スキャン、再接続後の古い一覧消去も確認。
2. BLUEとREDそれぞれ三人称追従/三人称通常/FPS/Lolnamで短い1シーンを書き出す。自動、手動ブルー/レッド基準、スマート構図ON/OFFで対象が画角中心に残るか、壁/地面/逆向きにならないか。RED自動192°は暫定なので、悪化した場合は手動基準で比較しカメラ名・対象チーム・設定を報告。
3. 素材37種類が一覧にあり、旧素材と追加01/08/16で本物のキラー/被害者アイコンが入るか。プレビューと書き出しで大きさが一致するか。発光OFF/弱/強、角の光、行間0/12/36を同シーンで比較。色・解像感・3行表示を確認。
4. ミラーON、品質「操作優先」でスライダー/色/タブ/スクロール。図鑑で実シーン保存→検索→拡大→適用。補正前/後が同じ実画像で、拡大待ち中も操作できるか。「表示サイズで確認」は必要時に比較。
5. 1080p60fpsの1シーンと選択2シーンでカラー・正常な再生速度・長さ・LoLだけの音声・同期を確認。タスクマネージャーのGPU Compute/Video Encodeと診断のconfirmed/fallbackを併せて確認。NVENCだけではGPUエフェクトの証明にならない。
6. アプリの「自動診断」とRUN_AUTOTEST.batを実行し、失敗項目があれば記録。GPU実行の比較はアプリを閉じてTEST_GPU_RENDER.bat、同じ短いraw動画で6ケースを実行。起動ログ・結果JSONはdiagnosticsに残る。

結果はCOLLECT_DIAGNOSTICS.batのZIPと「操作/対象チーム/カメラ/素材/ミラー品質/良否」を送ってください。カメラ問題は該当する短い映像も有用です。LinuxではWindows/NVIDIA/LoL実機の映像・音声・速度を確認していません。
