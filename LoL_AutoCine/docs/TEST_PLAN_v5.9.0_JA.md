# Windows 実機テスト手順 v5.9.0

**前準備**：v5.8.4/5.8.5安定版は保管し、この版は別フォルダに展開。LoLリプレイ開始。対象プレイヤー固定、出力先を確認。

1. **起動・検出**：`START.bat`で起動、リプレイAPI接続→スキャン→右のシーン選択で中央の選択表示と曲線グラフが変わるか。
2. **従来経路（最重要）**：「シーン別演出」はOFF、エフェクトOFFでチェックした1シーンのみ作成。カラー・LoLゲーム音・1080p MP4・カメラ追従を確認。
3. **個別編集**：1シーン選択→Orbit=20 / Dolly=5 / 角度+30 / キル前5秒→「このシーンに保存」。対象シーン左に✎が表示されるか。シーン別演出ONでチェックしたその1シーンを書き出し、ログに`SCENE_PLAN`が出るか。
4. **Undo/Redo**：「元に戻す」で解除され、「やり直す」で✎が戻るか。
5. **プロジェクトJSON**：保存→アプリ再起動→自動復元 or 明示的読み込み→編集値の保持。
6. **スマート自動編集**：新しい`✨ スマート自動編集`を1回押し、自動スキャンから書き出しまで進むか。マルチキルのシーンでは `dynamic` が選ばれるか。LoL音声・カラーを確認。
7. **2シーン選択**：チェックした2シーンのみ作成。二重起動・応答停止・音声抜けがないか。モンタージュONならつながるか。
8. **GPU連携**：診断ZIPでNVENCとGPU/CPU経路の記録を確認。GPUエフェクト自体はCodex側の別テストになる。

**送ってほしいもの**：動作OK/NGの一言、問題発生時の `diagnostics` ZIPと何番のテストか。テスト中のCPU/GPU使用率手動採取は不要。

**注意**：シーン別モードは1シーンごとに書き出すので、隣接キルの結合挙動は通常経路と異なる。自由キーフレーム編集は今回未実装。
