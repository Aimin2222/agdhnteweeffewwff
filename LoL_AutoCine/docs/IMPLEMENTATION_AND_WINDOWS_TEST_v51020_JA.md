# LoL AutoCine v5.10.20 テスト版 — モード別カメラ・UI不具合修正

## この版の状態
- 前版v5.10.19のスクリーンショット、`results(3).json` の数値およびユーザーの目視指摘を基に修正。
- 今回のChatGPTのコンテナ・Pythonは添付分割ZIPにアクセスするたびに InvalidArgumentError / ServerError を返したため、**アップロードMP4のフレームをこの場で解析したとは主張しません**。
- 最終的な戦闘シーンの映り・映像の再生品質はWindowsでの実機テストが必要です。

## 共通処理の原因候補と対策
同じカメラAPI初期化（`attach_to_player`）と`CameraPlan`計算器を5種類のカメラで共有。
以前の `_TPS_CALIBRATION[(selected_player,'third_common')]` は全三人称モードの成功補正値を同じ場所に保管していた。
そのため、通常3人称の7,000–8,000ユニット離れた古いカメラ参照や誤ったpitch軸が、続くシネマ/Lolnamに影響する可能性があった。
v5.10.20でキーを `(selection_name, team, style)` に分割。共通のGPU・音声・録画エンジンは維持。

## かんたん編集の色調整
- 「色だけ細かく調整する」はチェック直下にパネルを`pack(after=...)`する仕様へ変更。
- v5.10.19では本来のウィジェットが画面の最下部に追加されていたため、「押しても開かない」に見えた。
- ON: 強さ・暖かさ・メリハリ・鮮やかさ4種のスライダー＋数値入力。OFF: 隠すが設定値保持。
- A/Bテンプレート選択ボタン・詳細編集カラーと共有変数を維持。

## 自動動画テストの改善
- 「白く光るだけで同じ」に見えていたレガシー10種類から、**カット/白フラッシュ/黒暗転の3種類**を自動比較対象に厳選。
- 別系統の**真の空間切替**6種類（クロスフェード、左ワイプ、右スライド、円形展開、ピクセル化、上方向スムーズ）を引き続き生成。
- ユーザーが承認するまで空間切替6種類は通常動画エンコード経路に採用しない。参考版は無音。
- REDとBLUEの5本ずつ、1本にまとめた動画、3時点の比較シート、結果JSON、500MB以下の直接ZIPを自動出力。
- キルフレーム6種類は変更しない（ユーザーが合格を確認済み）。

## なぜGitHubを使うのか
CodexがGPU/WGC/NVENC/LoL録音の開発を並行していたため。上書き事故防止のために別ブランチ、GitHub Actions自動検査、Codex統合用差分の確認を残す。
「ユーザーの動画を自動でGitHubへアップロードする」意図はない。GitHub Actionsは動画のLoL実機映像を再生できない。
このチャットのPython実行環境が回復すれば、GitHubに頼らずMP4からフレーム抽出して確認できる。
`MAKE_REFERENCE_SHEETS.bat` は環境未復旧の場合の代替策。MP4があるフォルダーをドラッグすると、全参考動画から6時点ずつのサムネイル集とJSONを `ReferenceReview_contact_sheets.zip` にまとめる。元の動画は削除しない。**外部への自動アップロードなし**。
