# 開発用CameraQA・各30MB以下の送信

通常録画と書き出しは1080p・60fpsの既存経路を維持する。カメラ座標・角度・FOV、LoLプロセス専用録音、GPU Fullの効果処理はこの変更では変えない。全カメラQAが完了した後、送信用だけ960×540・60fpsのMP4を作り、各ZIPを**30,000,000バイト以下**にする。古いリモート計画が500MBを指定していても上限は30MB。

送信用MP4は最大24MBを実容量で確認。NVENC優先、失敗時は制限ビットレートのCPUへ切り替え、実際の経路をresults.jsonのqa_uploadと診断に記録する。縮小は軽量なCPU bilinear。GPU処理だけで完了したとは表示しない。音声は既存MP4のAACを再エンコードせずコピーし、新しい録音・時間変更・映像効果の再適用はしない。元60fps映像の時刻とフレーム数をpassthroughで保つ。連結MP4の継ぎ目に小さな時刻の隙間がある場合も補間/フレーム追加をしないため、平均fpsは元と同じく60よりわずかに低い値になり得る。

元1080p動画・raw素材はPCに残す。ZIPには送信用最終MP4、比較画像、results.json、QA_Supportの説明と診断を入れ、rawと内部の.qa_uploadディレクトリーは入れない。ZIPのMP4は元動画と同じ相対名を使い、qa_upload.filesにサイズ・解像度・エンコーダー・失敗理由を記録。results.jsonの既存outputsはPC内の元動画のパスなので、解凍後はqa_upload.filesの相対名から動画を探す。画像と既存ピクセル指標は元1080pから作成するため、圧縮コピーの指標と厳密には同一にならない。

軽量化失敗時は元映像をそのまま梱包する。大きければ.mp4.part001等へ分割し、RESTORE_OVERSIZED_FILES.txtを同梱する。ZIP全partをそろえれば元動画を復元できる。この場合も各ZIPは30MB以下、失敗を隠さない。再実行時は新しいコピーと_export02等のZIPを作り、古いZIPを上書きしない。キャンセルは軽量化中のFFmpegを終了し、元動画を保持する。送信用コピーを追加するため、その分の空き容量は必要。

## 今回のWindows確認

1. 新しいフル版を旧版と別フォルダーに展開しSTART_GPU.batで起動。
2. 全カメラの開発用一括テストを1回実施。各part ZIPのプロパティで30,000,000バイト以下を確認。
3. 全partを同じ新しいフォルダーへ解凍。RED/BLUE各5モード、切替、登場FX、比較画像、results.json、QA_Supportがそろうことを確認。
4. 送信用MP4が540p/60fps、再生速度・音声・キル時刻が元動画と一致することを確認。results.jsonのqa_uploadがdev-30mb-540p60であることを確認。
5. 軽量化中の中止を1回確認。PCの元1080p・raw動画と以前のZIPが残ることを確認。
6. 通常の1シーン書き出しが1080p/60fpsのまま、LoL音声のみ・既存GPU経路を保つことを確認。
7. 新しい全part ZIPを会話へ添付し、最後に「完了」と送る。低解像度映像では最終画質の合格を判定しない。

## 以前の大きなQAを録画し直さず送る

既にPCにCameraQA_20261013_131223フォルダーがあれば、results.jsonがある**フォルダーごと**MAKE_CAMERAQA_UPLOAD.batへドラッグする。旧ZIPではなく元のフォルダーを使う。コマンドなら `python -m tools.make_cameraqa_upload "CameraQAフォルダーのパス"`。同じフォルダーに新しい30MB以下のZIPを作る。旧reportは.qa_upload内へバックアップ、旧ZIPと元動画は保持する。全てが低解像度化できたかqa_upload.filesを確認する。

## 最終アプリへの実装時に削除する対象

これはユーザーの指定による**一時的な開発用機能**。正式なアプリ配布前に、開発用一括QAボタン/起動経路、core/qa_upload.py、tools/make_cameraqa_upload.py、MAKE_CAMERAQA_UPLOAD.bat、camera_qa.pyの送信軽量化呼び出しと30MB専用制御、専用テスト/計画を除外または削除する。一般の録画・GPUエフェクト・音声・エンコードからこのアダプターを呼ばない構造なので、これらの本番機能を変えずに外せる。配布前チェックリストをdocs/APP_PACKAGING_PLAN_JA.mdへ追加した。現在は開発中のため使える状態を維持する。

Windows/LoL実機と物理NVENCの今回の動作はユーザー確認待ち。自動テストだけで映像構図の改善や最終画質の合格は宣言しない。
