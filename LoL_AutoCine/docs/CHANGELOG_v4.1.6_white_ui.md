# LoL AutoCine v4.1.6 — White UI Redesign

## UI変更
- 参考画像をベースに、白基調・薄いブルーアクセントの編集アプリUIへ全面再構成。
- 上部ナビゲーションを追加：ホーム / テンプレート / 参考動画 / 設定。
- 3ペイン構成へ変更：左=素材・ワークフロー / 中央=プレビュー・タイムライン・カメラ / 右=シネマ演出・出力。
- カメラプレビューを画面中央の主役として配置。
- LoLnam風シネマ設定、自動カメラモーション、出力設定を右側に集約。
- 詳細編集（基本 / カラー・FX / 録画・出力）は中央下部に残し、既存機能へアクセス可能。
- 参考動画URL取得、複数動画追加、参考テンプレート生成、リミックス機能を維持。
- プレイヤー取得、対象固定、キルスキャン、選択キル作成、全キル作成、モンタージュ、ログ、診断機能を維持。

## 互換性
- `core/` 以下のカメラ・録画・エフェクト・Replay API・音声処理ロジックは変更していません。
- UIから既存ハンドラを呼び出す構成を維持しています。
- `START.bat` から従来どおり起動できます。
