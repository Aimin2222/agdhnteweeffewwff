# LoL AutoCine v4.1.1 Reference Template

## 基準
`LoL_AutoCine_v4.1_白基調_v1.2カメラ統合` を基準版として維持。
カメラ (`core/camera.py`)、録画、FFmpeg書き出し、既存の白基調UIは置換していません。

## 追加
- 参考動画を複数追加して安全に管理
- 追加しただけでは解析しないため、動画追加時のクラッシュを回避
- 参考動画から色、テンポ、カット密度、フラッシュ傾向、シネマ枠、グレイン等を解析
- 解析失敗した動画はスキップし、成功した動画だけでテンプレートを作成
- 作成テンプレートは `templates/reference/*.json` に保存
- 参考テンプレート適用時も、現在の v1.2 カメラ設定を維持
- `REF-HERO / REF-CLEAN / REF-HYPE` の3種リミックスをワンクリック生成
- OpenCV必須ではなく、FFmpeg + NumPyだけで参考動画解析

## 既存
録画、60fps出力、内部144fps、BGM、ゲーム音、LUT、Fog、DOF、カーブ、
モンタージュ、三人称シネマ、地面安全ガード等は基準版のまま。
