# GPUミラー＋Workキル素材 一括テスト（2026-10-20）

ZIPを新しいフォルダへ一度だけ展開し、`LoL_AutoCine/START.bat` を起動する。旧版へファイルを貼り付けない。初回は依存ライブラリの準備に時間がかかる。既存設定と録画は保管し、原本89枚・既存37バッジ・Workブランチは変更しない。

## この版の範囲

- Work台帳から652キルフレーム候補と35エフェクト案（A/B/C/D、D31テーマ）を選択できる。6種類の登場方法と弱／強を維持。既存37バッジはWork素材オフ時に使える。
- 正式合格は静止画No.083 Aの1件。残る651候補と35演出案は未合格で、明示的に「確認・テスト用」をオンにした時だけ選べる。肖像穴が未検証の651候補は原画確認のみで、チャンピオン肖像との合成出力には使えない。正式合格数は自動テストでは増やさない。
- ミラー映像の縮小・対応済みの色／ぼかし／一部動画FXをOpenCV OpenCLでGPU優先処理する。非対応の粒子、カーブ、LUT、glitch/VHS/chroma系やOpenCL失敗は既存CPU表示へ戻し、画面とログに理由を出す。Tk表示、Workレイヤー、録画・最終書き出しは別経路。NVENC使用はミラーGPU処理や最終出力GPUエフェクト成功の証明ではない。
- No.083 Aのミラー合成は表示サイズで処理し、サイズ別の枠・肖像・演出をキャッシュする。素材のSHA検証と品質ゲートは維持する。

## まとめて行うテスト順

- [ ] **起動・画面**：`START.bat` で起動。「かんたん編集」「詳細編集」の両方で左側の参考動画カード、旧カメラ設定、既存37バッジ、HUD・音声設定が見える。
- [ ] **生ミラー**：LoLリプレイ表示中にミラー開始。FXオフ、画質「操作優先」で10秒間、止まり・遅延・黒画面を確認。GPU欄とログの「ミラー処理: OpenCL GPU (デバイス名)」またはCPU理由を記録。
- [ ] **FXミラー**：FXオンで色、Bloom、DOF、Vignette、シネマ枠、分割比較を順に操作し、UI操作の引っ掛かりと色・画面の破綻を確認。粒子またはLUTを選び、CPUフォールバック理由が出ることも確認。FPS値は完成MP4の60fpsとは別。
- [ ] **Work正式素材**：上部「Work素材」を開き「正式合格 No.083 A を選択」。未合格表示をオフにしたまま6種類の登場を確認し、キル時のミラーと1シーンのMP4で枠・肖像穴・中央装飾・発光・2人の本物のチャンピオンアイコンを見る。文字や`x1`が増えないことを確認。
- [ ] **Work演出案**：明示的に「未合格素材を確認・テスト用に表示」をオンにし、A/B/C/Dから各1案とD31テーマから1案をNo.083 Aと組み合わせて確認。弱／強、キル瞬間、連続キル、ミラーとMP4の前後関係を確認。未合格651候補は原画確認のみ。未合格演出を正式合格扱いしない。
- [ ] **カメラ**：従来手動、固定視点＋自動構図、フルオートをBLUE/REDで各1シーン。上下反転、プレイヤーの画面外れ、構図の急変、良好だったRED2/4/5の退行を確認。Windows実映像を見ないままカメラ合格と判定しない。
- [ ] **出力**：1920×1080・60fpsのキル1件と連続キルを出し、LoL音声の保持・同期、NVENC表示、エンコード終了、ミラー復帰を見る。最終出力のGPUエフェクト成否は別欄で確認する。
- [ ] **問題発生時**：症状と時刻を控え、`COLLECT_DIAGNOSTICS.bat` で同じフォルダにできる`AutoCine_Diagnostics.zip`を共有する。録画や診断にユーザー名・ローカルパスが含まれるためGitHubへ公開しない。

自動テストはGPUデバイス上の処理・素材台帳・品質ゲート・UI選択・出力合成を検査した。LoL実映像での見た目、体感遅延、音声、全652候補の品質合格は実機未検証。
