# Windowsで確認してほしいこと — v5.10.5

旧版を残し、完全版を別フォルダへ展開してSTART_GPU.batで起動してください。最初は従来の設定と同じ1シーンで試します。

1. **今回の重さ**：ミラーON・FX反映ONで、色温度/カラー/DOFのスライダーを連続で動かす。カラーとFXのタブを切り替え、ホイールでスクロールする。操作が固まらず、操作終了後に最新の設定が表示されるか確認します。簡易FXの表示は最大15回/秒です。
2. **ミラー切替**：ON/OFFを試し、OFFにした後で古い映像が復活しないこと、もう一度ONで表示できることを確認します。カメラ演出再生中のFXも確認します。
3. **録画**：60 FPS・Bloom+円形DOFでチェックした1シーン、次に複数シーンを書き出します。カラー、焦点、TargetLock、再生速度、LoLだけの音声と同期を確認します。書き出し中のミラーには重い簡易FXをかけません。
4. **UI側の追加**：キルフレーム画像の確認、発光ON/OFF、強さ0.2/1.0、説明「？」、近接キルの最大3段表示を確認します。
5. **サイド別カメラ**：ブルー/レッドの対象で自動基準、手動ブルー/レッドを試し、被写体が中心から外れないか確認します。

終わったらCOLLECT_DIAGNOSTICS.batのZIPと、どの操作がまだ重かったかを送ってください。スライダーは追従したか、映像更新だけ遅かったかを分けると原因を絞れます。録画/加工FPS、GPUエフェクト実行、NVENC、エラーをログで照合します。

LinuxのGUI/FFmpeg回帰テストと、WindowsのWGC・音声・実GPUの確認は別です。この統合版の実機動作と改善率はまだ未確認です。
