# Phase 2: Functional White UI

Phase 1で作った白基調UIを、既存のLoL AutoCine機能へ段階的に接続した版です。

## 接続済み
- Replay API / game.cfg
- `.rofl` リプレイ選択・再生
- 最近のリプレイ
- プレイヤー取得・対象固定
- キルスキャン
- キル一覧 / 選択キル移動
- 選択キル作成 / 全キル作成
- 参考動画URL / ローカル動画
- 参考動画テンプレート生成
- HERO / CLEAN / HYPE リミックス
- テンプレート適用
- 三人称 / シネマ / FPS / 固定カメラ
- Orbit / 自動モーション
- ミラー
- カラーグレードと数値スライダー
- Fog / カーブ / DOF
- BGM / LUT / ゲーム音声
- 出力FPS / 出力形式
- プログレス / キャンセル / 出力フォルダ
- ログ / 診断

## 互換性
`core/` はPhase 1から変更していません。元の処理を優先して利用します。
