# v5.0.2

## クリップ速度
- 録画中の実時間を基準に、完成MP4の再生時間を正規化。
- WGC/FFmpegのフレームタイミングずれで8倍速などになるケースを補正。
- 正規化後の時間軸をカラーFX・音声合成にも使用。

## 音声
- デスクトップ全体のループバックを廃止。
- LoLプロセスの音声だけをProcess Loopbackで取得。
- ネイティブWASAPI処理は子プロセスに隔離し、GUIクラッシュを防止。
- LoL音が取得できない場合、Discordやブラウザ音を混ぜず映像のみ続行。

## カメラ
- 既存のOrbitTargetLockの座標系・3人称追従ロジックは変更しない。
- Lolnam風自動Orbit / ドリー / ローアングル / FOV / キル前後の補間 / マルチキル時のワイド化を維持。
