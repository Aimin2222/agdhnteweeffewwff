# LoL AutoCine v4.0 設計書

## 1. 目的

lolnamを参考に、編集項目を残しながら「操作数を減らす」ことを最優先したLoLキルクリップ自動生成ツールを完成版として構成する。

既存設計のReplay API差分送信・レート制限、キル位置への自動移動、144fps取り込み→60fps出力、HUD復元、ゲーム音、lolnam系カラー/Fog/DOF、ワンクリックテンプレートを維持する。

## 2. lolnamから参考にしたUX

- プレビューを中央の主役にする
- 編集項目を右側へ集約
- カラー/Fog/カーブ/DOFを同じ編集エリアで扱う
- プリセットを先に選び、細かい調整は必要な場合だけ行う
- 数値入力ではなくスライダー中心
- 編集結果を確認してから書き出せる

lolnamそのものを再実装するのではなく、AutoCine固有の「リプレイからキルを自動抽出する」ワークフローを優先する。

## 3. UI構成

```text
┌───────────────────────────────────────────────────────────────────┐
│ LoL AutoCine        ステータス                 設定/診断          │
├───────────────────────────────────────────────────────────────────┤
│ かんたん編集  [テンプレ] [自然/標準/強め]       [LoLを準備] [★自動作成] │
├─────────────┬─────────────────────────────┬───────────────────────┤
│ 1 準備      │ プレビュー                  │ 4 編集                │
│ 2 対象      │                             │ [かんたん]             │
│ 3 スキャン  │                             │ [カラー]               │
│             │ キル一覧                    │ [カメラ]               │
│             │ ログ                        │ [録画・出力]            │
└─────────────┴─────────────────────────────┴───────────────────────┘
```

### 左
手順を固定して迷いにくくする。1. Replay API設定/リプレイ起動、2. 10人取得/プレイヤー固定、3. 全編スキャン。プレイヤーはダブルクリックでも固定可能。

### 中央
映像確認を最優先にする。ミラー、編集プレビュー、カメラ演出確認、キル一覧、選択キル移動、個別作成、全キル作成、ログを集約する。

### 右
編集を「かんたん / カラー / カメラ / 録画・出力」の4カテゴリに整理する。

## 4. 自動処理

```text
リプレイ → Replay API → 10人取得 → 対象固定 → 全編スキャン → キル抽出
→ キル3秒前へシーク → カメラ配置 → HUD非表示 → 144fpsキャプチャ
→ 60fps化 → カラー/Fog/DOF/タイトル → ゲーム音mux → MP4 → 任意でmontage
```

## 5. 安定性

- renderは変化した値だけ送信
- renderは既定20Hzでレート制限
- playbackは速度変更時だけ送信
- HUDは既に非表示なら再送しない
- 接続拒否はReplayGoneErrorとして扱う
- 作成済みクリップを残して安全中止
- UIスレッドに例外を出さない

## 6. カメラ

標準は三人称追従。tps / follow / fps / cinema / orbit / topを対応。
キル位置へ自動移動し、地面埋まりをAPI/フレームの2段階で確認する。topでも対象プレイヤーを追従する。キル瞬間に被害者へ切り替える自動カーブも利用可能。

## 7. 映像

取り込み144fps、最終60fps。WGCでLoLウィンドウだけを取得し、最新フレームを保持する。

## 8. 音声

v4.0ではLoLプロセス音を第一候補にする。

1. WASAPI Process Loopback
2. 失敗時は通常のWASAPIデスクトップループバック
3. それも失敗した場合は録音失敗として無音継続

プロセスループバックはLoLのPIDを取得して対象プロセスツリーを録音する。Windows 10 2004以降を想定する。

## 9. lolnam系編集

グレード、色温度、コントラスト、露出、自然な彩度、ビネット、グレイン、ブルーム、シネマ枠、LUT、Fog presets、カーブ、DOF、フラッシュ/フェード等の切替を搭載。

手動キーフレームは対象外。キル時刻を基準とした自動カーブで処理する。

## 10. 出力

既定: `%USERPROFILE%\\Videos\\LoL_AutoCine\\<player>_<champion>\\`

raw録画は残す。同名ファイルは上書きしない。

## 11. 設定

APIキーを要求しない。game.cfgへReplay API設定を書き込む際はバックアップを作成する。

## 12. テスト

Replay API mock、render throttle、camera height、top追従、出力名重複、タイトル空欄、lolnam系フィルタ、ワンクリック、日本語パスを対象とする。

v4.0リリース時点で既存回帰テスト7件が成功することを確認する。

## 13. 制約

- Xの参考動画は直接取得できないため、その動画そのものの完全再現ではない
- 手動キーフレーム編集はない
- WASAPI Process LoopbackはWindows環境差があるため自動フォールバックする
- 実機のLoLリプレイ/API環境によってカメラ対応差がある

## 14. 完成版の判断基準

普段は「プレイヤーを選ぶ → テンプレを選ぶ → 自動作成」の3操作を中心にし、高度な編集をしたい場合だけ右側の詳細設定へ入る構造とする。
