# LoL AutoCine v4.0 CHANGELOG

## v4.0.0
- lolnamを参考にUIを再設計
- プレビュー中心の3カラム構成
- 編集項目を「かんたん / カラー / カメラ / 録画・出力」に整理
- ミラー開始/停止を1つのトグル操作へ統合
- プレイヤーのダブルクリック固定を追加
- 「選択キルへ移動」を追加
- 「選択キルだけ作成」を追加
- 上部にワンクリック操作を集約
- Replay APIキー不要の導線を明示
- LoLプロセス音声を優先するWASAPI Process Loopbackを復元
- プロセス音声が使えない場合はデスクトップ音声へ自動フォールバック
- フォールバック理由をログへ表示
- START_HEREをv4.0向けに更新
- 設計書/使い方ガイドを追加

## v4.1.0 - v1.2カメラ統合
- v1.2の三人称カメラ (`third_cinema` / `third`) を復元
- キル前後のスロー / FOVズーム / ドリーインを復元し、マルチキル時は各キル時刻へ追従
- 三人称のローアングル＋寄り演出と地面埋まり防止を復元
- 追従設定を1秒ごとに再送するハートビートを復元
- v1.2のゲーム内Fog / DOFをReplay API経由で録画・プレビューへ統合し、終了時に元設定へ復元
- v4.1白基調UIは維持し、三人称仰角・距離をカメラ設定から調整可能に変更
- 選択キル移動時の不正な `tps` 呼び出しを三人称カメラ経路へ修正
- v4.1既存回帰テスト7件 + カメラ安全性チェックを確認
