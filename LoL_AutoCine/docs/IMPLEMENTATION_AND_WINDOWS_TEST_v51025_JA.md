## この版の唯一の映像動作変更
`core/camera_tuning.py` の `("BLUE","third")` の**X方向の小幅な見上げ角**を `+3.0° → -2.0°` に変更（差は -5°）。BLUE側のX軸は仰角であり、視線を少し上に向けると被写体がフレーム内で下側に移動することを狙う。Zロールは常時0のまま。距離倍率1.10、キル瞬間カメラ移動パターン、追従座標、カメラ速度、FOV、ゲーム音、エフェクト、GPU処理、その他9モードは変えない。画角の改善は**Windows実機で未確認**。

回帰テストはBLUE6の各時点で角度のみ5°変わりカメラオフセットが同一であること、他9モードの距離/方位バイアスがv5.10.24と変化していないことを確認する。

## 配布と安全性
- 既存のCodex GPU Full PR #29、Codex録画/ネイティブゲーム音/非同期プレビュー、TargetLock機能を上書きしない。
- GitHub ActionsでWindows BAT実行、Pythonの構文チェック、UTF-8検査、Xvfb回帰テスト、ZIP妥当性とSHAを検証し成功した時のみユーザーへ配布する。
- 配布はWindowsテスト用フルZIP、Codex統合用差分ZIPの**別々の2ファイル**。ZIPの中にZIPを含めない。
