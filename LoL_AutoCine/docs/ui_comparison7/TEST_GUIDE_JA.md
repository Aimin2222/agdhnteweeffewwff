# AutoCine 7案 Windows UI比較テスト

このZIPを展開し、`LoL_AutoCine_UI29.exe`を起動します。名称は従来との互換性のため維持していますが、比較対象は7案です。外部ブラウザは不要です。`LoL_AutoCine.exe`は従来UIとして同梱しています。

## 比較する7案

1. 旧テストB カメラ・FX
2. 旧案3 ハイブリッド
3. 旧テストA 現行整理
4. 旧案6 ライブラリ・編集
5. 新E Flow
6. 旧案2 標準編集
7. 旧案5 ウィザード

起動直後に候補を選びます。画面右端の「UI比較」または `Ctrl+Shift+U` で切り替えます。各候補でメイン、詳細編集、素材を確認してください。旧案2・旧案5・旧テストAの詳細画面と、元画像に素材専用画面がない案の素材画面には「補完」と表示します。これは原画像を忠実再現したという意味ではありません。

## 操作確認

1. 候補を切り替え、シーン選択・カメラ数値・枠の選択が保持されるか確認します。
2. メイン → 詳細編集 → 素材 → 詳細編集 → メインをたどります。
3. LoLリプレイを開き、試合全体スキャン、BLUE/RED、TargetLock、ミラーの順に確認します。LoL未接続時は実映像を表示しません。
4. カメラ、FX、枠、登場アニメを選び、演出プレビューと出力を確認します。
5. 1920×1080、1366×768、Windows表示倍率125%で文字の重なりや画面外のボタンを記録します。
6. 問題があれば候補名、画面、押した操作、時刻、スクリーンショット、ログを保存します。

## 合否の扱い

オフラインでの画面遷移や状態保持の合格は、LoL実機、GPU/NVENC、ゲーム音声、録画、MP4の合格を意味しません。対象PCでそれぞれ確認してください。比較版は最終採用UIではなく、7案の操作性を選ぶためのものです。
