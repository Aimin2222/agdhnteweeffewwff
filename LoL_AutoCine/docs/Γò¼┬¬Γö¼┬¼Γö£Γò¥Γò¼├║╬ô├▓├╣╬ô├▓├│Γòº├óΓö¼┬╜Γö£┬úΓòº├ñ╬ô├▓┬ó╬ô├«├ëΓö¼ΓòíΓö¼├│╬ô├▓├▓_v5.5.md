# LoL AutoCine v5.5 要件定義書

## 1. 目的

LoLリプレイから、ゲーム内の対象プレイヤーを固定してキル・アシスト周辺のシーンを自動検出し、LoLnam系のシネマティックなカメラ演出、色・Fog・カーブ・DOF等の映像効果を適用した1080p MP4を、専門的な動画編集知識がなくても作成できるWindows向けデスクトップアプリを提供する。

本バージョンでは「動画編集ソフトのように見やすく細かく調整できること」と「誰でも迷わず動画を作れること」を両立する。

## 2. 基本方針

- UIは添付参考UIの白基調3ペイン構成をベースとする。
- 中央のLoLミラー／カメラプレビューは常時見える領域とし、下側の編集領域だけをスクロール可能にする。
- 中央プレビューと編集領域の境界は上下ドラッグ可能なスプリット表示とする。
- 左側は「参考動画・テンプレート・リプレイ準備・対象選択・検出」のワークフローをまとめる。
- 右側は「カラー・FX・カメラ・LoLnam演出・検出シーン・出力」をまとめ、必要時に縦スクロールできる。
- 数値を持つスライダーは、スライダー操作と直接数値入力の両方に対応する。
- 初心者向けに「★これで自動作成」を常に利用できるようにする。
- GPUを第一優先とし、NVIDIA環境ではNVENC/CUDAを利用する。GPU非対応フィルタはCPUへフォールバックする。
- LoLゲーム音声はLoLプロセス単位で取得し、最終MP4へ確実にmuxする。

## 3. ユーザー像

### 3.1 初心者

- リプレイを開く
- 対象プレイヤーを選択
- 自動作成を押す

だけで基本動画を完成できること。

### 3.2 中級者以上

- キル／アシストの選択
- シーン選択
- カメラOrbit
- カメラ演出カーブ
- 色補正
- Fog
- DOF
- BGM/LUT
- 出力FPS
- 出力先

を個別に調整できること。

## 4. 機能要件

### 4.1 リプレイ

- Riot Replay APIへの接続
- .roflリプレイの起動
- 最近のリプレイ表示
- プレイヤー一覧取得
- 対象プレイヤー固定

### 4.2 シーン検出

- キル検出
- アシスト検出
- キル＋アシスト検出
- 検出シーン一覧
- チェック／解除
- チェックしたシーンだけ作成
- 選択シーンへ移動
- 全シーン一括作成
- マルチキルの結合

### 4.3 カメラ

- 三人称通常
- 三人称シネマ
- FPS風
- LoLnam風シネマ
- TargetLock
- Orbit
- 自動Orbit
- ドリーイン／アウト
- FOV変化
- ローアングル
- キル前／瞬間／キル後の連続演出
- 0/90/180/270度付近でも対象を失わないこと

### 4.4 滑らかさ

- カメラモーション計算は最大144Hzで内部補間する。
- Replay APIへのHTTPアクセスは60Hz以下に制限し、API待ちで144Hzループが停止しないようにする。
- 再生時間はmonotonic時計で連続補間し、定期的にReplay APIの実時間へ補正する。
- キル瞬間のFOV、速度、距離、Orbitを急変させない。
- 60fpsまたは144fpsのCFRで映像を生成する。
- LoLミラーのUI更新は144Hzを目標とする。

### 4.5 プレビュー

- LoLミラー表示
- 144Hz更新を目標
- 再生／停止
- 1枚更新
- 編集中の見た目を反映
- ミラーは編集エリアをスクロールしても消えない
- 上下スプリッターでプレビュー領域を変更可能

### 4.6 映像効果

- カラーグレード
- 色温度
- コントラスト
- 露出
- Vibrance
- Vignette
- Grain
- Bloom
- シネマ枠
- Fogプリセット
- トーンカーブ
- DOF
- LUT
- トランジション

### 4.7 カーブ

- ヒストグラム表示
- グリッド表示
- 基準対角線
- 制御点追加・ドラッグ
- 数値編集
- LoLnam参考スクリーンショットに近い操作感

### 4.8 音声

- LoL音声のみを優先取得
- Windowsのプロセスループバックを優先
- 利用できない場合はLoL以外を録音中だけミュートするフォールバック
- 録音WAVを検証
- 最終映像とは別工程でゲーム音をAAC muxし、映像filterによる音声消失を防ぐ
- BGM利用時はゲーム音を優先してダッキング

### 4.9 GPU

- NVIDIA NVENCを優先
- CUDAデコード／GPUリサイズを可能な範囲で利用
- NVENCがない場合はCPUエンコードへフォールバック
- GPU状態をUI表示
- GPU利用を基本経路とする

### 4.10 出力

- 16:9
- 1920x1080
- MP4
- 標準60fps
- 必要に応じ144fps
- 出力フォルダ選択
- 出力フォルダを開く
- モンタージュ生成

## 5. UI要件

### 中央

```text
┌─────────────────────────────┐
│        LoL ミラー            │
│       カメラプレビュー        │
├════════════ ↕ ═══════════════┤
│      タイムライン             │
│      カメラ設定               │
│      エフェクト設定           │
│      カーブ補正               │
│      その他                   │
│        ↕ スクロール            │
└─────────────────────────────┘
```

- 上段はスクロールしない。
- 下段のみスクロールする。
- 境界をドラッグして上下比率を変更できる。

### 右側

- 検出シーンカードのチェック切替・選択シーン移動・作成ボタンは同一カード内で切れない配置とする。
- 右パネル全体は縦スクロール可能。

## 6. 初心者向け導線

- 「★ かんたん作成」を目立つ位置に表示する。
- 主要な3ステップを画面内に明示する。
- 高度な設定を触らなくても標準テンプレートで完成する。
- 高度な設定は後から変更可能。

## 7. 非機能要件

- Windows 10/11を対象とする。
- 日本語UI。
- UTF-8のMarkdown・設定ファイルを使用し、日本語文字化けを防止する。
- 1つのクリップの失敗でアプリ全体を終了させない。
- 音声やReplay APIの失敗原因をdiagnosticsへ記録する。
- 出力動画はCFRとし、可変フレーム時間によるガクつきを抑える。

## 8. 受入基準

1. 編集設定を下へスクロールしてもLoLミラーが表示されたままである。
2. 中央の境界をドラッグしてミラーと編集領域の高さを変更できる。
3. 検出シーンの「チェック切替」「選択シーンへ移動」が常に操作可能である。
4. 数値スライダーは直接入力できる。
5. 出力フォルダをUIから変更できる。
6. NVIDIA環境ではNVENCが優先される。
7. キル付近のカメラがHTTP待ちによってガクつかない。
8. 完成MP4にLoL音声ストリームが存在する。
9. 標準出力は1080p/60fpsである。
10. 144fpsを選択した場合は144fpsのCFRで出力される。
11. 初心者が自動作成ボタンから一連の作成処理を開始できる。
