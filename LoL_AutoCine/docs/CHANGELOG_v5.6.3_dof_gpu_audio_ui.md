# LoL AutoCine v5.6.3 修正内容

## DOF
- 旧実装の「画面全体を一律ぼかす」処理を削除。
- フォーカス距離を中心に、近距離・遠距離側だけをぼかすDOF近似へ変更。
- Replay APIから画素単位の深度バッファを取得しているわけではないため、2D映像の上下位置を奥行きの代理値として使用。
- UIの近距離・フォーカス距離・遠距離・ぼかし強度を引き続き利用。

## 音声
- Process Loopback失敗時に、他アプリをミュートしてデスクトップ全体を録音するフォールバックを廃止。
- Windowsの音量・他アプリのBGMを勝手に変更しない方針に変更。
- LoL専用Process Loopbackが利用できない場合は、誤った音声をMP4へ混ぜず明示的に失敗する。

## GPU / FFmpeg
- CUDA/CUVIDデコードをエフェクト処理の必須経路から外した。
- CPUフレームへデコードしてフィルターを適用し、利用可能なら最終H.264エンコードはNVENCを使用。
- これにより `CUDA_ERROR_INVALID_VALUE` / `auto_scale` / `h264_nvenc Could not open encoder` の連鎖失敗を回避する設計。

## UIプレビュー
- Tkinter + PIL/Numpyで行っているライブエフェクト計算はCPU処理であることを明確化。
- 144Hzで毎回フルエフェクト処理してUI操作が重くなる問題を避けるため、プレビュー処理を最大60Hzへ制限。
- 最終動画のGPUエンコードとは別系統。
