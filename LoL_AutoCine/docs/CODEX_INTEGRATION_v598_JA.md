# LoL AutoCine v5.9.8 — Codex統合用差分

前提：ChatGPT側 v5.9.7 をベースにした変更ファイル。**Codex側の最新エンジンを古いファイルで丸ごと上書きしない**でください。

## 手順
- `v598_changes.patch` は既存ファイルの統一差分です。元のv5.9.7ソース直下で `git apply --check v598_changes.patch` で確認し、`git apply v598_changes.patch` で適用。
- `new_files/` には追加ファイルがあり、相対パスを保って取り込んでください。
- `changes/` には変更済みファイルも収録していますが、パッチが競合した場合は **統合・差分確認** を優先してください。機械的にすべて上書きしないこと。
- 既存のcore.audio、core.camera、core.jobs、GPUエンコードやReplay APIの実装は変更していません。
- Windows実機/LoLリプレイで完成映像と音声を確認し、通常モードとの差分をチェックしてください。

## 主要追加機能
- スマート自動編集の演出タイプ4種
- キル時刻基準の5点カメラキー生成、頭と終端がゼロに戻る
- キル瞬間だけの色を維持する短い明るさ・彩度アクセント
- 詳細編集で強調スライダーと全シーン推薦
- JSON保存、Undo/Redo、実行ログ

※この差分はv5.9.7のベースに対するもので、Codex上で別の修正が進んでいる場合は衝突を目視確認してください。
