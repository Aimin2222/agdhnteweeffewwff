# LoL AutoCine v5.6 要件定義書

## 1. 目的
LoLリプレイから、誰でも簡単にキル・アシストの見どころ動画を作成できる編集アプリを提供する。動画編集ソフトの自由度を持たせつつ、初心者はテンプレートとチェック操作だけで完成動画を作れることを重視する。

## 2. 映像演出要件
以下の演出をチェック式で利用できること。

- 映像切り替え: Motion Camera / Radial Blur / Zoom Blur / Glitch / Kaleidoscope / VHS Damage / Block Motion / Spin Motion
- キル瞬間: Chroma Leak / Flash
- 映像全体: Focus Blur / Vignette / Glint / Camera Shake / Wiggle
- 照明系: VR Blur / VR Light Leak（Film Burn） / 球体ブラー
- ワイプ系: Panel Wipe / Stretch Wipe
- Transformers: Mirror / Slice

## 3. 操作要件
- 各エフェクトをチェックボックスでON/OFFできる。
- 各エフェクトの強度をスライダーと数値入力で変更できる。
- 「キル瞬間」「カメラ演出」「VHS / Glitch」「シネマ」「全部控えめ」の簡易プリセットを提供する。
- ミラー中のプレビューにエフェクトの軽量近似を表示する。
- 最終書き出しはFFmpegで処理し、NVIDIA環境ではNVENC等のGPUエンコードを優先する。

## 4. 安定性要件
- 既存のTargetLock、LoLnam風カメラ、144Hz内部カメラ制御、LoLゲーム音声、検出シーン、出力フォルダ等を削除しない。
- 新しい演出をOFFにすれば従来の映像処理と同等の経路を維持する。
- エフェクトはFFmpeg標準フィルタを中心に構成し、利用環境差によるクラッシュを避ける。


## v5.6.1追補

- v5.6追加エフェクトは初期状態をすべてOFFとする。
- LoLゲーム音はプロセスループバックを第一優先とし、起動プロトコルを警告に強い方式へ変更する。
- WindowsではPyAudioWPatchをフォールバック経路の依存関係として導入する。
