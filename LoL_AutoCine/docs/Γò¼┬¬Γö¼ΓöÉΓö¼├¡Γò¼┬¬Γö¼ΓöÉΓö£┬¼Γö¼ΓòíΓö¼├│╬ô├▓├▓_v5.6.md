# LoL AutoCine v5.6 設計書

## 1. 構成
- UI: Tkinter / ttk
- リプレイ制御: Replay API
- キャプチャ: WGC / FFmpeg経路
- 映像編集: FFmpeg filter_complex
- 出力: NVENC優先、CPUフォールバック
- 音声: LoLゲーム音を別WAVとして収録し、最終MP4へ後段MUX

## 2. エフェクトモデル
`Template.video_effects` に `{effect_id: strength}` を保存する。0またはキーなしはOFF、0.05〜1.0を強度として扱う。

`VIDEO_EFFECT_CATEGORIES` がUI表示カテゴリを定義し、`VIDEO_EFFECT_LABELS` が表示名、`VIDEO_EFFECT_DEFAULTS` が初期強度を定義する。

## 3. キル瞬間タイミング
`apply_effects()` に渡された `kills` と `Template.pre` から、各キルのクリップ内相対時刻を算出する。

- Chroma Leak: キル時刻前後の短時間
- Flash: キル時刻を中心とした短いフラッシュ
- VR Light Leak: キル前後の短いフィルムバーン表現

## 4. GPU方針
1. CUDAデコードが利用可能ならCUDA入力を優先。
2. GPU対応のリサイズ等はGPUを優先。
3. CPU専用のFFmpegフィルタはCPU側で処理。
4. 最終エンコードは `h264_nvenc` が存在すればNVENCを優先。
5. NVENCがない場合はlibx264へフォールバック。

「全フィルタをGPU」とはせず、実際に利用可能なGPU経路だけを使用する。

## 5. プレビュー
ミラー表示では `apply_camera_preview()` の後に `apply_video_effect_preview()` を通す。これは軽量な近似表示であり、最終書き出しのFFmpeg結果と完全一致させるものではない。最終結果確認には正確プレビュー/実書き出しを使用する。

## 6. UI設計
- カテゴリごとにエフェクトをまとめる。
- 各項目は `☑ エフェクト名 + 強度スライダー + 数値入力`。
- 初心者向けにプリセットを最上部に配置。
- 高度な設定は既存のカラー・FX領域へ追加し、基本の「自動作成」導線を邪魔しない。
