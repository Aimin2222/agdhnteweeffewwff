# v5.10.14 Windowsまとめテスト

前回Codex統合v5.10.13と比べてください。完全版を別フォルダへ展開しSTART_GPU.bat。旧フォルダと設定/録画/プロジェクトは残してください。全テスト後COLLECT_DIAGNOSTICS.batを実行し、生成ZIPと下記の結果を送ってください。

1. 起動・旧設定: 前回の切替演出/テンプレートを読み込み、旧「光るカット」「暗転カット」の意味を保持できるか。
2. ミラーON: 5作業領域をクリック/Ctrl+1〜5で切替、詳細4タブ、スクロール、色/エフェクト/カメラスライダーを連続操作。応答なしや長い停止が無いか。
3. 折りたたみ: カメラグラフ/キーフレーム/シーンFX/詳細、FOG/カーブ/DOFを開閉。値が維持され、再表示と書き出しに反映されるか。
4. コンボ: 開いた一覧だけホイールでスクロールし、背後のパネルが動かないか。閉じたコンボではホイールで値が誤変更されないか。
5. キルフレーム図鑑: 未接続でも開く。検索/分類、既存37素材、選択、発光0/1/2、発光OFF、拡大をミラーONで試す。連続変更後に最後の選択が表示されるか。閉じる→再度開くを繰り返す。
6. 適用: 図鑑の適用前に設定が変わらず、適用後はかんたん/詳細両方で同じ値。再起動後にも保存されるか。拡大表示が選択中の素材と一致するか。
7. 比較: 仕上がりプリセットに500msホバー、すぐ離れる、DOF比較の開閉を繰り返す。元のLoLフレームと加工後の左右比較が出るか。設定を勝手に変えないか。未接続時は案内が出るか。
8. スキャン: 試合全体→表示プレイヤー/キル/アシスト切替、チェックシーン/全検出シーンで対象が正しいか。
9. カメラ: BLUE/RED各4モード（通常三人称/シネマ三人称/FPS/Lolnam）を同じ場面で比較。RED通常の上下反転や横向きが直ったか。手動0/180°も確認。キル前後に対象を見失わないか。問題があればside/モード/時刻/スクリーンショットを添えてください。
10. 書き出し: 1080p・60fpsで1シーンと2シーン以上。cut/flash/dark/white/soft/gold/cool/pulse/cinema/shadowの全10種類。光・暗転・色が選択通りか。softはディゾルブ風の明度演出です。加工時間を記録してください。
11. 同期: 各出力が60fpsで、音声が末尾までずれず、切替で余分な映像/静止フレームが増えないか。ブラウザ等の音を鳴らしてもLoLだけが録音されるか。
12. GPU判定: 診断のエンコーダとGPU映像フィルターを別々に確認。切替演出のcpu_video_effectsが空か、フォールバックなら理由を確認。タスクマネージャーではVideo EncodeとComputeも見る。CPU使用率ゼロは目標ではありません。
13. 中断/再実行: 準備中/書き出し中の中止、その後再度書き出し。UIが応答し、処理中の対象変更が混ざらないか。
14. TEST_GPU_RENDER.bat: ウィンドウ内の結果/diagnosticsを確認。GPU比較6ケースとRUN_AUTOTESTを可能なら実行。すぐ閉じた場合も結果ファイルを収集してください。

報告例: GPU名/ドライバ、選択FFmpeg、素材/演出、シーン数と合計秒数、書き出し秒数、準備待ち秒数、fps、音声ずれ、ミラーON/OFF、カメラside/モード。今回のLinux検証は実GPU速度を保証しません。
