# LoL AutoCine v5.6.1 - Audio Fix

## ゲーム音の修正

- 音声ワーカーの `SyntaxWarning` が START プロトコルの先頭に混入しても起動失敗しないよう修正。
- 子プロセスを `-W ignore -u` で起動し、標準出力プロトコルを安定化。
- `START` / `ERROR` を受信するまで診断行を読み飛ばす。
- `return` を `finally` 内に置かないよう音声ワーカーを修正。
- Windows フォールバック用に `PyAudioWPatch` を依存関係へ追加。
- `REPAIR_AUDIO.bat` を追加。
- LoL プロセスループバックを第一優先、失敗時は LoL 以外のセッションを一時ミュートした WASAPI ループバックへフォールバックする構成を維持。
- 最終 MP4 は映像レンダー後に LoL WAV を AAC へ mux し、音声ストリーム存在確認を行う。

## エフェクト初期状態

- v5.6 で追加した映像エフェクトは初期状態をすべて OFF に変更。
- エフェクトの数値はプリセット適用時の基準値としてのみ使用。

## Adobe 互換性について

名称・カテゴリ・操作感を Premiere / After Effects に寄せているが、同一エフェクトのアルゴリズムを移植したものではない。FFmpeg で安定実行できる近似表現を使用する。
