# LoL AutoCine v5.9.6 — Codex統合用差分のみ

これはアプリ本体のフルZIPではありません。 **v5.9.5 → v5.9.6 の実コード差分だけ**を収録しています。

## 変更内容
- かんたん/詳細編集でHUDプリセットを共有（通常HUD／HUD非表示／HPバー中心）
- LoLの名前非表示設定はゲーム側で操作が必要。未対応のReplay API設定は送らない
- チェックした複数シーンへカメラ・色・FX設定を一括適用し、Undoで戻す
- 対応するテスト、変更履歴、VERSION.txtを同梱

## Codexへの指示
1. 対象のLoL AutoCineリポジトリのルート（legacy_app.pyがあるディレクトリ）を確認する。
2. 先に未コミット作業を保存し、別ブランチで作業する。
3. v5.9.5ベースであれば `git apply --check v5.9.5_to_v5.9.6.patch` の後 `git apply v5.9.5_to_v5.9.6.patch`。
4. Codex側で既に変更がある場合、`git apply --check` が失敗したら**強制適用・丸ごと上書きをせず**、パッチを読みながら手動で差分を統合する。
5. `tests/test_v596_hud_batch.py` を含む既存テスト、Python構文チェックを実行。LoL/NVENC/音声の挙動はWindows実機で確認する。

### 差分ファイル
- `v5.9.5_to_v5.9.6.patch`: Git統合パッチ（既存コードの変更＋追加ファイル）
- `base_sha256.json`: 差分を作成したv5.9.5側のファイルSHA-256

### 注意
このパッチはv5.9.5が基準。v5.9.6がすでに適用済みなら**再適用しない**こと。
Codex側のGPU最適化・LoL音声・カメラの既存修正を維持すること。
