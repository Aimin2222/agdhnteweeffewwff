# LoL AutoCine v5.4 — UI / GPU / 144Hz / Audio

## UI
- 中央プレビュー（LoLミラー）を固定。下側の編集エリアだけ縦スクロール。
- 右側を拡張し、検出シーンのチェック切替・選択シーン移動・作成ボタンを縦配置して見切れを防止。
- サイドの主要スライダーは数値入力と連動。
- 出力先を右パネルから直接変更可能。
- サンプル画像は表示しない。

## 初心者向け操作
- 「リプレイ準備 → 対象プレイヤー → 全編スキャン → テンプレート → 動画を生成」の一本道を維持。
- 複雑な設定は編集エリアへ隠し、プレビューを常時見える状態にする。

## Camera / Smoothness
- CameraDirectorを最大144Hzへ変更。
- FOV、位置、回転を時間定数ベースで補間。
- キル瞬間の急激な目標値変更によるジャンプを抑制。
- 144Hzはカメラ制御・ミラー表示の更新基準。最終MP4は1080p/60fpsを標準。

## GPU
- NVIDIA環境ではNVENCを優先。
- CUDAデコードを利用できる場合は入力デコードもGPU優先。
- CPUフィルタが必要なエフェクトは無理にCUDAフレームへ固定せず、安定性を優先してCPU/GPU間の不要な再変換を避ける。

## Audio
- LoLプロセス音声を録音。
- WAVが空/短すぎる場合は無音MP4を成功扱いしない。
- 最終MP4にAudio streamが存在することを検証。
- BGMを使う場合もLoL音声を基準にダッキング。

## 注意
WindowsのプロセスループバックはOS/API依存があるため、実機でLoLリプレイを再生しながらの音声確認が必要。
