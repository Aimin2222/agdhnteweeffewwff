## MAKE_REFERENCE_SHEETS.bat
- ZIPを直接処理するツールではない。動画MP4/MOV/MKV/WEBM単体、動画を含むフォルダーをドラッグ＆ドロップできる。ZIPは先に展開する。
- BATを単にダブルクリックした場合は、PythonのTkファイルダイアログが開く。動画選択をキャンセルすればフォルダー選択画面へ。ログ付きGUI選択なので、ファイル名に日本語を含む環境でも使いやすい。
- 処理エラーは `%TEMP%\AutoCine_ReferenceReview_latest.log` へ記録して、メモ帳も表示する。英数字のみのASCII BATとPython UTF-8表示は維持。CMD内で非ASCIIコマンドを実行しない。
- ユーザー環境でBATが即終了する原因は未確定。ログ（または手元で `cmd /k MAKE_REFERENCE_SHEETS.bat` を実行した画面）を見て原因を切り分ける。

## Windowsで必ず確認してほしいこと
1. v5.10.23を古い版と別フォルダーに展開。
2. `MAKE_REFERENCE_SHEETS.bat`をダブルクリック → ファイル選択画面 → MP4を指定 → `ReferenceReview_contact_sheets.zip` が生成されるか。
3. 同じBATへMP4をドラッグしても画像ZIPが生成されるか。失敗したら `%TEMP%\AutoCine_ReferenceReview_latest.log`を添付。
4. 一度もスキャンしていないリプレイで「開発用：1回で接続→全体スキャン→動画・画像→500MB ZIP」を押し、最後まで自動実行できるか。
5. RED #1：主役がより中央・適切な距離にいるか。Zロールや上下反転がないか。
6. RED #3：キルの主役と相手を中央付近に収められるか（以前は右上）。
7. RED #2/#4/#5：以前良好だった構図が悪化していないか。
8. BLUE #6〜#10：少し引いて後方から撮影した印象で、キルが十分大きく見えるか。特に#7/#9/#10の以前の良い構図を保つか。
9. ゲーム音/NVENC/1080p60/ミラー/HUD/チェックボックス/kill frameを以前通り使えるか。
10. `results.json`, `RED_camera_3frames.jpg`, `BLUE_camera_3frames.jpg`, `QA_Support`, 分割ZIPが揃うか。

## ファイル送付
このチャットのZIPファイル実行環境が復旧しない限り、ユーザーが添付した過去MP4を遡って自動で読み取ることはできない。代わりにBATで6時点のJPG比較を作って送ってもらう方法がある。MP4自体の分析には動画を読み取れる環境が必要。
