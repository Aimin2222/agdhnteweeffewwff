# LoL AutoCine v5.10.21 実装仕様・Windowsテスト

- ソース: Codex GPU Full v5.10.15からの累積差分。mainと従来のCodex統合ブランチを直接変更しない。
- Windows 1080p/60fps/NVENC/LoLゲーム音/TargetLock/HUD/ミラーを維持する。変更は対象カメラ座標の補正・UI・参照映像ツールに限定。
- Linux GitHub Actions は pytest/GUI/FFmpeg/ZIP/パッチ検証ができるが、LoL実機の構図は確認できない。
- 2026-10-12 16:30付属の `results(4).json` と画像の比較は済んでいる一方、`AutoCine_Diagnostics.zip` / 分割MP4は、このチャットのPython実行環境で InvalidArgumentErrorが発生して直接再解析できなかった。

## カメラ（アプリのLIVE経路）
- RED #1/2 はカメラ距離をそれぞれ6%/4%だけ縮める。#2の角度は維持。
- RED #3 FPS は、古いTopカメラとプレイヤーとの差分をそのまま使わず、プレイヤー中心の局所ベクトルから位置を作る。またRED固有の約192度回り込みを**位置と向きの両方**へ適用する。以前は位置=0度、向き=192度の不一致で空撮りが発生し得た。
- RED #4 は左右回り込みを小さく調整、俯角を少し浅くする試験値。RED #5 は左右方向を数度調整。
- BLUE #6 は数度だけ下を向ける。BLUE #7 は角度・距離とも変更なし。BLUE #8 FPS はREDと同じく対象座標基準の位置に変更。BLUE #9/#10 は俯角を2.5度増加。
- 特定の一人称/三人称モードとBLUE/REDを組にした設定辞書 `core/camera_tuning.py` で分離。他モードへの軸・角度の使い回しを避ける。移動/ズーム系の共通処理は残すが、補正値の共有は避ける。
- 新値は仮の小幅な修正。**カメラがキル瞬間に画面中央に収まるかはWindowsで再検証必須。** 必ずRED2とBLUE7の悪化を回帰条件に含める。

## かんたん編集UI
- 「自動ディレクター」をONにすると、直下に**演出強さ（0～150%）**のスライダーと数値欄が出る。キル数に基づく実際の回り込み/接近量に倍率を適用。
- 「色だけ細かく調整する」は別のチェックボックス。ONで色補正強度・色の暖かさ・コントラスト・鮮やかさの4項目を表示。ラジオ操作やプログラム経由の状態変更に対応。
- 既存テンプレートA/Bや詳細編集、元の色変数は消さない。

## MAKE_REFERENCE_SHEETS.bat
- 今までフォルダーしか受け付けなかったのを、MP4/MOV/MKV/WEBMファイル単体もドラッグして比較画像に変換できるようにした。
- ZIPはまず展開する。フォルダーも今まで通り受け付ける。
- Windowsでの失敗はコンソールに表示し、`%TEMP%\AutoCine_ReferenceReview_latest.log` を保存して「すぐ閉じる」場合にも調査可能にする。
- 処理はローカルのみ。動画をGitHubへアップロードしない。出力先はファイル指定時とフォルダー指定時で区別。
