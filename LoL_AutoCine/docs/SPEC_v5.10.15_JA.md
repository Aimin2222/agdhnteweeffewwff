# LoL AutoCine v5.10.15 実装仕様書／受入テスト

基準 v5.10.14（旧GPU・TargetLock・LoL専用音声・HUD維持）。

## 操作性と画面
1. プルダウン：Tk標準の候補リストが開いている場合、親画面のScrollFrameはホイールを受け取らない。閉じた選択欄はマウスホイールで値を変更しない。全候補欄に共通適用。
2. 詳細編集：「シーン／カメラ／カラー／FX／出力」を唯一のページナビにする。「基本／カラー／FX・DOF／出力」の内側タブは廃止。互換用の基本設定はシーンの下段へ残し、設定変数は削除しない。
3. DOF：FXページの「DOF（ぼかし）を有効にする」チェック直下に円形／従来ぼかし、強さ、中心、半径などが展開。OFF時は非表示。旧値とUI変数は保持。
4. チェック欄：Windowsのテーマで判別しにくい×表示に代えて、選択状態は明確な青背景＋白いチェックを示す。複数独立ON/OFFにはチェックボックス、排他選択にはラジオを維持。
5. 仕上がり：0.5秒ホバーの小型プレビューを残し、その下へ「仕上がりを大きく比較」を追加。ミラー原画と色補正後を左右比較。現在の色やカメラ設定はプレビュー操作だけで書き換えない。
6. カラーグレード：内部ID（標準、映画、ノワール等）は維持し、表示文字列に寒色／暖色／青緑×橙／高コントラストを明示。既存JSONでの保存互換を保持。
7. キルフレーム：確認済みテーマ素材にはK/DA風、PROJECT風、スターガーディアン風、精霊の花祭り風、ハイヌーン風などの名称を表示。16枚の追加オリジナル素材は、裏付けのない特定スキン名を付けず図鑑画像で判別できるまま残す。
8. モンタージュ：簡単編集の「動画のつなぎ目」をモンタージュ演出選択として説明。2クリップ以上をつなぐ場合に有効。切り替えの10スタイルの選択自体はv5.10.14維持。
9. ミラーの「表示サイズで確認」：プレビュー処理だけを画面のピクセル表示サイズへ合わせる高精細モード。通常の「操作優先」はCPUプレビューを低めの内部サイズで処理し軽量化。完成動画の1080p/60fpsとGPU処理には影響しないことを0.5秒ホバーで説明。
10. シーン：検出シーンを選ぶと実際のキラーのチャンピオンアイコンを表示。ローカルPNGを優先し、存在しない場合はバックグラウンドでData Dragonの正規アイコンの取得を試みる。取れない場合は名前を表示。キーフレーム時間軸は従来の曲線エディタのまま。

## カメラ（限定補正）
- BLUE/FPSとLolnamシネマは過去の評価を優先して既存挙動を維持。
- RED FPS：キル対象が左下に寄りやすい問題に対し、実測リグの水平右ベクトル基準で小さな水平移動、わずかに低めの位置補正。MIN_CLEARANCEは破らない。
- RED 通常三人称：キル周辺だけの横回転アクセントを+7°→+4°に緩和。通常の三人称サイド反転・キャリブレーション・TargetLockは維持。
- 上記は**実測映像のフレーム照合がまだできていない暫定の数値補正**。ユーザーのRED動画2本に対する成功はWindows実機で必ず再検証する。

## 不変条件
- 全体1回スキャン→選手別絞込を維持。
- 素材型37キルフレームと従来描画スタイル、カラー／FX／DOF、GPU Full、LoL専用音声、モンタージュの高速連結と音声コピーを維持。
- 既存テンプレートID、ファイル名・キルフレームstyle IDを変更しない。
- 追加GUIウィンドウはLoLのミラー開始／停止、カメラAPIに副作用を生じない。

## Windowsでの受入チェック
- [ ] プルダウンを開きスクロールしても背景画面は動かず、候補一覧だけ動く
- [ ] カラー／FX／出力へ切替時、内側の茶色い基本・FX-DOF・出力タブは存在しない
- [ ] FXのDOFチェック直下に詳細が開く。円形/従来の切替とミラー比較が正常
- [ ] チェックボックスに×ではなく✓が表示され、実際のON/OFFに一致
- [ ] 仕上がり「大きく比較」で原画と色補正後が見える
- [ ] 検出シーンでキルしたキャラの公式アイコンが表示される（未取得なら名前表示）
- [ ] キルフレームで各スキン風の名前が分かりやすい。37素材が欠損していない
- [ ] COLORグレードで色味の想像できる日本語表示
- [ ] 簡単編集の動画のつなぎ目から10種類が選べ、2クリップ以上のモンタージュへ反映
- [ ] RED側通常三人称：対象のキル瞬間が見える
- [ ] RED側FPS：以前より中心に見える。低い視点／壁／地形の事故がない
- [ ] BLUE側FPSとLolnam風シネマは悪化せず、初回・再録画で安定
- [ ] 1080p/60fps・NVENC・LoL専用ゲーム音声・HUD・TargetLock・ミラー復帰が正常

不具合時は MP4／診断ZIP／スクショ／BLUE or RED／カメラ名／キル時刻を添付する。
