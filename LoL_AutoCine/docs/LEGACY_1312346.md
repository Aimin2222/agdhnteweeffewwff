# LoL AutoCine v4.0 ユーザーガイド

## A. 初回だけ
1. Python 3.10以上を入れる
2. `START.bat`を起動
3. 初回は依存関係のインストールを待つ
4. 「LoLを準備」を押す
5. LoLを再起動する

APIキーの入力はありません。

## B. 普段の使い方
1. 「最近のリプレイを再生」または「リプレイ(.rofl)を開く」
2. 「接続して10人を取得」
3. 作りたいプレイヤーをダブルクリック
4. 上部の「かんたん編集」でテンプレートを選択
5. 「★ これで自動作成」

全編スキャン → キル抽出 → カメラ → 録画 → 編集 → MP4まで自動です。

## C. キルを確認してから作る
1. 「全編スキャン」
2. キル一覧から1件選択
3. 「選択したキルへ移動」
4. カメラ確認
5. 「選択キルだけ作成」

## D. lolnam系編集
右側「カラー」でグレード、色温度、コントラスト、露出、彩度、Fog、カーブ、DOFを調整できます。
基本はテンプレのまま使用し、違和感がある部分だけ調整してください。

## E. カメラ
右側「カメラ」で距離と高さ、HUD、HPバーを調整します。地面埋まり回避や俯瞰追従はAutoCine側で自動処理します。

## F. 音
「録画・出力」でゲーム音をONにするとLoLプロセス音を優先します。使えない場合はデスクトップ音へ自動フォールバックします。

## G. 出力
既定: `ビデオ\\LoL_AutoCine\\プレイヤー名_チャンピオン\\`
`kill_001.mp4`、`kill_002.mp4`、必要なら`montage.mp4`を生成します。同名ファイルは上書きしません。

## H. ミラー
「ミラー ON / OFF」でLoLウィンドウを中央へ表示できます。

## I. エラー
- `diagnostics\\last_error.txt`
- `diagnostics\\last_scan_events.json`
- `RUN_TESTS.bat`

## J. 重要
録画中はLoLを最小化しない、他ウィンドウで完全に隠さない、リプレイ中に操作しないでください。game.cfg変更前にはバックアップが作られます。

## K. 目標ワークフロー
普段: `LoLを準備 → プレイヤーをダブルクリック → テンプレ選択 → ★自動作成`

細かく作る時: `スキャン → キル選択 → カメラ確認 → 個別作成 → カラー調整`
