# v5.5.0 変更概要

- 中央UIを「上:固定LoLミラー / 下:スクロール編集」の上下Split構成へ整理
- 境界ドラッグでプレビューと編集領域の高さを変更可能
- かんたん作成導線を追加
- 検出シーンの主要ボタンが切れにくい配置へ変更
- 数値入力付きスライダーを維持・整理
- プレビュー144Hz、内部キャプチャ144fpsを標準化
- 最終出力は60fpsを標準、144fpsも選択可能
- CameraDirectorを144Hz内部補間 + Replay API最大60Hz送信へ変更
- Replay APIの毎フレームplayback GETを廃止し、0.25秒同期へ変更
- キル付近のカメラガクつき対策として時刻・速度・FOV・offset・rotationを平滑化
- GPU優先のCUDA/NVENC経路を整理
- LoLゲーム音を後段muxする方式へ変更し、映像filterで音声が消える問題を回避
- LoL音声ストリームの最終検証を維持
- 1080p MP4を標準出力として維持
- サンプルpreview_mock.pngをパッケージから削除
- 要件定義書と設計書をUTF-8 Markdownで追加
