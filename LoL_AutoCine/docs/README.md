# LoL AutoCine v4.0

LoLリプレイからキルを自動抽出し、カメラ演出・カラー・エフェクトを付けたMP4を作る個人向けWindowsツール。

## 特徴
- APIキー入力不要
- game.cfgを自動設定
- プレイヤーを選ぶだけ
- 全編キルスキャン
- キル位置へ自動移動
- 三人称/シネマ/FPS/俯瞰など
- 144fps取り込み / 60fps出力
- lolnam系カラー/Fog/カーブ/DOF
- LoLプロセス音優先 + 自動フォールバック
- ワンクリック全自動
