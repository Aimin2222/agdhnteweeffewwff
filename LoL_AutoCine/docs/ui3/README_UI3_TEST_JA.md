# 候補3 暫定機能統合版 — Windows試験手順

更新: 2026-10-28。候補3（内部ID `T-A-M`）を暫定的な操作画面として開きます。正式採用ではありません。候補1〜10、混合案、R1/R2、従来UIは残します。現在のBAT版は候補3と、WorkのLeague Director／Lolnam参考UIを切り替えられます。

## 起動

1. ZIPを従来AutoCineや7案比較版とは**別のフォルダ**へ展開します。日本語名や空白を含むフォルダでも起動できます。
2. Python 3.12 x64の既存環境に `python -m pip install -r requirements.txt` で依存を準備します。準備済み環境を使うときは、同じコマンド画面で `set AUTOCINE_UI3_PYTHON=C:\...\Scripts\python.exe` を指定できます。ZIPにはPythonやWebView2 Runtimeを同梱していません。
3. `START_AUTOCINE_UI3.bat` をダブルクリックします。起動前確認だけなら `START_AUTOCINE_UI3.bat --check`。Flash/Zoomを従来方式へ戻すには `START_AUTOCINE_UI3.bat legacy`。
4. エラー時は原因と準備方法を表示してコマンド画面を保持します。外部ブラウザは開きません。内部のWebView2はローカル通信 `127.0.0.1` を使います。

BATは作業フォルダを自身の場所へ切り替え、CRLF改行で保存されています。必要なNative LoL音声ヘルパーはZIPに同梱します。既存EXEは変更しません。従来画面は同梱の `START.bat` で起動できます。

## 候補3での操作

- 最初に正しい候補3 `testA / T-A-M` が開きます。下段タブの「Lolnam参考」「League Director参考」で追加2案へ移動し、追加2案の上部「候補3」で戻れます。3UIは同じAutoCineバックエンドを共有します。C3-P/Sも従来の比較画面として残し、元の候補3を置き換えていません。
- C3-Pではカメラの数値・サイド・既存10種、詳細の実キーフレーム表示と既存エディタへの入口を確認できます。C3-Sではカメラ・実素材・FX強さをカードから選び、素材ドロワーと出力内容確認を試せます。適用前のカメラ・素材ドラフトはキャンセルで破棄します。
- C3-P/Sの下部にはシーンタイムラインとキル前後トリムが常設されています。数値は従来AutoCineの同じ設定へ反映されます。「テスト結果」では前回の安全な自動診断の件数と診断ログへの入口を表示します。実LoL総合試験の合否とは別です。
- C3-Sの「控えめなおすすめ」は、変更するカメラモード・スタイル・FX強さを確認してから適用します。キー、素材、チェックシーン、録画には触れません。適用直後のみUndoが可能で、あとから手動値やキーを変えた場合はカスタム表示になります。
- メインのリプレイ、対象プレイヤー、スキャン、シーン選択、ミラー、トリム、動画作成は既存Appの操作へ送ります。
- 「詳細編集へ」から候補3の補完詳細画面へ進み、カメラ・Work素材と同名FX・6登場アニメを選べます。候補3の詳細画面に原画像はなく、比較用補完です。
- 候補3の下段タブ「全機能」を開くと、既存カメラ10種、素材図鑑、37バッジ、診断、一括QA、プロジェクト保存などへ進めます。35項目は従来の実動作エディタを開いて操作します。候補3画面内での専用操作への移植は未完了です。
- 既存の「開発用：カメラ＋Work素材一括QA・30MB ZIP」を起動する入口は全機能パネルにあります。長時間の総合QAは機能統合後まで保留します。
- 画面切替で同じAppインスタンスと選択状態を共有します。候補比較の他画面も引き続き利用できます。

## 保存先と保護

新規展開したZIPには `settings.json`、録画、診断ログ、プロジェクトを入れていません。候補3の表示設定と既定の書き出し先は、展開先の `LoL_AutoCine/ui3_data/` を使います。動画保存先を画面で変更することは可能です。元のAutoCineの設定や録画フォルダへこのZIPを上書き展開しないでください。

PR #54のFlash/Zoom試験改善は既定で有効ですが、BATの `legacy` 引数で旧処理へ戻せます。Work素材の正式合格はNo.083 Aのみで、残りの候補や35FXを承認済みには変更していません。ユーザー不採用5素材の推薦状態も変更していません。

## 実機で確認する順番

1. 起動、候補3の表示、全機能パネル、詳細編集・素材画面から戻る操作を確認。
2. LoLリプレイを選び、接続・試合全体スキャン・キルとアシスト・TargetLock・選択/チェック出力を確認。
3. BLUE/RED、既存10カメラ、固定自動/フルオート、上下反転、キーフレームを確認。
4. ミラーFPSと画質、HUD、FX、No.083 A、弱/強・6motion、既存37バッジを確認。
5. GPU/NVENCとCPU代替、LoLゲーム音のみ、1920×1080/60fps MP4を短い1シーンで確認。
6. その後に既存の一括QAとIssue #53の総合テストを再開し、ZIPと診断ログを保存。
