# クリップ安定化

- 1クリップの失敗で完成済みクリップを失わない

## v4.1.3 - 三人称カメラ安定化

- プレビューで成功した三人称カメラのリグ（水平向き・回転軸・符号・基準座標）を録画時にも再利用
- `cameraRotation` の一時的な軸判定失敗だけで三人称→FPS風へ切り替えない
- seek直後や地形/遮蔽物によるReplay側のカメラ補正を考慮し、三人称の位置検証を適度に許容
- 三人称検証が一時的に不安定な場合は同じリグを1回再送して再検証
- 診断ログに保存済みリグ再利用の有無を出力
- UI、v1.2カメラ設定、60fps、ProcessLoopback無効化の安定化方針は維持
