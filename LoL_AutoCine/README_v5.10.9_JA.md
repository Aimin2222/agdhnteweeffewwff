# LoL AutoCine v5.10.9 — Premium Kill Icon Material Integration

## 今回の実装
- ここで作成した**高発光キルアイコン素材**をアプリに同梱しました。
- 既存のベクター描画型キルログに加えて、**素材型テンプレート**を選べるようにしました。
- 追加スタイル:
  - プレミアム・ゴールド（高発光）
  - 黒曜石×ゴールド
  - ネオン・クリスタル
  - 星と翼の幻想
  - 炎熱ゴシック
  - サイバーパンク
- これらは `assets/kill_badges/` の透過PNGを使用し、キラー/倒された側の実際のチャンピオン肖像を動的に埋め込みます。
- 既存のシンプル / シネマ・ゴールド / ネオン・ブルー / インパクト・レッドは維持しています。

## 注意
- 今回の更新は**キルアイコン素材の統合と選択肢追加**が中心です。
- GPU書き出し本体の最適化は Codex 側で進行中という前提で、ここではGPUコアを壊さないようにしています。
- UIの細かな文言整理やテンプレート実写プレビュー強化は次段階の調整候補です。

## 使い方
1. アプリを起動
2. キルアイコン装飾のスタイルから新規スタイルを選択
3. シーンを作成して、実際のキラー/相手の組み合わせで表示確認
4. 問題なければそのまま書き出し
