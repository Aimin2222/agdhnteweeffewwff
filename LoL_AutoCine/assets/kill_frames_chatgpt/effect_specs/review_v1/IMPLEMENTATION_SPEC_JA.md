# A/B/C/D・Dスキンテーマ演出素材の実装引継ぎ

## 仕様の根拠と状態

正式な意味は `docs/KILLFRAME_ABCD_IMPLEMENTATION_HANDOFF_20261013_JA.md` と原本No.083で照合した。A=シンプル、B=高級感、C=シネマ、D=スキン・地域テーマ。No.008にもA-1の個別仕様がある。Dの31テーマは既存台帳 `core/kill_frame_themes.py` と `theme_correspondence.json` の実原本対応で復元した。古いカタログの存在しない画像名を実ファイル名と混同しない。

**以下の細かな運動・キル前の予告・粒子数は今回の追加設計案。過去に確定していた仕様を復元したとは主張しない。** 採用はユーザー判断待ち。既存のGPU・録画・音声・カメラ処理や素材選択のコードには接続していない。

## 素材・レイヤー契約

`original_alpha/review_v1/001`〜`089` は既存Codex抽出候補の無改変コピー。元RGBとcrop_boxを全画素で再照合し、独立マスクも再照合する。原本を新たに生成し直した素材とは別。小型図を拡大して高精細になったとは扱わない。

`effect_assets/review_v1/ABCD/{A,B,C,D}` と `D/<theme>` に、原本由来の `ornament_rgba.png`、派生レンダリングレイヤー `glow_rgba.png`、実際の分離連結成分 `particle_*.png` を配置する。粒子は装飾の断片であり、独立した花弁や星として原本から確認できない断片をその名称で断定しない。抽出できない場合は粒子なしと記録し、架空のテーマ図形で穴埋めしない。

glowは元アルファを6pxぼかし、premultiplied RGBを同じ量でぼかしてからunpremultiplyした派生画像。原本の画素不変を保証するのはornamentと原本透過素材のみ。glowは周囲24pxを追加しており、ornament座標からのオフセットは(-24,-24)。粒子の原本内座標は `source_local_bbox`。レイヤーはPNG RGBA・straight alpha・sRGB、読み込み時に合成器内部でpremultiplyする。glowの加算はlinear RGBで行い、最後にsRGBへ戻す。baseの合成は通常over。実装時に二重premultiplyをしない。

ゲームの実キラー・被害者アイコンは別レイヤーで、inventoryの肖像穴をdestination maskとして挿入する。素材中の肖像を利用しない。説明JPGの顔や見出しはQA参照用であり、動画用素材ではない。glowと粒子は合成直前に肖像穴マスクで除外し、顔の見やすさを保つ。×1、VS、テーマ名などの文字を動画に追加しない。

## 共通時計・画面座標

キルの出力時刻をt=0秒とし、オーバーレイの時計は出力タイムラインの秒で計算する。Replay時刻から出力時刻への既存変換をCodex側が一度だけ行う。再生速度変更や音声尺の変更をこの素材仕様から行わない。60fpsではt=n/60-kill_output_time。固定のフレーム番号に秒を混ぜない。

配置の今回提案は1920×1080で中心(960,166)、最大幅600px、高さ260px。HUDと重なる場合の位置選択は既存設定を優先し、カメラのTargetLockやFOVには手を加えない。原寸より拡大が必要なら警告し、通常はscale<=1。native_dimensionsとcrop_boxが正解の寸法。解像度違いでは画面短辺比で配置オフセットのみ換算する。

p=clamp(t/enter,0,1)、S(p)=3p²-2p³。q=clamp((t-enter-hold)/exit,0,1)。base opacity=S(p)×(1-S(q))。base scale=0.92+0.08S(p)。キル前の-0.12<=t<0はbaseを出さず、採用する場合のみ小さいglowを最大0.08で予告する。t< -0.12、t>=enter+hold+exitは全レイヤーalpha=0。先行予告は解析済みリプレイ編集向けの提案であり、リアルタイム検知では利用しない。

glow envelopeは enter中に sin(pi*p) で単発ピーク、holdはpeakの0.12倍、exitは(1-S(q))で減衰。粒子寿命はDで0.5秒を初期値とし、寿命に対してalpha=sin(pi*age/lifetime)²。生成時刻と乱数は event_id・theme_id・particle_index を安定ハッシュしたseedで固定。シークしても同じ位置になるよう、状態積分ではなく時刻から位置を直接計算する。

## 運動を実装する式

粒子iの初期角theta=2pi*i/N+seed_offset、a=clamp(age/lifetime,0,1)。ベース放射はr=24+speed*age、x=cx+r*cos(theta)、y=cy+0.45*r*sin(theta)。inwardはr=80*(1-a)、spiral/orbitはthetaへrotation_degrees*pi/180*aを加える。水滴・火花・ガラスはx+=vx*age、y+=vy*age+0.5*gravity*age²、gravity=120px/s²。上昇系はvy<0でgravity=0。花・葉・蝶・雪はxへ12*sin(2pi*a+theta)、yへvy*ageを加える。dragonはx= cx+vx*age、y=cy+22*sin(2pi*a+theta)+vy*age。JSONのvxはpx/s、rotationは1寿命内の度数。

scan/glintはx境界=-24+(width+48)*S(p)の帯を原本alphaと乗算する。pixel/stutterはpをfloor(p*4)/4へ量子化する。bounceはscale=1+0.06*sin(pi*p)*exp(-3*p)。wing系は左右半分を別レイヤー扱いし、中心からの横オフセットを(1-S(p))*24pxから0へ。four_piece_lockは四象限のオフセット±20pxを0へ。baseは回転させず、粒子にのみ角速度を適用する。

近接では放射半径を0.8倍・寿命0.8倍、遠隔は水平速度1.25倍、ハイブリッドは標準とするのが今回提案。素材中に該当ロールがない場合は勝手に別モチーフを作らず、ロール未確認を設定UIで扱う。弱版はglowと粒子alphaへ0.45、粒子上限へ0.5を乗算し、原本のweakフレームを選ぶ。

## Codexの統合境界と未確認事項

オフラインのanimated WebPとキーフレームはデザイン検討用。ゲーム用の動画・GPU実行結果ではない。CPUプレビューとGPU合成でalpha・線形加算・native座標・イベント時計が一致することを統合後に確認する。素材欠落時は別テーマに置換せず、その効果を無効にして理由を残す。

ユーザー採用後に素材IDだけを既存設定へ追加する。既存37件、設定保存、録画、ゲーム専用音声、TargetLockを変更する作業はこのパッケージに含まない。音・速度・カメラを演出の都合で自動変更しない。連続キルはイベント別seedを保持し、同一位置に最大2組まで、3組目は最古の退場を0.12秒に短縮する案とする。実装前にUIの既存ルールと調整する。

原本の見切れ、文字の背後、肖像に隠れた線、フリンジのRGB修正、全素材の等倍目視合格、実LoL録画での可読性は未承認。ユーザーが採用/不採用を判断するためのreview保存であり、これらを完了扱いにしない。
