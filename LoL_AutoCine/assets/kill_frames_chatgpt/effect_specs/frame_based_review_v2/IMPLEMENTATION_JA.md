# フレーム由来のキル瞬間エフェクト — 実装引継ぎ v2

## 今回の追加範囲

各既存フレームに対応するピーク用の静止エフェクトテクスチャ。フレーム本体の代替画像ではない。対応画像とSHAはproduction.json。新しい動き・倍率は追加設計案であり、過去に確定済みの仕様とは主張しない。

既存の `effect_specs/review_v1/IMPLEMENTATION_SPEC_JA.md` と `animation_catalog.json` のキル前・フレーム登場・保持・退場の契約を保持し、その上にキル瞬間の短いレイヤーを追加する。本体・GPU・カメラ・速度・録画・音声のコードは変更していない。

## 画像の契約

- PNG RGBA / sRGB / straight alpha。読み込み後、合成器内部でpremultiplyを一度だけ行う。
- キルフレームの実中心に、画像の正規化アンカー(0.5,0.5)を合わせる。各PNGの縦横比を保持し、幅は原寸フレーム幅の0.85倍を初期値とする。Aは0.35倍。高さは実フレームの1.4倍を上限とし、幅上限と高さ上限の両方に収まる倍率を選ぶ。ネイティブ画素より大きく拡大することを高解像度化と扱わない。
- レイヤーはフレーム装飾の上、キラー／被害者の実アイコンの下。実際に使用するフレームの肖像穴マスクでFXを除外する。全テーマに一律の丸穴や四角穴を推測して適用しない。
- 画像内の粒子と光は1枚に含まれる。独立した粒子挙動が必要なら既存review_v1の粒子レイヤーを別に使う。単一PNGの中の粒子を独立制御できるとは扱わない。
- 基本合成は通常source-over。追加で光を強調する場合はlinear RGBの加算を選択できるが、alphaを一度だけ適用し、HDRやsRGBの二重加算で白飛びさせない。
- 外周アルファ残留の警告があるPNGは最終承認前。自動的に原本・フレーム側を削ったり、閾値で装飾を消して合格扱いしない。

## キル前・瞬間・後

時計は出力タイムラインの秒、t=0がキル時刻。新テクスチャはt<0で必ず非表示。既存の事前予告は別レイヤーであり、未来のキル時刻が分かるリプレイ編集に限る。

新画像のopacityはt=0で0、.04秒で.8、.08秒で1、.20秒で.65、終了時刻で0。区間内はsmoothstep補間する。Aは.35秒、Cは.65秒、他は.80秒で終了。弱版はopacityに.45、強版は1.0を乗算する。フレーム全体の保持時間を短縮するものではない。

scaleは登場で.8→ピーク1.0→終了1.12。各テーマJSONの時間を使用する。花・葉・蝶はフレーム幅の.08だけ緩く下降、Cosmic系・Dark Star・Space Grooveは最大10度の小さい回転、PROJECTは最初の.08秒の開示を4段階へ量子化する追加案。フレーム本体は回転させない。

シークしても同じ絵になるようevent_idと出力時刻から値を直接計算する。追加のランダム積分、カメラ揺れ、FOV変更、速度変更や音声追加はしない。連続イベントの重なりは既存仕様へ従い、累積加算の白飛びを避ける。

## 確認用ビューアの限界

HTMLは縮小した画像の簡易的なopacity・scale・回転を表示するデザイン確認用。実GPU合成ではない。重ね合わせの位置は目安で、実人物アイコン用のマスクを再現したとは主張しない。実装時は原寸PNG、正確なフレーム位置と肖像穴、実LoL録画での可読性、sRGB/linearの明るさ、連続キルを別途確認する。

## 参照資料と生成履歴

`reference_centers/` と `reference_contact_*.jpg`、`qa_*.jpg` は比較用であり、ゲームに読み込むエフェクト画像ではない。読み込む画像は各JSONのtextureだけを使う。モデルに実際に渡した参照ファイルはproduction.jsonのgeneration_input_referenceとgeneration_input_sha256。input_referenceは中央切り出し資料であり、初回の全体フレーム参照とは区別する。修正前の画像はprevious_versionsに理由とSHAを保持し、主素材を上書きしない。
