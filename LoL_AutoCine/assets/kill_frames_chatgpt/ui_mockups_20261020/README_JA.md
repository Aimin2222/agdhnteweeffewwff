## 寸法と確認範囲

設計基準は1920×1080・16:9です。画像生成の原寸PNGを保持しており、納品PNGの実画素数は上表のとおりです。1920×1080への再出力・引き伸ばしは行っていません。LAYOUT_SPEC.jsonの座標は実装用の設計意図で、生成PNGから測定した正確な境界座標ではありません。

主要な日本語ラベル・パネル配置・数値入力・チェック欄・設定への導線を制作側で目視確認。ゲーム画面・人物・フレームやエフェクトの小画像はモック内の生成イメージです。実際の素材選択や接続状態、スキャン結果、録画・音声・書き出しが動作した証明ではありません。

キルフレーム／エフェクトの制作作業や本体コードは今回変更していません。画像中にあるサムネイルを正式素材として採用したり、既存素材の承認状態を変更したりしないでください。

## 実装担当向け

- IMPLEMENTATION_NOTES_JA.md：各案の差、固定表示とスクロール、既存機能の導線、実装時の確認事項。
- LAYOUT_SPEC.json：1920×1080基準の領域分割と共有状態。
- QA_REVIEW.json：8画面の目視確認記録と静止画像としての制限。
- GENERATION_CALLS.json／PROMPTS.json：組み込み画像生成への指示と修正履歴。
- MANIFEST.json：原寸、サイズ、SHA-256。
- GITHUB_RECEIPT.json：GitHubへの保存後の読み戻し照合結果。ZIPとは別添で保存。

モック制作の納品であり、新UIの実装・動作検証の完了報告ではありません。
