# 生成・再構成版の採用と追加制作

利用者からの指定（2026-10-16）:

- 今後の主方式は生成・再構成版。
- No.001〜004、No.086〜088は原本内の全バリエーションを対象とする。
- No.013の旧生成版は汚れ、No.014・015の旧生成版は形状不一致の指摘があり、不採用。履歴を残して別ファイルに再制作する。
- 原本透過版、原本89枚、既存37バッジ、本体コードは変更しない。

対象は322パーツ。No.013の `ui_display_reference` は同じデザインの配置例のため、新規パーツ数に含めない。
No.004の8パーツは原本自体が右端で見切れている。不可視部分を忠実に復元できる根拠がないため `source_partial` として保留する。

`production.json` がパーツ単位の進捗表。`*.source_crop.png` は原本から切り出した比較資料で、完成素材ではない。`*.generated.png` が生成候補。生成元PNGのバイト列は変更せず保存する。

方式の採用と個々の素材の最終合格は別である。新画像は原本比較、顔・文字・背景残り、透過、見切れのレビューを要する。`final_approved: false` を合格と読み替えない。

技術検査ではRGBA、透明画素の存在、外周画素のアルファを記録する。外周にわずかでも残留があれば自動合格にしない。目視で問題が見えなくても、厳密な透過合格を保証するものではない。
