# LoL AutoCine v5.10.5 — キルログ装飾／発光／説明／サイド別カメラ

v5.10.4を引き継いだ修正版です。**GPUエンコーダ・音声・WGC録画・1080p/60fpsの既存処理は変更していません。** 進行中のCodex側GPU高速化との差分統合では、`core/effects.py`・`core/jobs.py` の競合に注意し、GPU側の変更を上書きしないでください。

## 新機能

1. **チャンピオン2アイコン型キルログ**：選択したプレイヤーではなく、各イベントの**実際のキラーと倒された相手**を表示。公式肖像アイコンが取得できない場合は誤ったキャラ画像を表示せず装飾を省略。`KILL`、`x1`などの文字なし。短時間にキルが続いたら最大3段にスタック。
2. **額縁・発光**：枠の角にアクセント、より明瞭な2段階のハロー処理。ゴールド（シネマ）、ネオン、シンプル、インパクトに対応。色、光のON/OFF、光の強さ、中央マークを詳細編集から変更。シネマの中央マークは新しい「金のエンブレム」。（元画像と全く同じ装飾を複製するものではありません。）
3. **発光プレビュー**：「詳細編集→録画・出力→キルフレームを画像で確認」で変更後のPNGをすぐ表示。LoLリプレイの10人を取得して対象プレイヤーを固定してから利用。装飾が「なし」の場合は表示不可。公式画像の初回キャッシュ取得にはネット接続が必要。
4. **映像演出の「？」**：クリックすると分かりやすい説明ダイアログを表示。以前の「スクロール済みの上部欄だけが変わる」問題を解消。
5. **サイド別三人称カメラ**：「詳細編集→カメラ→サイド別・斜め後ろカメラ」で「自動（対象のチーム）／ブルー側基準／レッド側基準」を選択。ブルーとレッドで水平方向のオービットを180°切り替え、**カメラ位置と視線の回転をセットで更新**。既存TargetLockの座標系やプレイヤーへのアタッチは変更しません。サイド選択は設定に保存されます。

## 既存から維持する機能

- TargetLock、Orbit、Lolnam風カメラ、カメラプレビュー、円形DOF（円形モザイクはなし）。
- LoL専用音声、GPUエンコード設定、HUD、シーンチェック、スクロール操作、キル前後の演出、スマートモンタージュ。
- 横型1920×1080を基本として、縦型出力は追加しません。

## 実機テストのお願い

1. **キルログ／発光**：対象を固定→キルアイコンを「シネマ・ゴールド」→発光をON→強さ0.2と1.0を別々にプレビュー。光の違いと「金のエンブレム」を確認。ネオン・ブルーでも試す。
2. **複数キル**：近い時刻にキルが連続する場面で、異なる相手の画像が縦に並ぶか確認（最大3行、同時に表示している間のみ）。
3. **？説明**：映像演出の「？」を押すとダイアログが表示され、項目の説明を読めるか確認。
4. **サイド別**：ブルー対象とレッド対象で同じ三人称カメラの基準向きが切り替わるか、キャラがフレーム中央から外れないか確認。「手動レッド／手動ブルー」も試す。もし地形に隠れたり逆を向くなら**映像と診断ZIPを送ってください**。サイド方向を自動で切り替える幾何学的な実装であり、すべてのLoLリプレイで被写体が完璧に見えることはWindows実機ではまだ未検証です。
5. **旧機能確認**：LoL専用音声・カラー・GPU設定をCodex側の変更と比較。初回ネクサス対策、カラー/FXタブのホイール、チェック後のリスト位置もまとめて確認。

## 自動テストと制限

- Linux/XvfbでGUIを含む通常pytestを実施。元々時間のかかる`tests/gui_smoke.py`は別扱い。
- FFmpegの実動画で2キルの重ね合わせ、装飾PNGの発光差、ブルー／レッドのカメラ幾何、設定互換、説明ダイアログを検証。
- **Riot Replay API、WGC、NVENC、Windowsネイティブ音声の実機テストはこの環境ではできません。**
- v5.10.5ではCodex側で並行実装中のGPU処理には手を加えていません。
