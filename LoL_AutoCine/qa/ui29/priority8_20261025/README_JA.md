## 比較手順

1. `LoL_AutoCine_UI29.exe` を起動する。外部ブラウザは不要。
2. 右端「UI比較」で候補を選ぶ。8候補を上表の順で試す。
3. メインのスキャン/シーン/ミラー/動画作成/基本設定を探す。新B/Cは左端「シーン・スキャン」を開く。
4. 「詳細編集へ」でカメラ、素材、FX、色/シーン、タイムラインへの入口を試す。「メインへ戻る」で戻る。
5. 切替前後のカメラ値と選択シーンを見比べる。原画像がない派生詳細は機能配置を評価し、画像忠実度の採点から外す。
