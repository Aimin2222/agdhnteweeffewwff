- 旧11画面には編集可能なHTMLソースがなく、現在のブラウザ実装では**未実装**として明示する。元画像を貼って操作できるように見せない。
- 新18画面も、現時点で全722部品の接続と視覚合格は完了していない。単純な操作の接続を始めた段階であり、候補セレクターから旧候補を選んでも未実装応答となる。
- エンゲージ専用検出は既存Appに見当たらないため能力 `engage=false` とし、キルへ代替接続しない。
- `baseline/index.json` は29件すべて `NOT_RUN`。これは実装キャプチャやLoL実機を確認していないという意味で、合格ではない。

## 画面ごとの審査

アプリ実行画面を画面IDと同じ名前のPNGで撮影し、同寸の原本、50%重ね、絶対差分、領域RGB平均絶対誤差を作る。

```powershell
python tools/ui29_review.py --capture-dir <実装PNGフォルダ> --bounds-dir <実測JSONフォルダ> --output qa/ui29/review
```

実測JSONは `{"regions":{"header":[x,y,w,h], ...}}`。新画像は主要矩形の各辺±2px、旧画像は再構成として±8原画pxを初回許容する。映像内容だけをマスクし、周囲のパネルと操作部品は審査に含める。比較画像ができても自動的に `PASS` にしない。

LoL実接続、GPU/NVENC、ゲーム音声、録画、動画書き出し、1920×1080/60fps、125%/150%のWindows倍率は別の実機記録で判定する。現時点は未検証。現行版のバックエンド、カメラ計算、GPU、録画、音声、BAT起動には手を加えていない。
