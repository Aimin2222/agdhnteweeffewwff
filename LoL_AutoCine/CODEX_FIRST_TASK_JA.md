# Codex に最初に頼むタスク

このフォルダは LoL AutoCine v5.8.5 です。`AGENTS.md` と `CODEX_HANDOFF_JA.md` を最初に読んでください。

**最初のタスクは実装の全面改修ではなく、「安全な開発基盤の整備・現状診断」です。**

1. フォルダ構成、Windows依存部分、GUI、カメラ、FFmpeg/GPUフィルター、音声、診断、テストを読み、実コードに基づくアーキテクチャ図（Markdown）を作ってください。
2. `git status` を確認し、現状を保持できるようGitのベースライン化手順を提案してください（既に履歴がある場合は壊さない）。
3. 既存のPython構文チェックとWindows不要のテストを実行し、通過/失敗/未実行と理由を区別してください。
4. `avgblur_opencl` の実行可否・NVENC有効状態・エフェクト実行経路のログが一致しているか、ソースレベルで検証してください。
5. GPUエフェクトが未実行になった原因仮説と、Windows/GTX 1070 Tiで使う診断コマンドを含めて、段階的な移行計画を作ってください。
6. 必要なら診断ログ・GPU状態を改善する**小さな修正だけ**実装してください。ロールバック可能な変更にし、変更ファイル一覧とテスト結果を出してください。

**禁止**: 既存カメラ座標系・LoL専用録音処理・UI全体の書き換え、機能の削除、実機未検証のGPU速度向上の断言。
**完了条件**: 現状を安全に管理でき、次のGPUエフェクト開発へ移れる状態。日本語で結果とユーザー実機テスト方法を説明。
