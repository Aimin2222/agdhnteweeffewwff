# LoL AutoCine v5.10.10：実シーン比較・UI整理・発光調整

## 変更内容

- **テンプレート図鑑：実フレーム比較**
  - スキャンで検出したキル／アシストシーンを選び、「①選択シーンへ移動」→ミラー映像に正しい場面が映っていることを確認→「②ミラーの今の実フレームを保存・比較」。
  - 各テンプレートに同じ実フレームの **左：補正前、右：色＋2D FX適用後** を並べる。
  - 以前から保存済みのシーンサムネイルは自動で再利用できる。「再表示」で再読み込み。
  - 未取得時は架空画像を表示せず、撮影の案内を表示。比較元シーンはキルとアシストのどちらでも選べる。
  - カードから適用すると従来どおり本体UIとミラーにテンプレート設定が伝わる。
  - **カメラ位置・時間変化・FFmpeg固有演出は1枚の画像から完全再現できない**。比較はカラーと一部2D FXの静止画近似。実際の書き出しは別途確認が必要。
- **UI整理**
  - 旧来の「かんたん編集／詳細編集」分離を維持。
  - キルフレームの発光・色・中央装飾など詳細な設定を折りたたみ式に変更。
  - かんたん編集側の折りたたみ色見本（方式A）と、独立した実シーン図鑑（方式B）を両方残す。後で好きな方を選べる。
  - アプリ起動直後・ウィンドウサイズ変更時の「LoLミラーを開始すると…」の案内を中央に再配置。
- **発光の微調整**
  - 詳細編集のキルフレーム設定に、発光量0.0〜2.0のスライダーと「弱／標準／強」ボタンを追加。
  - v5.10.9で追加したプレミアム素材型6スタイルを**385×116の適正サイズ**にリサイズして書き出し時に合成。
  - 素材型でも追加ブルーム・発光色・角の光の強さを描画へ反映。素材に描き込まれた元の光は残るため、発光0は「完全に光の無い別デザイン」ではない。
- **維持した機能**：キルログ素材6種＋従来4種、キル／アシストスキャン、サイド別カメラ、TargetLock、LoL専用ゲーム音、円形DOF、GPU優先エンコード、既存エフェクト、1080p/60fpsの基本仕様。

## 簡単な使い方

1. ZIPを新しいフォルダへ解凍し `LoL_AutoCine/START.bat` から起動する。
2. LoLリプレイを開き、対象チャンピオンを選び、ミラーをON、キル＋アシストなどをスキャン。
3. 上部「テンプレート」から図鑑を開き、代表シーンを選択。
4. **①シーンへ移動** → ミラーに希望の戦闘場面が映ったのを確認 → **②実フレームを保存・比較**。
5. カードごとの左（元画像）と右（テンプレ色／FX適用後）を比較し、気に入ったものを適用。
6. 必要なら「詳細編集→録画・出力→キルフレーム詳細」で発光を弱／標準／強に調整し、プレビューして書き出す。

## 注意

- ミラーを再生していないと実フレームは取得できない。画像を勝手に別シーンへ割り当てることを避けるため、シーンの確認・撮影はユーザー操作で行う。
- GPUフル書き出しのコアや音声実装には手を加えていない。ミラーFXは従来どおりPython/PILによる近似であり、GPU書き出しとピクセル完全一致ではない。
- 実機確認は `TESTLIST_v5.10.10_JA.md` を参照。

## Codex用差分について

- 差分のベースは **v5.10.9 Windowsフル版**。同梱のパッチを `git apply --check` で確認してからマージ。
- 最新のCodex作業ブランチに同じファイルの変更がある場合、丸ごと上書きしない。特にGPUコードはCodex側の変更を優先する。
