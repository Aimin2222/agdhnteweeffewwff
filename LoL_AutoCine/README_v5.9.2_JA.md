# LoL AutoCine v5.9.2 — Scene Keyframes / FX / Thumbnails

## このバージョンで追加したもの

1. **カメラキーフレーム**：シーン選択後「時刻s / 回転° / 寄り% / FOV°」を入力し「追加 / 選択を更新」。時刻はキル瞬間を0秒とした相対時間。最大40件で滑らかに補間。空のままなら従来のカメラ制御。
2. **実際の動画へ反映**：シーン別演出ONで「このシーンに保存」したキーフレームは、既存のCameraPlanに渡り、キャラ中心のOrbit・視線・距離・FOVを同期して動かします。カメラの実機での最終的な高さ・角度は引き続き要確認。
3. **シーン別色/エフェクト**：「このシーンだけ色・エフェクトを上書き」をONにした場合のみ、色温度、ブルーム、Focus Blur、DOFぼかしを個別設定。OFFなら全体テンプレートを継承します。
4. **シーンサムネイル**：選択シーンへ移動→LoLミラーで場面を確認→「ミラーの現在画面をサムネイルに保存」。サムネイルはprojects/thumbnails/へ保存。映像を自動でseek/録画する機能ではありません。
5. **編集プロジェクト互換性**：schema_version 3。v5.9.0のv1、v5.9.1のv2を読み込み可能。新機能はUndo/Redo・保存/読み込みに対応（保存の確定操作が必要）。

## 変えていないもの

- 既存のワンクリック作成、シーン選択、並べ替え、カメラ自動推薦、LoL音声録音。
- GPUパイプライン/FFmpeg実行部/Native Audio Helper（`core/gpu_pipeline.py`, `core/audio*.py`, `core/procloop.py`, `core/recorder.py`等）。
- `core/effects.py` はTemplateにフィールド1件追加のみ。エフェクト計算本体は無変更。

## PCで実際にテストしてほしいこと

1. v5.9.2を新規フォルダに展開し、START.batで起動。v5.9.1は別途バックアップ。
2. スキャンで1シーン選択 → シーン別演出をON → キーフレームを -2秒, 0秒, +2秒に追加（例: 回転 -12/15/0°、寄り 0/12/0%、FOV 0/-4/0°）→「このシーンに保存」。
3. グラフが変わることを確認し、1シーンを書き出す。キル前後にカメラが滑らかに動き、対象が画面内にいるか確認。
4. 色・FXの上書きをON → ブルーム0.2、色温度0.2、Focus Blur0.15などを指定 → 保存 → 1シーン書き出す（負荷が高いなら1つずつ）。
5. Undo/RedoとJSON保存・読み込みでキーフレームおよび色/FXが復元されるか確認。
6. シーンへ移動しLoLミラーを表示 → サムネイル保存 → 別シーンを選択し戻った時に同じ画像が表示されるか確認。
7. シーン別演出OFFでも前と同じ挙動、チェックした2シーン・音声・カラー・モンタージュも問題ないか確認。
8. エラーが出た場合は diagnostics/ をZIPにして共有。手動のCPU/GPU計測は不要。

## 既知の制約

- 「動きをプレビュー」は曲線グラフの更新。実機カメラプレビューは従来の「▶再生」を使用し、保存済みのシーン設定に限って反映します。
- サムネイルは**現在ミラーに映っているフレーム**です。自動で正確なキル瞬間へ移動してサムネイルを取得するものではありません。JSON外の `projects/thumbnails` に保存されるため、別PCへ移行する場合はフォルダもコピーしてください。
- Windows/LoL Replay API/GPU実機での書き出しはこの環境では検証できません。カメラ位置の以前の問題は今回の修正対象ではありません。
- 背景の色調整、ビデオエフェクトはGPUに変換されていません。Codex側で最適化する想定です。
