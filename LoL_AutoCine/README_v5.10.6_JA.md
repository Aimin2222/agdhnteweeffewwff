# LoL AutoCine v5.10.6 — ミラー復帰・カメラ・キルログ・アシスト・UI修正版

ベース: GitHub `codex/lol-autocine-v5105-responsive-ui-handoff`

## 実装

- **ミラー復帰**: 録画・プレビュー後、また録画準備や音声開始に失敗した場合、Replay APIを停止し選択チャンピオンの安全な俯瞰追従視点に戻す。これにより、三人称FPS offset=0で地形やモデルに埋まる問題を避ける。出力済み映像には影響しない。
- **レッドサイド**: 三人称Orbitでは元からレッドチーム向けにカメラ位置を180°変更していたが、視線のYawにサイド補正が抜けていた。両者をそろえた。TargetLockの計算は不変更。
- **キル＋アシスト**: 手動の全編スキャンでUIの検出モードをワーカーに渡し、「キル」に固定されないようにした。通常の全シーン作成で設定を変更した場合はスキャンし直す。結果ログにキル/アシスト件数を記載。
- **キルログ**: オリジナルの細い「ガラス斬撃」を新規追加。シンプルの自動中央装飾は「なし」。詳細編集では従来の中央マークも任意選択可能。外部の有料/ライセンス素材不使用。
- **「？」説明**: 映像演出の？上に約1秒ホバーすると小さな非モーダル説明を表示。クリック説明も互換性のため残す。
- **GPUエンコード**: Codexで進行中の別開発領域なので実装変更なし。
